Embeds let you export a feed of your agenda, sessions, and speakers to place in your app or website. The feed refreshes automatically — no manual sync or push required. You can output as styled HTML, basic HTML, JSON, XML, or iCal.

## Embed types

<CardGroup cols={2}>
  <Card title="Schedule itinerary" icon="list-check">Searchable sessions with multiple filters; prominent speaker headshots and bios.</Card>
  <Card title="Speaker gallery" icon="users">Speakers alphabetically by last name, with headshots and details.</Card>
  <Card title="Agenda" icon="table-cells">Approved sessions in a grid by location and time.</Card>
  <Card title="Session list" icon="list">Sessions with speakers, filterable by format, language, tag, track, location.</Card>
  <Card title="Speaker list" icon="microphone-lines">Speakers with their sessions and info.</Card>
</CardGroup>

<Note>
Search behavior varies by type: itinerary & session list match session titles and speaker names; speaker gallery & list match speaker names only. Descriptions, tags, levels, audience, and custom fields are excluded from search.
</Note>

## Create an embed

<Steps>
  <Step title="Open Embeds">In the **Deliver** module, select **Embeds**.</Step>
  <Step title="Add an embed">Click **Add Embed**.</Step>
  <Step title="Choose a format">
    - **Embed Styled HTML** — one line of JavaScript for an interactive agenda/session/speaker list
    - **Embed HTML** — HTML output for developers to style to your site theme
    - **JSON / XML** — expanded properties for apps or databases
    - **iCal** — a calendar link showing all approved sessions as events
  </Step>
  <Step title="Style & filter">
    (Styled/HTML only) Set display options, colors, and optional custom CSS, then apply filters such as specific tracks or statuses.
  </Step>
  <Step title="Select fields">
    Choose fields for the Agenda, Speaker, and Session cards. Grey fields are required; blue fields are preselected and customizable.
  </Step>
  <Step title="Save">Click **Save** to retrieve the embed code, and **Preview** to open it in a new window. Share the code with your web team.</Step>
</Steps>

## Updates & editing

Embeds auto-update every **60 minutes**. For faster updates, use **Embeds → ⋯ → Refresh Cache**. To edit, use **Embeds → ⋯ → Edit** — you can change styling and fields, but not the data type (create a new embed to change type). You may need to refresh the cache to see changes.
