Session Submitters are contacts that complete the Session Submission Form but may not be listed as a speaker of the session. An example of this is an assistant who completes the form on behalf of their leadership team.

Admin users may want to update this person for an existing session or create a new record for a new session that was added manually.

### Create & Assign A Session Submitter

To create a session submitter, you will need to first create them as a contact.

👉🏾 Learn how to create a contact

Next, you can assign the contact as a 'Session Submitter' of a session.
1.  Once a speaker is created, navigate to the Sessions module and click the pencil icon to the left of the session you want to associate the session submitter with.

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/image-png-Feb-02-2026-07-29-02-2623-PM.png)

2.  Within the session page, navigate to the "Participants" tab and locate the "Session Participants" box. Here you can remove the existing one: ​

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/image-png-Feb-17-2026-05-07-51-3723-PM.png)

3. Search for the contact's name to attach them to the session.

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/image-png-Feb-02-2026-07-31-11-8725-PM.png)

4.  Once complete, click the "Save Changes" button at the bottom of the page.
