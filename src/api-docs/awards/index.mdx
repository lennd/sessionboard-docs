The Awards API is the programmable side of Sessionboard Awards. It has its own reference, MCP tools and release notes, apart from the other Sessionboard products.

## Base path

Awards are organization-level, so every operation starts at `/v1/organization/{orgId}/awards`. It runs on the same regional hosts as the rest of the API: `public-api.sessionboard.com` in the US and `public-api-eu.sessionboard.com` in the EU.

## What you can do

<CardGroup cols={2}>
  <Card title="Programs">
    List, get, create, update and delete programs. Creating a program sets up its submission form and first round.
  </Card>
  <Card title="Categories, rounds and promo codes">
    Manage each program's categories and subcategories, review rounds and promo codes.
  </Card>
  <Card title="Submissions">
    List submissions (by status, category or current round), read their answers, update them, delete them.
  </Card>
  <Card title="Reviews">
    Read each reviewer's assignment and scores on a submission, and remove a reviewer.
  </Card>
</CardGroup>

Submissions are still created by nominees in the program's portal, and scores are entered by reviewers in the review portal.

`PUT` and `PATCH` update only the fields you send. Deletes are soft: the record goes to Trash. Where the app asks you to confirm (a program with submissions, a round with reviewer assignments, a promo code already used, a category with submissions), the API answers `409` until you send `force=true`.

Awards needs the `read:awards` and `write:awards` scopes; see [Authentication](/sessionboard-awards/api/authentication). AI assistants can do the same work with the [Awards MCP tools](/sessionboard-awards/api/mcp-tools). Release notes are in the [Awards changelog](/sessionboard-awards/api/changelog).
