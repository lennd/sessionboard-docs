## Upcoming

### Awards: build and edit your Awards Site by API or chat

**Added — the Sites API.** Read your Awards Site and its pages, edit the draft (pages, blocks, menu, theme), see what Publish would change in plain sentences, preview it as a visitor, a Nominee or a Reviewer on desktop, tablet or phone, publish, and restore any earlier version into the draft. `POST /v1/organization/{orgId}/sites/make` makes an Awards Site from your programs and your Brand Kit, or rebuilds a page you point it at. Every edit lands in the draft, and nothing goes live until you publish with the person's OK; an AI assistant's publish waits for a person to approve it in Sessionboard. The same operations are served under `/v1/sites/...` with the organization taken from the token. They need `read:sites` / `write:sites` or `read:awards` / `write:awards`. See the [Awards API overview](/sessionboard-awards/api).

**Added — ten MCP tools for your Awards Site,** from `list_sites` and `get_site` to `edit_site`, `publish_site` and `restore_site_version`. See [Awards MCP tools](/sessionboard-awards/api/mcp-tools).

<Note>
These arrive with an upcoming Sessionboard release. The date will be added here when they are live.
</Note>

## October 2026

### October 7 — Programs, categories, rounds, promo codes, submissions and reviews

**Added — manage Awards through the API.** Every path starts at `/v1/organization/{orgId}/awards`: programs; categories and subcategories, rounds and promo codes under `/programs/{programId}/...`; submissions (filter by `status`, `category_id`, `current_round_id`); and reviews. See the [Awards API overview](/sessionboard-awards/api).

**Added — the `read:awards` and `write:awards` scopes.** See [Awards API authentication](/sessionboard-awards/api/authentication).
