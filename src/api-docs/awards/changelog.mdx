Release notes for the Awards API and its MCP tools. Entries are grouped by month, newest first.

## Upcoming

### Agent sign-up

**Added — an AI agent can sign a person up, save a card and start a plan:** [plans and prices](/sessionboard-awards/api/reference/agent-sign-up/list-self-serve-plans-prices-and-card-rules) with no token, [start a sign-up](/sessionboard-awards/api/reference/agent-sign-up/start-a-sign-up-for-a-person) (Sessionboard emails the person a code), [finish it with their code](/sessionboard-awards/api/reference/agent-sign-up/finish-a-sign-up-with-the-persons-code), then [billing status](/sessionboard-awards/api/reference/agent-sign-up/get-card-and-plan-status), a [card link](/sessionboard-awards/api/reference/agent-sign-up/get-a-card-link-for-the-person) the person opens on Stripe, and [a plan on the saved card](/sessionboard-awards/api/reference/agent-sign-up/quote-or-start-a-plan-on-the-saved-card). New preview scopes `read:billing` and `write:billing`. See [Sign up with an AI agent](/sessionboard-awards/api/agent-signup).

**Added — invite teammates:** [`POST /v1/team/invite`](/sessionboard-awards/api/reference/agent-sign-up/invite-teammates) invites up to 20 colleagues, on any kind of account. From an AI assistant it waits for a person's OK in Sessionboard (`202`, `needs_approval`). New preview scope `write:team`; the product's own write scope works too. The MCP tool is `invite_teammates`.

### Everything in the Awards app, for AI assistants

**Added — add a nomination on someone's behalf:** [`POST …/awards/workspace/programs/{programId}/nominations`](/sessionboard-awards/api/reference/awards-workspace/add-a-nomination-on-someones-behalf) enters a nomination for a nominee, with the nominator, category and answers, and submits it like a nomination made on the Site (or keeps a draft and says which questions are left). It works on draft, open and closed programs, so an assistant can rehearse review and winners on a test program, and it emails no one. The MCP tool is `add_awards_nomination`.

**Added — the rest of the Awards app in the API and MCP tools:** the nomination form's questions, archiving a program, removing a reviewer or a nomination, the People's Choice vote, recording winners, the announcement preview, reminders and the nominations report. An assistant can now run a program from draft to announced winners; actions that go public or email people wait for a person's OK. See [Awards MCP tools](/sessionboard-awards/api/mcp-tools).

**Changed — winners from an assistant:** recording winners was refused to an assistant. It now waits for a person's OK in Sessionboard and is recorded as them. Announcing stays a separate step.

**Added — where nominations open:** a program's read now says which Site its nomination form is on, or will open on, and the form's revision for safe edits.

### Awards MCP tools

**Added — ten MCP tools for Awards,** from reading Awards Home and programs to drafting a program, opening nominations, inviting reviewers and announcing winners. See [Awards MCP tools](/sessionboard-awards/api/mcp-tools).

## October 2026

### October 7 — Programs, categories, rounds, promo codes, submissions and reviews

**Added — manage Awards through the API.** Every path starts at `/v1/organization/{orgId}/awards`: programs; categories and subcategories, rounds and promo codes under `/programs/{programId}/...`; submissions (filter by `status`, `category_id`, `current_round_id`); and reviews. See the [Awards API overview](/sessionboard-awards/api).

**Added — the `read:awards` and `write:awards` scopes.** See [Awards API authentication](/sessionboard-awards/api/authentication).
