Release notes for the Awards API and its MCP tools. Entries are grouped by month, newest first.

## Upcoming

### Agent sign-up

**Added — an AI agent can sign a person up, save a card and start a plan:** [plans and prices](/sessionboard-awards/api/reference/agent-sign-up/list-self-serve-plans-prices-and-card-rules) with no token, [start a sign-up](/sessionboard-awards/api/reference/agent-sign-up/start-a-sign-up-for-a-person) (Sessionboard emails the person a code), [finish it with their code](/sessionboard-awards/api/reference/agent-sign-up/finish-a-sign-up-with-the-persons-code), then [billing status](/sessionboard-awards/api/reference/agent-sign-up/get-card-and-plan-status), a [card link](/sessionboard-awards/api/reference/agent-sign-up/get-a-card-link-for-the-person) the person opens on Stripe, and [a plan on the saved card](/sessionboard-awards/api/reference/agent-sign-up/quote-or-start-a-plan-on-the-saved-card). New preview scopes `read:billing` and `write:billing`. See [Sign up with an AI agent](/sessionboard-awards/api/agent-signup).

### Awards MCP tools

**Added — ten MCP tools for Awards,** from reading Awards Home and programs to drafting a program, opening nominations, inviting reviewers and announcing winners. See [Awards MCP tools](/sessionboard-awards/api/mcp-tools).

<Note>
These arrive with an upcoming Sessionboard release. The date will be added here when they are live.
</Note>

## October 2026

### October 7 — Programs, categories, rounds, promo codes, submissions and reviews

**Added — manage Awards through the API.** Every path starts at `/v1/organization/{orgId}/awards`: programs; categories and subcategories, rounds and promo codes under `/programs/{programId}/...`; submissions (filter by `status`, `category_id`, `current_round_id`); and reviews. See the [Awards API overview](/sessionboard-awards/api).

**Added — the `read:awards` and `write:awards` scopes.** See [Awards API authentication](/sessionboard-awards/api/authentication).
