## October 2026

### October 7 — Programs, categories, rounds, promo codes, submissions and reviews

**Added — manage Awards through the API.** Every path starts at `/v1/organization/{orgId}/awards`: programs; categories and subcategories, rounds and promo codes under `/programs/{programId}/...`; submissions (filter by `status`, `category_id`, `current_round_id`); and reviews. See the [Awards API overview](/sessionboard-awards/api).

**Added — the `read:awards` and `write:awards` scopes.** See [Awards API authentication](/sessionboard-awards/api/authentication).
