---
title: "Awards MCP tools"
description: "The tools an AI assistant connected to the Sessionboard MCP server can use with Sessionboard Awards"
---

These tools are served by the Sessionboard MCP server. To connect an assistant, see [Awards API authentication](/sessionboard-awards/api/authentication#ai-assistants). Tools that read need `read:awards`; tools that change something need `write:awards`. Opening nominations, inviting reviewers and announcing winners reach people outside your team, so those three wait for a person's OK before they run.

| Tool | Hints | Description |
|------|-------|-------------|
| `get_awards_home` | read | Awards Home: who the awards are for and what is being awarded |
| `list_awards_programs` | read | Every Awards program: status, who can nominate and the review round's dates |
| `get_awards_program` | read | One program: its categories, the nomination form's questions and the review round with its scorecard |
| `draft_awards_program` | write | Draft a new program: name, and optionally a description, categories, nomination deadline and who can nominate |
| `update_awards_program` | write · destructive | Change a program's name, description, nomination deadline or who can nominate |
| `open_awards_nominations` | write · destructive | Open nominations: the program goes on the organization's Awards Site with a public nomination form |
| `invite_awards_reviewers` | write · destructive | Invite up to 50 reviewers to a program's review round |
| `assign_awards_reviews` | write | Give every submitted nomination its reviewers, spreading the load |
| `get_awards_results` | read | Submissions, reviewers, scorecards filled in and winners, per program |
| `announce_awards_winners` | write · destructive | Announce a program's winners and finalists by email |
