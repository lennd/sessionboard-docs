The Marketing API is the programmable side of Sessionboard Marketing. It is documented here, apart from the Platform API reference, because it serves the Marketing product: its own scopes, its own organization-wide operations and its own release notes.

## Base paths

Every operation is organization-level and is served two ways:

- `/v1/organization/{orgId}/marketing/...` with the organization in the path.
- `/v1/marketing/...` with the organization taken from the token.

Both run against the same regional hosts as the rest of the Public API (`public-api.sessionboard.com` in the US, `public-api-eu.sessionboard.com` in the EU). Tokens, scopes and AI assistant sign-in: see [Marketing API authentication](/sessionboard-marketing/api/authentication).

## Scopes

Marketing needs the preview scopes `read:marketing` and `write:marketing`. A token or OAuth client gets them only when they are named explicitly: tick them under **Opt-in** when you create an API token, or name them in your OAuth `scope` request. A token restricted to particular events cannot use these organization-wide operations.

## What you can do
