## Scopes

| Scope | What it allows |
|-------|----------------|
| `read:marketing` | Read how an event is doing, sign-up forms, subscribers and sign-up counts |
| `write:marketing` | Set goals, add and change sign-up forms, add and unsubscribe subscribers |

Both scopes are in **preview** and are never granted by default. A token or OAuth client gets them only when they are named explicitly: tick them under **Opt-in** when you create an API token, or name them in your OAuth `scope` request.

A token restricted to particular events cannot use the Marketing operations, because they act on the whole organization.

## Requests

Send an API token in the `x-access-token` header, or an OAuth access token as a bearer token:

```bash
curl https://public-api.sessionboard.com/v1/marketing/audience/summary \
  -H "x-access-token: <api-token>"
```

A request without a valid token returns `401`. A token without the scope an operation needs returns `403`.

## AI assistants

Claude, ChatGPT, Copilot and Gemini connect to the Sessionboard MCP server by signing in with OAuth; there is no token to copy. In your Marketing workspace, open **Apps**, then **AI assistants**. Add the Sessionboard connector, sign in, then ask.
