## Scopes

| Scope | What it allows |
|-------|----------------|
| `read:crm` | Read a person's Sessionboard engagement and the suggestions, and run the speaker finder (it reads only) |
| `write:crm` | Accept and dismiss suggestions, keep speaker finder results as suggestions, and run the actions |

A token whose scopes do not include the one an operation needs gets `403`. Another organization's id anywhere in the path returns `404`.

## API tokens

An organization admin creates a token in Sessionboard under **Organization Settings → API Tokens** and ticks `read:crm` and, to make changes, `write:crm`. Copy the token when it is shown, because it is displayed once. Send it in the `x-access-token` header:

```bash
curl "https://public-api.sessionboard.com/v1/organization/{orgId}/crm/member-value?email=ada@example.org" \
  -H "x-access-token: <api-token>"
```

A token restricted to particular events cannot use the CRM operations, because they act on the whole organization.
