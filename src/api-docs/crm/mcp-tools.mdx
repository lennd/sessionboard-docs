---
title: "CRM MCP tools"
description: "The tools an AI assistant connected to the Sessionboard MCP server can use with Sessionboard CRM"
---

These tools are served by the Sessionboard MCP server. To connect an assistant, see [CRM API authentication](/sessionboard-crm/api/authentication#ai-assistants). Tools that read need `read:crm`; tools that change something need `write:crm`. None connects an app: connecting takes the person's own keys, so they do it in Sessionboard CRM. Only `send_crm_contract` and `void_crm_contract` reach anyone, the signer, and they run only with `confirmed: true`, which the assistant passes after the person says yes. `archive_crm_pipeline_entry` needs `confirmed: true` too.

| Tool | Hints | Description |
|------|-------|-------------|
| `get_crm_home` | read | Contacts by type, tags, active contacts against the plan, the setup steps and the most recent contacts |
| `find_crm_contacts` | read | Search, filter (type, tag, source, event, active), sort and page contacts, with counts per type, tag and source |
| `get_crm_contact` | read | One contact with their history and the team's notes |
| `manage_crm_contact` | write, destructive | Add a contact, change one, or add a note. An email already in CRM is not added twice |
| `delete_crm_contacts` | write, destructive | Delete contacts by id; the assistant asks the person first |
| `tag_crm_contacts` | write, destructive | Add or remove types and tags on many contacts at once |
| `list_crm_tags` | read | Every tag with how many contacts have it |
| `manage_crm_tag` | write, destructive | Create, rename or delete a tag (its contacts are kept) |
| `import_crm_contacts` | write, destructive | Preview an import row by row, then import the rows the person agreed to, matched by email, sent 250 at a time |
| `list_crm_sources` | read | The CRMs, AMSs and event platforms people can be read from (contacts from HubSpot, Salesforce and iMIS; one event's speakers from Cvent, Swoogo, Bizzabo, ON24 and Goldcast): connected, health, what each brings |
| `discover_crm_people` | read | Who a connected app holds, compared with your contacts; writes nothing and never reads attendees, for the person to review before importing |
| `export_crm_contacts` | read | The filtered contact list as CSV, up to 1,000 rows (the Contacts page exports up to 25,000) |
| `get_crm_pipeline` | read | The stages with their counts and the pipeline entries (search, filter by stage, type, tag or event, sort, page), or one entry's history |
| `add_to_crm_pipeline` | write | Add up to 200 contacts to the pipeline in a stage and for an event; contacts already in it are skipped |
| `move_crm_pipeline_entry` | write, destructive | Move an entry to another stage with a note, or change its event; every move is kept in its history |
| `archive_crm_pipeline_entry` | write, destructive | Take an entry off the pipeline (the contact stays), after the person says yes |
| `list_crm_contracts` | read | Contracts by status or contact, with the contact, template and dates |
| `get_crm_contract` | read | One contract with its signers and history, and the PDF link |
| `send_crm_contract` | write, destructive | Send a contract for signature from a published template, or resend one, after the person approves the template, title and recipient |
| `void_crm_contract` | write, destructive | Void a contract that is not complete, after the person says yes |
| `list_crm_contract_templates` | read | The templates and the built-in starters |
| `add_crm_contract_starter` | write | Add a speaker, sponsor or exhibitor starter template, published and ready to send |
