## Upcoming

### CRM: the API and MCP tools

**Added — the CRM API.** Search, read, add, change, tag, delete and export contacts; add notes; manage tags; import from rows or a CSV, 250 rows a call, with a preview that saves nothing; list and connect CRMs, AMSs and event platforms, and discover who they hold without writing anything (contacts from HubSpot, Salesforce and iMIS; one event's speakers from Cvent, Swoogo, Bizzabo, ON24 and Goldcast). Paths start at `/v1/organization/{orgId}/crm`; the same operations are served under `/v1/org/{orgId}/crm` and, with the organization taken from the token, `/v1/crm`. They need the preview scopes `read:crm` / `write:crm`. See the [CRM API overview](/sessionboard-crm/api).

**Added — twelve MCP tools,** from `get_crm_home` and `find_crm_contacts` to `import_crm_contacts` and `discover_crm_people`. See [CRM MCP tools](/sessionboard-crm/api/mcp-tools).

**Added — the pipeline and contracts.** List the pipeline's stages and entries, add contacts, move an entry with a note, read its history, archive it and export; list, read, send, resend and void contracts sent with Sessionboard e-sign, get the PDF, list templates and add a built-in starter. Contacts gain `stage`, and a contact's page gains `pipeline` and `contracts`. Sending, resending and voiding email the signer.

**Added — ten MCP tools** for the pipeline and contracts, from `get_crm_pipeline` to `send_crm_contract`. Archiving, sending and voiding run only with `confirmed: true`, after the person says yes.

**Added — People and hand-offs.** List everyone the organization knows with the CRM view (membership, lifecycle stage, CRM owner, pipeline stage, attendance), filter for warm opportunities, read one person's signals, add people to contacts and export. Bring an event platform's attendees into People, keep a source in sync, and hand a selection to Marketing, Sessions, Learning or Awards as a tag. `POST …/crm/import` takes `as: people`, and discovery says where each kind lands.

**Added — six MCP tools** for People: `find_crm_people`, `find_warm_opportunities`, `get_crm_person`, `add_people_to_crm_contacts`, `start_crm_attendee_sync` and `hand_off_crm_people`.
