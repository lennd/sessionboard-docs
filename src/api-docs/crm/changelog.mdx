Release notes for the CRM API. Entries are grouped by month, newest first.

## Upcoming

### Agent sign-up

**Added — an AI agent can sign a person up, save a card and start a plan:** [plans and prices](/sessionboard-crm/api/reference/agent-sign-up/list-self-serve-plans-prices-and-card-rules) with no token, [start a sign-up](/sessionboard-crm/api/reference/agent-sign-up/start-a-sign-up-for-a-person) (Sessionboard emails the person a code), [finish it with their code](/sessionboard-crm/api/reference/agent-sign-up/finish-a-sign-up-with-the-persons-code), then [billing status](/sessionboard-crm/api/reference/agent-sign-up/get-card-and-plan-status), a [card link](/sessionboard-crm/api/reference/agent-sign-up/get-a-card-link-for-the-person) the person opens on Stripe, and [a plan on the saved card](/sessionboard-crm/api/reference/agent-sign-up/quote-or-start-a-plan-on-the-saved-card). New preview scopes `read:billing` and `write:billing`. See [Sign up with an AI agent](/sessionboard-crm/api/agent-signup).

### Connected apps

**Added — the operations Sessionboard's CRM apps call:** [a person's Sessionboard engagement](/sessionboard-crm/api/reference/crm-connected-apps/get-a-persons-sessionboard-engagement), [suggestions](/sessionboard-crm/api/reference/crm-connected-apps/list-suggestions) with accept and dismiss, the [speaker finder](/sessionboard-crm/api/reference/crm-connected-apps/find-speakers-for-a-topic), and [actions](/sessionboard-crm/api/reference/crm-connected-apps/create-a-draft-from-a-crm-action) that create drafts.

<Note>
These arrive with an upcoming Sessionboard release. The date will be added here when they are live.
</Note>
