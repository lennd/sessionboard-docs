---
title: "Learning MCP tools"
description: "The tools an AI assistant connected to the Sessionboard MCP server can use with Sessionboard Learning"
---

These tools are served by the Sessionboard MCP server. To connect an assistant, see [Learning API authentication](/sessionboard-learning/api/authentication#ai-assistants). Tools that read need `read:learning`; tools that change something need `write:learning`.

## Courses from your videos

| Tool | Hints | Description |
|------|-------|-------------|
| `list_learning_media` | read | The Media-section videos and clips a course can be made from, newest first |
| `read_learning_library` | read | Published and draft lessons and courses in the Learning library: what `assign_course` can target |
| `read_course_drafts` | read | Course drafts made from videos, with their status and progress |
| `draft_course_from_media` | write | Start a course from 1 to 10 Media-section videos or clips |
| `update_course_draft` | write | Save edits to a draft: reword a question, drop a lesson, rename the course |
| `apply_course_draft` | write · destructive | Publish a reviewed draft (lessons, course and certification) and assign it |
| `assign_course` | write · destructive | Assign a published certification, course or lesson to the whole team or named teammates |

## Workspace, learners and results

| Tool | Hints | Description |
|------|-------|-------------|
| `read_learning_workspace` | read | Read the Learning workspace |
| `publish_event_on_demand` | write · destructive | Put a meeting on demand, in three steps |
| `import_meeting_for_learning` | write · destructive | Bring a meeting in from the organization's registration platform and make courses from it |
| `get_learning_results` | read | Learning results: completions and certifications, or credits for associations |
| `read_learners` | read | Find learners by name or email, and read one learner's courses, certifications, assignments and credits |
| `list_certifications` | read | The organization's certifications: what earns one, how long it lasts and how many people hold it |

## Engagement

| Tool | Hints | Description |
|------|-------|-------------|
| `due_for_recertification` | read | Who is due for recertification |
| `recommend_courses` | read | Courses to recommend to a group of people |

## Your Learning Site

Edits land in the Learning Site's draft; nothing goes live until `publish_site`, which an assistant calls only after the person has seen the changes and said OK. Reading needs `read:sites` or `read:learning`; changing needs `write:sites` or `write:learning`.

| Tool | Hints | Description |
|------|-------|-------------|
| `list_sites` | read | Your Sites, with whether each has unpublished changes |
| `get_site` | read | One Site as its draft stands: pages, blocks, menu, theme, the block kinds it takes and the rules for editing |
| `make_site` | write | Make a Learning Site from your courses and your Brand Kit, or rebuild a page from its address |
| `edit_site` | write | Edit the draft: add, change, move, hide or remove pages and blocks; set the menu and the theme |
| `get_site_diff` | read | What publishing would change, one plain sentence per change |
| `preview_site` | read | A link to the draft as one role on one device, and what that role sees |
| `publish_site` | write · destructive | Publish the draft once the person has said OK |
| `list_site_versions` | read | Every published version, newest first |
| `restore_site_version` | write · destructive | Copy an earlier version into the draft to review and publish |
| `discard_site_draft` | write · destructive | Throw away the unpublished changes |
