The Learning API is the programmable side of Sessionboard Learning. It has its own scopes, its own reference and its own release notes, apart from the other Sessionboard products.

## Base paths

Every operation is organization-level and is served two ways:

- `/v1/organization/{orgId}/learning/...` with the organization in the path.
- `/v1/learning/...` with the organization taken from the token.

Both run on the same regional hosts: `public-api.sessionboard.com` in the US and `public-api-eu.sessionboard.com` in the EU. Use the host for the region your organization's data is in.

## What you can do

Learning needs the preview scopes `read:learning` and `write:learning`; see [Authentication](/sessionboard-learning/api/authentication). The same work is available to AI assistants as [Learning MCP tools](/sessionboard-learning/api/mcp-tools). Release notes are in the [Learning changelog](/sessionboard-learning/api/changelog).
