## Upcoming

### Agent sign-up

**Added — an AI agent can sign a person up, save a card and start a plan:** [plans and prices](/sessionboard-learning/api/reference/agent-sign-up/list-self-serve-plans-prices-and-card-rules) with no token, [start a sign-up](/sessionboard-learning/api/reference/agent-sign-up/start-a-sign-up-for-a-person) (Sessionboard emails the person a code), [finish it with their code](/sessionboard-learning/api/reference/agent-sign-up/finish-a-sign-up-with-the-persons-code), then [billing status](/sessionboard-learning/api/reference/agent-sign-up/get-card-and-plan-status), a [card link](/sessionboard-learning/api/reference/agent-sign-up/get-a-card-link-for-the-person) the person opens on Stripe, and [a plan on the saved card](/sessionboard-learning/api/reference/agent-sign-up/quote-or-start-a-plan-on-the-saved-card). New preview scopes `read:billing` and `write:billing`. See [Sign up with an AI agent](/sessionboard-learning/api/agent-signup).

## October 2026

### October 30 — Courses from video (preview)

**Added — make a course from Media-section videos.** Draft a course from one to ten webinars, recordings or clips (`POST /v1/organization/{orgId}/learning/drafts/create`), poll the draft until it is ready, edit it, then publish and assign it (`…/drafts/{draftId}/apply`). Each lesson plays a clip cut from the video, pauses on questions written from what was said, and ends in a quiz. The same operations are available under `/v1/learning/…` with the organization taken from the token.

**Added — the preview scopes `read:learning` and `write:learning`,** granted only when named. See [Learning API authentication](/sessionboard-learning/api/authentication).
