## Upcoming

### Learning: build and edit your Learning Site by API or chat

**Added — the Sites API.** Read your Learning Site and its pages, edit the draft (pages, blocks, menu, theme), see what Publish would change in plain sentences, preview it as a visitor or a signed-in learner on desktop, tablet or phone, publish, and restore any earlier version into the draft. `POST /v1/organization/{orgId}/sites/make` makes a Learning Site from your courses and your Brand Kit, or rebuilds a page you point it at. Every edit lands in the draft, and nothing goes live until you publish with the person's OK; an AI assistant's publish waits for a person to approve it in Sessionboard. The same operations are served under `/v1/sites/...` with the organization taken from the token. They need `read:sites` / `write:sites` or `read:learning` / `write:learning`. See the [Learning API overview](/sessionboard-learning/api).

**Added — ten MCP tools for your Learning Site,** from `list_sites` and `get_site` to `edit_site`, `publish_site` and `restore_site_version`. See [Learning MCP tools](/sessionboard-learning/api/mcp-tools).

<Note>
These arrive with an upcoming Sessionboard release. The date will be added here when they are live.
</Note>

## October 2026

### October 30 — Courses from video (preview)

**Added — make a course from Media-section videos.** Draft a course from one to ten webinars, recordings or clips (`POST /v1/organization/{orgId}/learning/drafts/create`), poll the draft until it is ready, edit it, then publish and assign it (`…/drafts/{draftId}/apply`). Each lesson plays a clip cut from the video, pauses on questions written from what was said, and ends in a quiz. The same operations are available under `/v1/learning/…` with the organization taken from the token.

**Added — the preview scopes `read:learning` and `write:learning`,** granted only when named. See [Learning API authentication](/sessionboard-learning/api/authentication).
