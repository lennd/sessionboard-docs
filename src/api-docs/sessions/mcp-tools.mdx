---
title: "Sessions MCP tools"
description: "The tools an AI assistant connected to the Sessionboard MCP server can use with Sessionboard Sessions"
---

These tools are served by the Sessionboard MCP server. To connect an assistant, see [Sessions API authentication](/sessionboard-sessions/api/authentication#ai-assistants). Tools that read need `read:sessions`; tools that change something need `write:sessions`. Opening the call for speakers and publishing the agenda are public, so those two wait for a person's OK before they run.

| Tool | Hints | Description |
|------|-------|-------------|
| `get_sessions_home` | read | Your plan, every Sessions event with its counts and whether its call is open, and what the plan leaves to the Sessionboard platform |
| `get_sessions_event` | read | One event: dates, timezone, the call for speakers (open, link, text, closing date), rooms, tracks, sponsors and counts |
| `list_submissions` | read | An event's sessions with speakers, decision, time, room, track and sponsors; only the call's submissions, or one decision |
| `get_event_agenda` | read | Accepted sessions with times and tags; the rooms, tracks and sponsors; whether the agenda is published |
| `list_event_speakers` | read | Everyone on an accepted session, with their sessions and the speakers your plan includes |
| `manage_sessions_event` | write, destructive | Create an event, or change its name, dates, timezone or location |
| `manage_call_for_speakers` | write, destructive | Change what speakers see and the closing date, close the call, or ask to open it (waits for a person's OK) |
| `decide_submission` | write, destructive | Accept, decline or move back to undecided. No email is sent to speakers |
| `manage_program_session` | write, destructive | Add a session you invited, with its speakers, or change a session's title, description, time, room, track and sponsor tags |
| `set_rooms_and_tracks` | write, destructive | Replace the room list, the track list, or both; one a session still uses is kept |
| `manage_event_sponsors` | write, destructive | Add a sponsor (name and website) or remove one |
| `import_event_program` | write | Add sessions and speakers from spreadsheet rows; titles already on the event are skipped |
| `publish_event_agenda` | write, destructive | Ask to publish the agenda and speaker wall to your website (waits for a person's OK) |

Your plan's limits apply to assistants as they do to people: the tools say what needs a bigger plan instead of trying another way around it.
