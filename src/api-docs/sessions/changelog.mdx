## Upcoming

### Sessions: the API and MCP tools

**Added — the Sessions API.** List and create Sessions events; change what speakers see on the call for speakers and close it; list submissions and accept or decline them; add and import sessions; give sessions a time, room, track and sponsor tags; set the rooms and tracks; read the speakers; add and remove sponsors. Opening the call and publishing the agenda answer `202 needs_approval` and wait for a person's OK in Sessions. Paths start at `/v1/organization/{orgId}/sessions-workspace`, and the same operations are served under `/v1/sessions-workspace` with the organization taken from the token. They need `read:sessions` / `write:sessions`. See the [Sessions API overview](/sessionboard-sessions/api).

**Added — thirteen MCP tools,** from `get_sessions_home` and `list_submissions` to `decide_submission`, `manage_program_session` and `publish_event_agenda`. See [Sessions MCP tools](/sessionboard-sessions/api/mcp-tools).
