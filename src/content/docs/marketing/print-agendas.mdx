**Print** turns the sessions, speakers and sponsors already in your event into printable booklets — a full program book, a day-at-a-glance grid, a speaker bio book, a sponsor guide. You pick a starter, the editor fills it from your event data, and you fine-tune the structure, branding and layout before exporting a PDF or sharing a link.

## Before you begin

Make sure your event has:

- Accepted sessions with dates, times and rooms
- Accepted speakers, ideally with headshots and bios
- Sponsors and their tiers, if the booklet includes a sponsor page
- Event branding — the editor pulls your logo, colors and fonts from your event settings

You need **Reports › Read** to open Print, **Content › Create** to add a booklet and **Content › Update** to edit one.

## Open Print

Open your event and go to **Program → Print**. Every booklet and certificate already created for this event is listed as a card. Each card shows the record type it prints (Sessions, Session role) and a **Legacy** badge on older Word-based templates.

![The Print page listing the booklets created for an event, with the Add menu in the top right](/images/kb/print-library.png)

Use the **⋯** menu on a card to **Edit**, open **Settings**, **Duplicate** or **Delete** it.

## Create a booklet

Click **Add → Add Template**. The **Create a booklet** dialog gives you five ways to start:

![The Create a booklet dialog on the Gallery tab, showing starter cards with a category chip and estimated page count](/images/kb/print-create-booklet.png)

| Tab | Use it when |
|---|---|
| **Gallery** | You want a pre-built booklet. Pick a starter and the editor opens with your event data already merged in. |
| **From scratch** | You want an empty booklet — a cover and one blank page — and will add elements yourself. |
| **Import Word** | You have an existing program in a `.docx` file. Headings, paragraphs, lists and tables become editable blocks, and the booklet takes its name from the first heading. |
| **AI prompt** | You would rather describe the booklet. Sessionboard picks the best starter, applies your title and opens the editor. |
| **Legacy** | You need the older per-record document flow — one merged Word or rich-text document per session or person. See [Create documents](/documents/document-generation). |

### Gallery starters

| Starter | What it builds | Typical length |
|---|---|---|
| Agenda Program Book | Complete program: cover, welcome, day-by-day schedule, speaker bios, sponsors | ~24–40 pages |
| Conference Brochure | Marketing-grade prospectus: introduction, key themes, at-a-glance schedule | ~16–34 pages |
| Detailed Agenda | Linear day-by-day agenda with times, rooms and speakers | ~2–12 pages |
| Schedule Grid (At-a-Glance) | Day-at-a-glance grid with one column per room or track | ~1–4 pages |
| Daily Schedule Sheet | One printable page per day, time × room, filterable to a track | ~1–3 pages |
| Speaker Bio Book | Pocket book of headshots, titles and full bios | ~10–60 pages |
| Awards Program | Ceremony booklet — categories, nominees and winners | ~12–28 pages |
| Session Handout | One-page flyer for a single session | ~1 page |
| Sponsor Guide | Tier-by-tier sponsor showcase | ~6–18 pages |

Page counts are estimates; the real number depends on how many sessions, speakers and sponsors your event has.

<Tip>
**Copy from…** in the same **Add** menu imports a booklet you have already built in another event in your organization, so a returning conference can start from last year's program.
</Tip>

### Certificates

Below the booklet gallery, the **Certificates** section holds per-person starters: **Chair / Moderator Certificate**, **Invited Speaker Certificate**, **e-Poster Certificate**, **Poster on Board Certificate**, **Oral Presentation Certificate** and **CE / Credit Certificate**. Each prints one certificate per person per session, driven by your session roles (the CE / Credit certificate takes its signatories from your organization's credit settings). Certificates use the legacy document editor — see [Create documents](/documents/document-generation) for merge fields, filters and printing.

![The Certificates section of the Create a booklet dialog with six certificate starters](/images/kb/print-certificates.png)

## The booklet editor

The editor has three panels: **Structure** on the left, the **Preview** in the middle and an inspector on the right. Every change saves automatically and queues a recompile, so the preview catches up a few seconds after you edit.

![The booklet editor with the Structure rail, compiled preview and the Document properties inspector](/images/kb/booklet-editor.png)

### Top bar

- **Title** — click the booklet name to rename it.
- Status chip — *Not compiled yet*, *Compiling…*, *Compile failed*, or *Up to date* with the time of the last compile, page count and block count. A yellow bar underneath lists **compile notes**, such as an empty block that printed nothing.
- **Regenerate with AI**, **Revision history**, **Share** and **Export** — covered below.
- **Recompile** — rebuilds the booklet from current event data. Use it after you edit sessions or speakers elsewhere in the event.

### Structure

Sections are the chapters of your booklet (Cover, Welcome, Schedule, Featured Speakers, Our Sponsors, …). Drag the handle to reorder a section, click it to select it, and use **Add section** at the bottom to append a new one. Inside a section, click a block to select it or **Add element** to insert one.

**Add element** opens the **Add to booklet** dialog:

![The Add to booklet dialog listing text, data, media and layout elements](/images/kb/booklet-add-element.png)

| Group | Elements |
|---|---|
| Text | Heading, Rich text, Stat row |
| Data blocks | Agenda list, Agenda calendar, Schedule grid, Speaker grid, Sponsor grid, Awards list, Table of contents |
| Media | Image, QR code |
| Layout | Section, Columns, Grid, Divider, Spacer |

Data blocks are what make the booklet live: an Agenda list prints whatever sessions match its filters at compile time, so adding a session to the event and clicking **Recompile** updates every booklet that lists it.

### Block inspector

Select a block and the right panel switches to the **Block** tab with that block's options. For an Agenda list you can group by day or track, show descriptions, choose a participant layout and field order (honorific, name, title, company), toggle headshots, pick which participant roles appear and add contact fields.

![The Block inspector for an Agenda list block with grouping, participant and headshot options](/images/kb/booklet-block-inspector.png)

### Document properties

The **Document** tab applies to every page:

- **Brand kit** — shows the palette, font and logo resolved from your event's branding. **Apply to booklet** copies them into the booklet's colors and typography; **Refresh** re-reads them after you change the event's branding. You can still override any value afterwards.
- **Colors** — Primary, Headings, Body text, Background, Surface, Accent, Border and Muted text.
- **Page setup** — portrait or landscape, and margins in inches.
- **Typography** — a system font, a Google font, or an uploaded font file.
- **Header** and **Footer** — bands that print at the top and bottom of every page except covers.

### Preview

Toggle **Print layout** to switch between continuous scrolling and one card per printed sheet, which is the layout your PDF will have. **New tab** opens the compiled booklet full-size in its own browser tab.

## Regenerate with AI

Describe the change you want — "add a sponsor thank-you page after the schedule", "make the speaker bios shorter" — and click **Generate proposal**. The editor shows a diff of what would change; **Apply changes** writes it to the booklet and **Discard** leaves it untouched. A proposal never overwrites your booklet on its own.

![The Regenerate with AI dialog with a prompt box and Generate proposal button](/images/kb/booklet-regenerate.png)

## Revision history

Every edit is saved as a revision. Open **Revision history** to preview any earlier version and **Restore** it; restoring creates a new revision, so nothing is lost.

## Export

**Export** offers four formats:

![The Export menu with PDF, PDF (large book), Markdown and Copy as Markdown](/images/kb/booklet-export-menu.png)

- **PDF** — print-ready, formatted pages, downloaded immediately.
- **PDF (large book)** — for long programs. It runs in the background and Sessionboard notifies you when the file is ready.
- **Markdown (.md)** — the text of the booklet as a file.
- **Copy as Markdown** — the same text on your clipboard, ready to paste into a notes tool or an AI assistant.

Export always uses the latest compile. If the status chip says *Up to date*, the PDF matches the preview; recompile first if you have changed event data since.

## Share a link

**Share → Publish** creates a public URL that anyone can open without a Sessionboard account.

![The Share dialog with the public link, Copy link, Republish and Revoke](/images/kb/booklet-share.png)

<Warning>
The link is a **snapshot** of the current compile, so recipients keep seeing that version even as your program changes. When you are ready to push an update, click **Republish** — the URL stays the same and the content rolls forward. **Revoke** (click it twice to confirm) turns the link off.
</Warning>

## Keep the booklet current

1. Edit sessions, speakers or sponsors anywhere in the event as usual.
2. Open the booklet and click **Recompile**, or edit any block — edits recompile automatically.
3. Check the compile notes bar for empty blocks.
4. **Export** a fresh PDF, or **Republish** the shared link.

## FAQ

**Do I need a Brand Kit from Marketing?**
No. The booklet's Brand kit section reads your event's own branding — event settings, or your portal appearance and organization defaults when the event has none. [Marketing Brand Kits](/marketing/brand-kits) drive Advocacy assets and the CMS site.

**Can I edit the compiled PDF?**
Edit the booklet instead — the PDF is generated from it. Every block, color and margin is editable in the inspector, and Import Word lets you bring in text you already have.

**Why is a section blank in the PDF?**
A data block with no matching records prints nothing and raises a compile note. Check the block's filters, and that the sessions or speakers it expects are accepted in the event.

**Where did the older document templates go?**
They are still on the Print page with a **Legacy** badge, and the **Legacy** tab of the Create a booklet dialog makes new ones. See [Create documents](/documents/document-generation).
