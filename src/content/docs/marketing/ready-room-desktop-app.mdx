Ready Room is the Sessionboard desktop app for the machine in the room — the laptop that drives the projector in a speaker ready room or a session room. It signs in with the same console link as the [Live Transcribe Console](/marketing/live-transcribe-console), keeps every speaker file on disk, opens decks in PowerPoint or Keynote with one click, runs Live Transcribe from the room's audio feed, and puts captions on a confidence monitor. It runs on macOS and Windows.

Ready Room is the Sessionboard desktop app for the machine in the room. It runs on the laptop that drives the projector, keeps every speaker deck on disk, opens them in PowerPoint or Keynote, and streams the room audio to Live Transcribe for captions. It signs in with the same console link the Live Transcribe Console uses, so the web console and the station always show the same live state.

Reach for it when a room has to keep working even if the venue Wi-Fi does not: a speaker ready room, a session room with a dedicated technician, or a confidence monitor that needs captions. The web console stays the right tool for a producer moving between rooms with a browser.

Paste the console link from your invite email. A link shared by the whole room asks for your email, so the team can see who is on the station. If you do not have a link yet, enter the event ID and one is emailed to you.

Choose the room this station is running. Each room shows how many sessions it has, and the search box helps when the venue has many. Everything for the event, every room, every session and every file, is already syncing to this machine in the background.

The room runs top to bottom by day, with the session that is on now marked live. Pick a session to prepare it.

A session shows its description, the participants with their roles, the session timer, and every deck that has been uploaded. Files download on their own as soon as a speaker uploads them. The green check means the file is on this machine and ready.

Open launches the file in its default app, PowerPoint, Keynote or Preview. Reveal shows it in the folder, Copy path puts the location on the clipboard, and you can drag files into the order you will present them. That order stays on this station and never changes anything in Sessionboard.

If a speaker re-uploads a deck after it was downloaded, the file is flagged, never swapped underneath a running presentation. Pull the new version when you are ready, and the old copy is replaced.

When a speaker hands you a USB stick, add the file from this machine. It joins the same playlist, marked as local, and opens the same way.

Live Transcribe runs from the station too. Pick the room audio input, watch the level meter move, and start. The transcript streams in as the speaker talks, and because the station shares the console state, nobody can start a second capture of the same session by mistake.

The caption overlay is a transparent, always-on-top window you can drop on a confidence monitor or a second display. For a switcher, turn on the chroma-key fill and key it out. Position, size, colors and the number of lines are in Settings.

Focus Mode is the all-day view for a technician. Every session for the room sits on top, the selected session's files sit below, and Play, Next and the folder are one key away.

If the network drops, everything already synced keeps working. The status bar says so, the decks still open, and sync picks up again the moment the venue Wi-Fi returns.

Settings holds the rest: the download folder and auto-download, the clock format, theme and language, the caption overlay style, the server region for your account, how much space the files take, and sign out.

Ready Room is downloaded from inside Sessionboard: under Live Transcribe, and from the Live Transcribe Console home. Install it on the room machine, paste the console link, and the decks are already there when the speaker walks in.

## Why use it

Show day is where a browser tab falls short. The deck has to open in the real PowerPoint or Keynote, on the machine that is plugged into the projector, and it has to be there before the speaker walks in — not downloading over venue Wi-Fi while the room fills up. Ready Room does that work ahead of time: it syncs every file to the room machine as soon as it is uploaded, flags a re-upload instead of swapping it under a running presentation, and keeps the schedule, speakers and files usable when the network drops. Because it shares the Live Transcribe Console's sign-in and live state, the producer at the desk and the technician in the room see the same thing, and nobody double-starts a capture.

## When to use it, and when to use the console

| | Ready Room (desktop) | Live Transcribe Console (browser) |
|---|---|---|
| Runs on | The room machine, installed | Any laptop with Chrome |
| Speaker files | On disk, opened in PowerPoint, Keynote or Preview | Downloaded one at a time |
| Re-uploaded deck | Flagged as **New version on server**, pulled when you choose | Download again |
| Live Transcribe | Yes, from the room's audio input | Yes |
| Captions on a monitor | Caption overlay window, transparent or chroma-key | Attendee View in a browser |
| Network drops | Keeps working from the local copy; sync resumes | Needs the connection |
| Sign-in | Console link (named invite or magic link) | Same |

Use Ready Room for a speaker ready room, a session room with a dedicated technician, or anywhere a confidence monitor needs captions. The console remains the right tool for a producer who moves between rooms with a browser, and for Mission Control.

## What each station needs

- A Mac (macOS 12 or later) or Windows PC (Windows 10 or later) that stays in the room, with PowerPoint, Keynote or another app that opens the speakers' files.
- A console link for the event — a named invite from **Marketing → Transcribe → Invites**, or a direct magic link. See [Give your crew access](/marketing/live-transcribe-console#give-your-crew-access).
- For Live Transcribe: the soundboard or microphone feed into the machine's audio input.
- For the caption overlay: a second display or a capture into your switcher.
- Enough disk space for the event's files. Ready Room checks for free space before every download and keeps files under `Documents/Sessionboard Ready Room`, one folder per session.

## Install and sign in

<Steps>
  <Step title="Download Ready Room">
    In Sessionboard, open **Apps → Ready Room** (every screen of the app, the walkthrough video and the installers) or the **Ready Room for desktop** card under **Marketing → Transcribe**. The same card is on the Live Transcribe Console home, so a crew member with a console link can download it without an admin account. Pick **Download for macOS**, **Windows** or **Windows on ARM**. Every download is recorded in **History** for the organization.
  </Step>
  <Step title="Install it">
    On a Mac, open the disk image and drag **Sessionboard Ready Room** to Applications. On Windows, run the installer; it installs for the current user with no admin prompt. On first launch, allow microphone access when the system asks — Live Transcribe needs it.
  </Step>
  <Step title="Paste the console link">
    Paste the link from your invite email into **Console link** and click **Connect**. A link shared by the whole room asks for your email, which is what attributes activity to a person. No link yet? Enter the event ID and Ready Room emails you one, if your address has been invited to the event.
  </Step>
  <Step title="Choose the room">
    Pick the room this station is running. Everything for the event — rooms, sessions, speakers and files — is already syncing to the machine.
  </Step>
</Steps>

![The Ready Room sign-in screen with the Console link field and Connect button](/images/kb/ready-room-app-login.png)

<Tip>
A named invite lasts 30 days and can be opened again, so a station that restarts signs back in by itself. A direct magic link lasts 30 minutes — use it to get someone in right now, not for a station you set up the week before.
</Tip>

## The three views

![The room picker, listing each room with its session count](/images/kb/ready-room-app-rooms.png)

- **Rooms** — one card per room with its session count. Choose the room this machine is running; the search box helps at a large venue.
- **Agenda** — every session for the event by day, in time order, with the live session marked.
- **Focus Mode** — the all-day view for a technician: the room's sessions on top, the selected session's files below, and the play controls always in reach. See [Focus Mode](#focus-mode).

Opening a room shows its sessions top to bottom by day. Pick a session to prepare it.

## A session and its files

![A session in Ready Room: description, participants and files on the left; the session timer, Live Transcribe and the live transcript on the right](/images/kb/ready-room-app-session.png)

The session page has the description, the participants with their roles, the session timer, and **Presentations & files** on the left; the session tools — timer, **Live Transcribe**, **Caption overlay** and **Live transcript** — on the right.

### Files

Every file a speaker uploads downloads to the station on its own (turn this off under **Settings → Sync & downloads → Auto-download files** if you would rather download by hand). The icon beside each file tells you where it stands:

| Icon | Meaning |
|---|---|
| Green check | On this machine and ready to open |
| Spinner | Downloading |
| Clock | Waiting to download |
| **New version on server** | The speaker re-uploaded it after it was downloaded |
| Red warning | The download failed; **Re-download** tries again |

![A session's file list with Open, Re-download, Reveal and Copy path on each file](/images/kb/ready-room-app-session-files.png)

For each file:

- **Open** launches it in the default app for its type — PowerPoint or Keynote for a deck, Preview or Acrobat for a PDF.
- **Reveal** shows it in Finder or File Explorer. **Copy path** puts its location on the clipboard, for an app that wants to open it itself.
- **Re-download** fetches a fresh copy from Sessionboard.
- The participant picker on the row assigns the file to a speaker, and the handle on the left drags files into the order you will present them.

<Note>
Presentation order and which participant a file is assigned to are kept on this station only. They help the technician run the room and never change anything in Sessionboard.
</Note>

### When a speaker re-uploads a deck

A file that is re-uploaded after it was downloaded is flagged **New version on server** and left alone — the copy on disk is never swapped underneath a running presentation. Click **Get latest version** when you are ready, and the old copy is replaced. The notice on the session page says how many files have a newer version.

![A file flagged New version on server, with the Get latest version button](/images/kb/ready-room-app-session-new-version.png)

### Files from a USB stick

**Add a file from this machine** puts a file that never went through Sessionboard — a last-minute deck on a USB stick — into the same playlist, marked **Local**. It opens the same way and can be removed from the list later. It is not uploaded to Sessionboard.

### Presenting

When a file is on disk, the bar at the bottom of the session page shows what is up next. **Play** opens it; the keyboard does the rest while you stay on the session:

| Key | Action |
|---|---|
| **→** | Play the next file |
| **←** | Previous file |
| **Esc** | Stop |
| **F** | Open the session's folder |

## Live Transcribe from the station

![Audio input picker, level meter, language and the Stop transcription button while a capture is recording live](/images/kb/ready-room-app-transcribe.png)

The **Live Transcribe** panel on the session page works the same way as the [console's](/marketing/live-transcribe#capture-a-session):

1. Pick the room's audio input. The level meter shows whether the feed is live before you start.
2. Choose a language, or leave it on auto-detect.
3. Click **Start transcription**. The panel shows **Recording live**, the transcript streams into **Live transcript** below, and the console shows the same capture.

A session the event left out of **Sessions available to transcribe** can't be captured, even from the station's saved copy: the panel says it is not available to transcribe.

Only one capture runs per session, wherever it was started. If someone else is already live on the session, the station says so and offers **Take over**, which stops their capture, keeps the audio already saved, and starts a new take from this machine. Changing the audio input is blocked while recording; stop first.

Live Transcribe has no on/off switch: it is available on every event. What the station can capture, and with which model, follows the event's **Marketing → Transcribe → Settings**; see [Set up before the event](/marketing/live-transcribe#set-up-before-the-event).

## Caption overlay

![The caption overlay window showing live captions in a dark box](/images/kb/ready-room-app-overlay.png)

**Show** under **Caption overlay** opens a transparent, always-on-top, click-through window with the station's live captions. Drag it onto a confidence monitor or a second display; it prefers a display other than the main one when there is one. It only shows captions from this station's own capture.

For a switcher, turn on **Chroma key background** under **Settings → Caption overlay**: the window fills with solid green so the switcher can key it out. The other overlay settings are position (top or bottom), font size, number of lines, text color, box color and box opacity. **Hide** closes the window; it also closes when the main window does.

## Focus Mode

![Focus Mode, with the room's sessions above and the selected session's files below](/images/kb/ready-room-app-focus-mode.png)

Focus Mode is for a technician running a room for the whole day. The top pane lists every session, filtered to one room or all rooms, with a dot showing whether its files are ready, partly downloaded or missing. The bottom pane is the selected session's playlist with **Play**, **Folder**, **Add** and **Re-download**. The same keyboard shortcuts apply. **Exit Focus Mode** returns to the room picker.

## Working offline

Ready Room keeps the event on the machine: rooms, sessions, speakers and files. If the network drops, the status bar switches to **Offline, showing saved copy** and everything already synced keeps working — files open, the agenda and speakers read as before. Sync picks up on its own when the connection returns; **Sync now** in the status bar forces a check.

![The status bar showing Offline, showing saved copy](/images/kb/ready-room-app-offline.png)

The status bar always shows connectivity, the sync state (**Up to date**, **Syncing…**, **Sync error**), how many files are downloading, and the time. Ready Room checks Sessionboard for changes every 30 seconds while online.

## Settings

![The Settings page in Ready Room](/images/kb/ready-room-app-settings.png)

| Section | What it holds |
|---|---|
| **Signed in** | The event and the operator this station is signed in as, and **Sign out**. If the event team revokes the invite the station signed in with, the station is signed out and returns to the sign-in screen |
| **Display** | 12-hour or 24-hour clock, light, dark or system theme, and the app language |
| **Sync & downloads** | **Auto-download files**: fetch new speaker files as soon as they are uploaded |
| **Storage** | The download folder (change it or reset to the default), how much space the files use, and **Delete all downloaded files** |
| **Caption overlay** | Position, font size, lines, text color, box color and opacity, chroma-key background |
| **Server** | The Sessionboard region your account lives in (US or EU) |
| **About** | The installed version and **Check for updates** |

<Warning>
**Delete all downloaded files** removes every file in the download folder for every session. They download again on the next sync, but not instantly — do this after the event, not between sessions.
</Warning>

## Updates

Ready Room updates itself. A signed-in station checks for a new version shortly after launch and every four hours, downloads it in the background and installs it the next time the app quits — never during a session. **Settings → About → Check for updates** asks right away. A station that is signed out or offline does not check; it catches up the next time it is online and signed in.

## What the event team can see

Ready Room reports what a station does, so the event team can follow the room from Sessionboard without being in it:

- **Marketing → Transcribe** lists every station that has reported in for the event: the room it runs, who is signed in, the app version and platform, and when it was last seen.
- **History** records each station's activity — signing in and out, the room picked, decks opened or re-downloaded, Live Transcribe started and stopped, the caption overlay shown or hidden, Focus Mode, an update installed, going offline and back online — under the subject **Ready Room station**. Console and desktop sign-ins appear as **Ready Room sign-in**, and installer downloads as **Ready Room download**. A station that was offline reports later, with the original times.

## FAQ

<AccordionGroup>
  <Accordion title="Does the technician need a Sessionboard account?">
    No. Ready Room signs in with the same console link as the Live Transcribe Console — a named invite or a direct magic link. An admin login works too.
  </Accordion>
  <Accordion title="Can the console and the app run at the same time?">
    Yes. They share one live state per session: a capture started in the app shows as live in the console and the other way round, and only one capture runs per session.
  </Accordion>
  <Accordion title="Where are the files on the machine?">
    In `Documents/Sessionboard Ready Room`, one folder per session, unless you change the folder under **Settings → Storage**. **Reveal** on any file takes you there.
  </Accordion>
  <Accordion title="A speaker just re-uploaded their deck. Which copy opens?">
    The copy already on disk, until you click **Get latest version**. The file is flagged **New version on server** so you can pull it between sessions rather than mid-presentation.
  </Accordion>
  <Accordion title="The station says the session is already live somewhere else.">
    Someone started the capture from the console or another machine. **Take over** stops their capture, keeps what was recorded, and continues from this station.
  </Accordion>
  <Accordion title="Does the overlay show captions from the console?">
    No. The overlay shows captions from this station's own capture. To put captions in front of the audience from any source, use the [Attendee View](/marketing/attendee-view).
  </Accordion>
</AccordionGroup>
