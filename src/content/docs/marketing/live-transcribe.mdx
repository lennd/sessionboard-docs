## Two ways to run it

Which one you use depends on how your event is staffed.

| | Self-serve | AV crew |
|---|---|---|
| Who runs it | Your team, from the admin app | AV professionals, from the Console |
| Where | **Marketing → Transcribe** | [Live Transcribe Console](/marketing/live-transcribe-console) at a separate URL |
| Login | Normal Sessionboard login | Magic link, no account |
| Best for | A handful of rooms you're staffing yourself | Multi-room events with a dedicated AV team |

Both produce identical output. You can mix them across an event.

## What each room needs

Sessionboard runs in the browser, so nothing is installed on the room laptops. Plan on this per conference room:

- **A laptop with Chrome.** It stays in the room for the day and runs the Console.
- **A wired internet connection.** Live transcription streams audio continuously; venue Wi-Fi drops cause gaps a wired line does not.
- **Audio input connected to the laptop.** A line from the soundboard into the laptop's audio input. A laptop microphone works in a small room, but a board feed is what makes a large room accurate.
- **One person assigned to start and stop each session.** Transcription never starts by itself. Name who presses **Start Transcription** and **Stop Transcription** in each room before show day.

The people running the rooms need access to the event: either a Sessionboard login ([invite them as event team members](/event-team/invite-manage-event-team-members)) or a Live Transcribe Console invite link, which needs no account (see [Give your crew access](/marketing/live-transcribe-console#give-your-crew-access)).

## Set up before the event
Go to **Marketing → Transcribe → Settings**.

- **Sessions available to transcribe** — which sessions appear in the Live Transcribe Console and the Capture session picker. Choose **All sessions**, or **Only sessions with selected statuses** and tick the standard and custom statuses to include; at least one must stay ticked. New events start with Accepted only. Events that were already set up keep showing all sessions until you change this. With a status filter on, withdrawn sessions are always left out. The attendee-facing session list is not affected.
- **Transcription model** — General or Medical. Medical is worth selecting for clinical and scientific programs.
- **Multilingual live captions** — turn this on when a room mixes languages on the same floor feed (for example English and French). The live model detects the language per utterance. Leave it off for English-only rooms. If a room must stay English-only live, feed the interpretation channel instead of the floor mix. When this is on, live capture **and** post-session recovery use General (Nova-3), because Medical is English-only. Medical still applies when the setting is off.
- **Keyterms** — product names, acronyms, and speaker names the model would otherwise miss.
- **AI summaries** and **AI insights** — generate a summary and pull quotes and topics per session.
- **Auto-generate recaps** — drafts a recap when a session stops. Drafts only; nothing publishes on its own.
- **Translation** — stores translated transcripts for admin use. Attendees pick their language in the attendee hub **Settings**. That picker is separate from this toggle.
- **Post-session recovery** — re-transcribes from the recording afterwards, which cleans up anything the live pass missed. Re-transcribing regenerates every line, so wait for it to finish before [correcting transcript lines by hand](/marketing/media-library#edit-a-transcript-line) — manual edits are discarded by a re-transcription.
- **Speaker tagging** — manage the **Generic participant tags** (Audience Member, MC / Emcee, Staff Member, Unknown Speaker, and any you add) used to label voices that are not session participants. See [Tag speakers](/marketing/media-library#tag-speakers).
- **Room Console** and **Mission Control** — for multi-room AV operations. See [Live Transcribe Console](/marketing/live-transcribe-console).

<Tip>
Add keyterms before your first session rather than after. They materially improve accuracy on names and jargon, and they can't retroactively fix a transcript that's already been captured.
</Tip>

## Capture a session

<Steps>
  <Step title="Open the session">
    Go to **Marketing → Transcribe** and open the **Console**, then pick the session from the room's schedule. Its session console is where the capture runs.
  </Step>
  <Step title="Choose your input">
    Select the microphone or line input. A feed from the soundboard gives far better results than a laptop microphone in a large room. The level meter under the picker moves when the feed is live. Click **Test input** to run a short transcription that is not saved to the session.
  </Step>
  <Step title="Start">
    Click **Start Transcription**. The transcript streams in live under **Live Transcript**.
  </Step>
  <Step title="Stop">
    Click **Stop Transcription** when the session ends. If auto-recaps are on, a recap draft is queued. In the [Live Transcribe Console](/marketing/live-transcribe-console), use **Next session** in the **Up next** panel to move straight on to the next session in that room.
  </Step>
</Steps>

<Warning>
Transcription never starts by itself — someone has to press start for each session. If a session ends with no transcript, that's almost always why.
</Warning>

## After the session

The session appears under **Captured sessions** with badges for Transcript, Summary, Insights, and Podcast. Opening it takes you to the session profile in [Media](/marketing/media-library), where you can [tag speakers](/marketing/media-library#tag-speakers) — session participants, or generic tags such as Audience Member and MC / Emcee for voices that are not contacts — [correct the transcript line by line](/marketing/media-library#edit-a-transcript-line), and pull [quotes](/marketing/quotes) and [clips](/marketing/clips).

Recap drafts land in **Marketing → Transcribe → Recaps**. Generating one takes a minute or two, and nothing publishes without you.

## Consent and sensitive sessions

Decide before the event which sessions may be captured, and keep the rest out of the pickers rather than deleting transcripts afterwards. Two controls do this:

- **Sessions available to transcribe** in **Marketing → Transcribe → Settings**. Choose **Only sessions with selected statuses** and give sessions that must not be recorded — licensed content, closed-door discussions — a status you leave unticked. They then do not appear in the Capture session picker or in the Live Transcribe Console, so nobody can start them by accident.
- Nothing is captured until someone clicks **Start Transcription**. For a one-off, simply do not start the session; the AV crew's Live Transcribe Console shows the same list you configured.

If a session was captured by mistake, delete the media from its card menu in [Media](/marketing/media-library). It moves to **Trash**, where **Restore** brings it back if you change your mind, and it stops appearing in the library, the attendee view and anything generated from it.

## FAQ

<AccordionGroup>
  <Accordion title="Do I need special hardware?">
    Nothing to install. Each room needs a laptop running Chrome on a wired internet connection, an audio input into that laptop (a soundboard feed gives the best quality), and a person assigned to start and stop each session. See [What each room needs](#what-each-room-needs).
  </Accordion>
  <Accordion title="How long until I can use the content?">
    The transcript is live as the session runs. Summaries and insights follow shortly after you stop. Recap generation takes a minute or two.
  </Accordion>
  <Accordion title="What if the transcript missed the beginning?">
    Turn on **Post-session recovery** in Settings. It re-transcribes from the recording afterwards and grooms the result. If **Multilingual live captions** is on, recovery uses the same mixed-language model so French and Portuguese stay labeled per utterance. Any re-transcription — recovery included — regenerates every line and discards transcript lines you edited by hand, so make manual corrections after it has run.
  </Accordion>
  <Accordion title="Can attendees follow along?">
    Yes, through the attendee hub. Configure it under the **Attendee View** tab. Attendees pick their language in hub **Settings** — live captions, replay, and the session transcript follow that choice, including when the floor mixes languages.
  </Accordion>
  <Accordion title="What if speakers switch languages in the same room?">
    Turn on **Multilingual live captions** in **Marketing → Transcribe → Settings** and capture the floor mix (stage mics), not the interpreter booth. Speaker labels stay on the people on stage. Use the interpretation channel only if that room must be English-only live; then the speaker label is the interpreter.
  </Accordion>
  <Accordion title="Why don't I see the Invites or Console options?">
    Those appear for enterprise AV setups. Events on the simplified shell run capture entirely inside the admin app.
  </Accordion>
</AccordionGroup>
