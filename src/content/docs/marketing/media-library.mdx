Media is where every recording lives — uploads, imports from your webinar platforms, and sessions captured with Live Transcribe. Each item gets a transcript, AI chapters, suggested clips, and quotes, all attributed to the speakers who appear in it.

<Note>
Media is part of the Marketing module, which is currently Early Access.
</Note>

## The tabs

- **Library** — everything you've ingested
- **Discover** — pull recordings from connected platforms
- **Quotes** — the [quote library](/marketing/quotes)
- **Clips** — the [clip library](/marketing/clips)
- **Import** — upload files or paste a URL
- **History** — the status of every import

At the organization level you get your whole corpus across events; inside an event it's filtered to that event.

## Import recordings
### Upload files
Go to **Media → Import** and drag files in, or use **Choose files** or **Choose folder**.

- Video and audio up to **50 GB** per file
- MP4, MOV, MKV, WEBM, M4V, AVI, MP3, M4A, WAV, AAC, FLAC, OGG
- SRT and VTT caption files
- Recordings up to about six hours

Uploads keep running in the bar at the bottom while you work elsewhere in Sessionboard.

<Warning>
Uploads don't resume if you reload the page. A 50 GB file can take over an hour, so leave the tab open — reloading means starting that file again.
</Warning>

### Import from a URL
Paste a YouTube or Vimeo URL on the same tab. Vimeo passwords are accepted for the import and aren't stored. Importing the same URL twice won't create a duplicate.

### Discover from connected platforms

**Discover** scans platforms you've connected under Apps — Zoom, Goldcast, ON24, BigMarker, Cvent, Google Drive, Dropbox, YouTube, Vimeo, and Descript — and lets you select what to bring in. Progress shows under **History**.

## What happens after import

Sessionboard extracts the audio, transcribes it with speaker diarization, and adds the result to your searchable corpus. Once the transcript is ready the item opens with a player, an editable transcript, and tools for chapters, clips, and quotes.

Speakers are matched to your contacts automatically, which is what makes content attributable per speaker across events.

## Work with a recording

Open any item from the Library, or a captured session from **Transcribe → Overview**.

- **Chapters** — click **Generate** to segment the recording, or **Regenerate** to redo it
- **Find quotes** — pull quotable lines into your [Quotes library](/marketing/quotes)
- **Suggested clips** — generate clip suggestions, then export the ones you want
- **Transcript** — correct text and tag speakers

<Tip>
Correct speaker tagging before generating quotes and clips. Attribution flows into the speaker's profile and every downstream asset, so fixing it first saves re-doing the rest.
</Tip>

### Tag speakers

Each detected voice in the transcript can be tagged as one of the session's participants, which is what attributes the content to that contact. Not every voice belongs to a contact, though — an audience question, the emcee, a staff announcement. Tag those as a **generic participant** instead: **Audience Member**, **MC / Emcee**, **Staff Member**, or **Unknown Speaker**, or a type your organization has added. Give the tag an **Instance label** such as "1" or "2" to tell several apart — "Audience Member 1", "Audience Member 2". Generic tags never create a contact, and they show on the transcript as a dashed grey badge so they are easy to tell from real speakers.

Admins manage the list under **Marketing → Transcribe → Settings**, in **Speaker tagging → Generic participant tags**: add a **New generic participant type** for the whole organization or this event only, rename one (for example **MC / Emcee** to **Host**), or archive one you no longer use. Labels must be unique within your organization (capitalization does not count as a difference), and an organization-wide label cannot reuse a name already used by an event-only type, since it would appear in that event's picker too.

### Edit a transcript line

Hover a line in the transcript and click the pencil (**Edit transcript text**), change the text, and click **Save** — or press ⌘ Enter / Ctrl Enter (Escape cancels). The corrected text is what recaps, exports, search, and the attendee hub use from then on. Search and chat results across Content Studio pick up the correction after a short re-index. If the line came from a linked media recording, the recording's transcript is corrected in the same step. The original wording is kept: an **Edited** chip on the line shows who changed it and when, and opens the line's edit history. The audio is never altered.

<Warning>
**Re-transcribing discards manual edits.** Re-transcription regenerates every line from the audio, so any lines you corrected by hand are lost. Sessionboard warns you with **Discard manual edits?** before it starts; make your corrections after the final transcription pass.
</Warning>

## FAQ

<AccordionGroup>
  <Accordion title="How long does processing take?">
    It depends on length and queue. Upload is usually the slow part — a large file can run an hour or more. Transcription follows automatically once the upload finishes.
  </Accordion>
  <Accordion title="Why is my YouTube import failing?">
    YouTube sometimes blocks automated downloads from data-centre addresses. Upload the file directly instead.
  </Accordion>
  <Accordion title="Can I import captions I already have?">
    Yes, SRT and VTT files are accepted alongside audio and video.
  </Accordion>
  <Accordion title="My library is empty but I've run events.">
    Media only contains what's been ingested. Sessions captured before Live Transcribe was enabled won't appear — import those recordings under **Import**.
  </Accordion>
</AccordionGroup>
