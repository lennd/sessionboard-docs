New features and improvements, newest first. Each entry links to the guide that covers it in full.

<Note>
Looking for something older? The [Sessionboard changelog](https://feedback.sessionboard.com/changelog) has the complete release history, and you can request features on our [feedback board](https://feedback.sessionboard.com).

## September 13, 2026

- **Surveys (Early Access Beta)** — score sessions, speakers, posters, and subsessions while the event runs, with named reviewer stations, an open link, per-session QR codes, and a printable committee packet. New in this release: checkbox and yes/no question types, conditional questions ("if bias = yes, describe"), and per-option result charts. Request access from **Sessions → Evaluation → Surveys**. [Surveys](/evaluations/surveys)

## September 12, 2026

- **Participant inventory for sessions** — set minimum and maximum participant targets per session and track staffing across the whole program with new **Assigned Participants** and **Assignment Status** columns on the Sessions grid. Off by default; enable it per event in Program Settings. [Track participant inventory on sessions](/sessions/participant-inventory)
- **Per-portal participant roles** — limit which roles portal users can assign when they add a participant to a submission, configured per portal with **Selectable Participant Roles**. Portals without a filter keep offering every role. [Portals 101](/portals/portals-101#step-three-configure-settings)
- **Portal sign-in methods per event** — turn username & password, magic-link, and single sign-on (SSO) access on or off per event, including the new passwordless magic-link option. [Choose how portal users sign in](/settings/portal-login-methods)
- **Date & time tiers for awards pricing** — charge different submission fees by deadline, such as early-bird and late pricing, from the awards pricing settings. [Awards pricing, payments & invoices](/awards/awards-pricing-payments-invoices)
- **Grip and Bizzabo sync improvements** — expanded guidance and behavior fixes for both connectors. [Grip](/apps/grip-integration) · [Bizzabo](/apps/bizzabo-integration)

## September 11, 2026

- **Tree custom field** — a new field type for multi-level choices (for example category → subcategory), alongside a reference page covering every custom field type and where each works best. [Custom field type reference](/concepts/custom-field-type-reference)
- **Visit and LiveBuzz writeback field pickers** — choose exactly which fields each connector writes back to Sessionboard instead of accepting a fixed set. [Visit](/apps/visit-integration) · [LiveBuzz](/apps/livebuzz-integration)
- **Email and file controls** — email campaigns can omit past recipients when re-sending, an Event Name merge tag is available in templates, and file-upload revision limits now support an admin exemption. [Email campaigns](/communications/email-campaigns) · [Enable, upload, & download files](/sessions/enable-upload-download-content)

## September 8, 2026

- **Automations (Early Access Preview)** — when a session or person field changes, automatically send a branded email or assign reviewers. Enable it per event. [Automations](/automations/overview)
- **Field rules** — format text, calculate a number, or assign fixed values to other fields on the same record when a saved value matches. [Create a field rule](/settings/field-rules)
- **Formula fields** — build a numeric field from other fields with a visual builder or a written expression. [Create a formula field](/settings/formula-fields)
- **Import currency handling** — clearer rules for currency values in CSV/XLSX imports. [Importing data](/settings/importing-data)

## September 4, 2026

- **Bidirectional question rules** — conditional logic on submission forms can now show or hide questions in both directions, on session and awards forms alike. [Session submission forms](/sessions/submission-forms)

## August 14, 2026

- **New App Marketplace connectors: LiveBuzz, Visit, and Brella** — push accepted sessions, speakers, and participants to each platform and keep them in sync. [LiveBuzz](/apps/livebuzz-integration) · [Visit](/apps/visit-integration) · [Brella](/apps/brella-integration)

## August 12, 2026

- **New Help Center** — this site launched at learn.sessionboard.com, replacing the previous knowledge base, and the same articles now power in-product help.
