## September 17, 2026

- **Recent runs on the Coordinator dashboard** — the Coordinator's Dashboard now lists its last ten runs: what each one drafted, how it ended, and how many eligible speakers it did not reach. A finished run used to leave no trace in the product at all. [Check Coordinator run history](/agents/coordinator-run-history)
- **Submission forms read right to left** — pick Arabic, Hebrew, Persian, or another right-to-left language on a multi-language form and the form is laid out right to left, not only translated. [Right-to-left languages](/sessions/submission-forms#right-to-left-languages)
- **Find translated fields in Add Field** — search the form builder's **Add Field** list by a field's translated name or by locale code, and the row containing your match opens expanded. The **Locked** badge on a standard field now explains on hover that adding a translated variant of it unlocks the row. [Add a translated field to the form](/sessions/submission-forms#add-a-translated-field-to-the-form)
- **Portal times name the event timezone** — a custom **Date & Time** field in a portal used to render in UTC with nothing on screen naming the zone, so a participant could read a time hours away from the one you entered. It now shows the event timezone with its abbreviation, the way session start and end times already did, and daylight saving is applied per value. [Dates and times in the portal](/portals/portals-101#dates-and-times-in-the-portal)
- **File request submissions now notify admins** — when a contact or group submits a file for a file request, event admins get a bell notification and an email instead of having to watch the File Requests tab. Control it under **Notifications > Preferences > File Request Submitted**, which now has an email option as well as in-product. [Collect documents/file requests](/portals/collect-documents#get-notified-when-a-file-is-submitted)
- **Session file uploads notify once, and only for participants** — uploading files on a session's **Files** tab used to send admins two notifications per upload, both worded as if a revision had been submitted, including when an admin did the uploading. It now sends one, only when a participant uploads, and says whether the file was uploaded or replaced. [Enable upload & download of content](/sessions/enable-upload-download-content)

## September 16, 2026

- **Submitters on full-page profiles** — assigned record owners now appear in the **Submitters** row on contact and session full-page profiles, not only in the slide-over sidebar. [Create a field rule](/settings/field-rules)
- **Visit consent picker lists every contact field** — the optional consent gate on a Visit mapping now offers every updatable contact field (portal-bound first), not only fields already placed on a portal form, plus form submissions and Config Set tasks. [Visit](/apps/visit-integration)
- **Visit Session ID on synced sessions** — when you push sessions as Visit activities, Sessionboard creates a read-only **Visit Session ID** field and fills it with the Visit activity id. The control reads **Set by Visit**. [Visit](/apps/visit-integration)
- **Embed search includes sub-sessions** — searching a schedule or session embed also matches sub-session titles and sub-session participants (every role the embed is set to display). The parent session is what surfaces. [Agenda & speaker embeds](/sessions/embeds)
- **Magic-link offer for first-time portal users** — when password and magic link are both on, people who have never signed in also see **Or, email me a sign-in link**. [Choose how portal users sign in](/settings/portal-login-methods)
- **Email frequency per organization and event** — the notification preferences you are looking at now carry their own **Email frequency**, so one organization or a single event can run on immediate emails while the rest of your account stays on the daily summary. The control names the setting in force, and **Use account default** clears an override — including one set from an event's portal preference centre, which previously could not be undone from the admin app. [Notifications](/communications/notifications#email-frequency)
- **Length limits stop the step, not the submit** — an answer outside a text question's minimum or maximum now blocks the step it sits on, naming the field and the limit, so submitters fix it as they go instead of meeting a wall of errors on Submit. [Session submission forms](/sessions/submission-forms#customize-question)

## September 15, 2026

- **Reconcile payments against your payment gateway** — a new **Reconciliation** tab on Awards and event invoices puts each invoice next to your gateway's own record of the charge: both statuses side by side, the processor's charge ID, a link to its hosted receipt, and a result saying whether the two agree. **Needs attention** narrows the table to the payments that disagree, and the organization-wide Awards export adds the charges your gateway processed that have no invoice at all. [Awards pricing, payments & invoices](/awards/awards-pricing-payments-invoices#reconciling-payments-with-your-gateway)
- **Tree fields open the next level in one click** — picking a value that has sub-values now reveals the level below it immediately, instead of taking a second click to expand. A new **only allow selecting the last level** field setting makes the upper tiers navigation-only, so every stored answer is a specific end value, and exports with several tree answers now join them with a pipe — the same separator an import file uses, so an export can be edited and re-imported. [Custom field type reference](/concepts/custom-field-type-reference#the-tree-field-multi-level-choices)
- **Reviewer recommendations on evaluations** — evaluators can mark each submission **Accept**, **Decline**, or **Alternate** alongside their scores; Alternate proposes new values for fields you choose (Format, Track, …) plus a note. Counts roll up in a Recommendations column on the plan's Submissions tab. [Round-based evaluations](/evaluations/setting-up-round-based-evaluations#reviewer-recommendations)
- **Reviewer session builds** — let evaluators propose combining their assigned abstracts into full sessions, within a per-reviewer quota you set per session type. Proposals land on a new **Builds** tab where you approve — creating the real session with the abstracts as subsessions — or decline with a reason. [Reviewer session builds](/evaluations/setting-up-round-based-evaluations#reviewer-session-builds)
- **Sort by score and saved views for evaluators** — evaluators can sort their queue by the score they've given and save named filter + sort combinations per round, with a starred default that applies automatically. [Evaluate sessions](/evaluations/how-to-evaluate-sessions#sorting-and-saved-views)
- **Suppression list for email campaigns** — see every address your event can no longer email, why each one was blocked, and clear a block once the cause is fixed. The list separates addresses that genuinely **Bounced** from those caught by a **Send failure**, where an entire message was rejected before sending — usually an unverified sending domain — so nobody received it and nothing bounced. Campaign run history now names which of the two skipped a recipient. [Suppression list](/communications/email-suppression-list)
- **Maritz RTS connector** — pull registrant profiles from Maritz Real-Time Services onto existing event contacts: job title, company, bio, and registration state stay current automatically on a 10-minute schedule. Inbound only — registrants match by Registrant ID then email, unmatched registrants are skipped and logged, and contacts are never auto-created. [Maritz RTS](/apps/maritz-rts-integration)
- **Embeds in your visitors' language** — every embed widget can now render in English, German, French, or Spanish: labels, buttons, search, and dates translate, and session titles, descriptions, and field values follow your event's [language variants](/settings/language-translation-variant) with automatic fallback for anything untranslated. Set a default in Style Options, or paste a per-language snippet on each localized page — one embed serves them all. [Embed languages](/sessions/embeds#embed-languages)
- **Choose which participant roles embeds show** — a new Participant Roles setting in the embed builder controls which roles appear across all widgets, including any custom roles you've created. Participants are grouped under their role name on session cards and pop-out views. [Agenda & speaker embeds](/sessions/embeds#how-to-create-an-embed)
- **Subsession details in embeds** — visitors can click a subsession inside a session's pop-out view to open its own detail view with its time, location, description, and participants. [Subsession details](/sessions/embeds#subsession-details)

## September 14, 2026

- **Copy sessions from another event** — bring sessions or abstracts from any other event in your organization into the one you're working in: pick the source event, select what to copy (no limit — large selections run in batches), map or create tracks, formats, rooms, tags, and custom fields, and confirm. Copies keep a visible link to their original on both sessions' Connections tabs. [Copy sessions from another event](/sessions/copy-sessions-from-another-event)
- **Merge tags for every session role** — emails sent from the Sessions module can name a session's moderators, chairpersons, and any custom role you've created directly in the message body, each with a "with titles" version that adds job title and company. The tags are grouped under **Session Roles** in the tag picker, alongside the existing speaker tags. [Email moderators and chairpersons](/faq/how-to-email-moderators-chairpersons#naming-them-in-the-message-body)
- **Session duration merge tag** — a new Session Duration (minutes) tag renders how long a session runs, worked out from its start and end times, so a speaker email can say "your session runs for 45 minutes" without looking it up. [Email campaigns](/communications/email-campaigns#sessions)
- **Nominee Headshot field for Awards forms** — the Awards form builder's Quick Add panel gains a Nominee Headshot field: submitters upload a single JPG, PNG, or GIF, and the image renders as a headshot in review sidebars, PDFs, and exports. [Awards submission form](/awards/awards-submission-form#standard-fields)
- **Per-portal session ordering** — a new **Session list order** setting on each portal's Configuration step controls how sessions and abstracts are ordered on the portal home: **Chronological** (scheduled sessions in agenda order, unscheduled last) or **Alphabetical**. [Create custom portals](/portals/creating-custom-portals#choose-how-sessions-are-ordered)
- **Clearer document template downloads** — the template editor's **Options** menu now separates **Download blank template** (the layout with merge fields unresolved) from **Generate for records** (finished documents bound to the records you pick), replacing the single ambiguous Download action. [Create documents](/documents/document-generation#the-options-menu)
- **Bulk file download for interest forms** — select interest-form submissions and click **Download Files** to get every uploaded file in one zip, organized by submission and named by question; the archive lands in **History → Exports**. [Interest forms](/speaker-crm/speaker-crm-interest-forms#download-submitted-files-in-bulk)
- **AND/OR recipient filters on campaigns** — advanced recipient filters on email campaigns can now combine with **Match all** (AND) or **Match any** (OR), so one send can target "Track A or Track B". [Email campaigns](/communications/email-campaigns#step-3-select-recipients)
- **Copy a site's configuration** — the Add Site dialog can start a new site from an existing one, copying settings, branding, and pages while you pick a fresh URL; the Clone Event options gain a matching **Sites** checkbox. [Setting up your site](/awards/setting-up-your-sessionboard-site#creating-a-new-site) · [Clone an event](/faq/clone-an-event)
- **Tag colors** — session tags can be given a preset or custom color when you create or edit them, and tag chips show it everywhere tags appear. [Program settings](/sessions/program-settings#tags)
- **Word and character limits on text questions** — **Customize Question** on a text field now has a **Length Limit** section: set a minimum and/or maximum and count in characters or words. Submitters see a live counter, and answers outside the limits are rejected. [Session submission forms](/sessions/submission-forms#customize-question)
- **Multi-page portal forms** — split a portal form into pages with **Page Break** blocks: portal users see a step indicator with your page titles, move through the form with Next and Back, and required questions validate per page. A new **Preview** button shows the form exactly as a portal user will see it, without leaving the builder. [Create & assign portal forms](/portals/create-assign-forms#layout-blocks--multi-page-forms)
- **Conditional logic on display blocks** — rich text blocks and section headers on portal forms can now be shown or hidden based on a previous answer, just like questions. [Create & assign portal forms](/portals/create-assign-forms#layout-blocks--multi-page-forms)
- **"New submission" automation trigger** — session automations can now fire when a form submission is completed (any form, or one you pick), and session email actions have a **Send to** choice: all participants, the submitter only, or both. Ideal for an instant "we received your submission" email. [Automations](/automations/overview)
- **Event-name merge tag in forms** — use &#123;&#123;event_name&#125;&#125; in submission-form and portal-form content (welcome text, section titles, descriptions, rich text, confirmation message) and it renders as the event's name — so duplicated forms don't carry last year's event name. [Session submission forms](/sessions/submission-forms#event-merge-tags-in-form-content)
- **Copy fields from another event** — from **Settings → Library → Fields**, **Add Field → Copy from…** imports custom fields from other events you can access; same-name fields are reused instead of duplicated. [Field types](/concepts/field-types#copy-fields-from-another-event)
- **Email themes on campaigns** — event email campaigns without their own theme are now wrapped in the event's default email theme, and a **Design not compiled** badge flags themes whose latest design edits haven't compiled into the sent HTML yet. [Email themes](/settings/email-themes)

## September 13, 2026

- **Tree field picker redesign** — on forms, Tree fields now open as a dropdown that shows one level at a time: drill into a branch to see its sub-options and use Back to go up, instead of scanning the whole hierarchy expanded at once. A new **max selections** field setting caps how many values can be picked — set it to 1 for single-select. [Custom field type reference](/concepts/custom-field-type-reference)
- **Redesigned Report Builder** — build custom reports in a full-screen workspace with a live preview: drag-and-drop columns, filters with real value pickers, grouping with date bucketing, pivots, nested rows, sorting with row limits, undo/redo, and an example gallery. Describe a report in plain English and the AI builds or refines it; schedule sends, share links, dashboard widgets, and the activity log are managed from tabs inside the builder, and exports run in the background. [Build a report](/reporting/report-builder)
- **Site builder for Program Sites** — design your Program Site visually with a live preview: choose the Portal or Marketing site layout, apply structural templates and WCAG-audited color schemes, build the landing page from twelve content sections, turn on public Speakers, Agenda, and Exhibitors pages with shareable profile pages and branded social cards, edit the menu and footer, hide the sign-in card on promotional sites, and start custom pages from ten ready-made templates including Call for papers and Evaluator guide. [Site builder](/site/site-builder)
- **Connect AI assistants to Sessionboard** — step-by-step guides for connecting AI assistants to your org through the Sessionboard MCP server, with the correct server URL for US, EU, and Middle East regions, OAuth sign-in, example prompts, and troubleshooting. [Overview](/integrations/connect-ai-assistants) · [Claude](/integrations/connect-claude) · [ChatGPT](/integrations/connect-chatgpt) · [Copilot](/integrations/connect-microsoft-copilot) · [Gemini](/integrations/connect-google-gemini)
- **Contracts with Docusign (Early Access Beta)** — send Docusign templates pre-filled with contact, account, session, and event data straight from a contact, account, group, or pipeline record; statuses update automatically, signed PDFs land on the record, a signed agreement can auto-advance the pipeline, and signers can sign from their portal. [Send and track contracts](/speaker-crm/contracts) · [Docusign](/apps/docusign-integration)
- **Surveys (Early Access Beta)** — score sessions, speakers, posters, and subsessions while the event runs, with named reviewer stations, an open link, per-session QR codes, and a printable committee packet. New in this release: checkbox and yes/no question types, conditional questions ("if bias = yes, describe"), and per-option result charts. Request access from **Sessions → Evaluation → Surveys**. [Surveys](/evaluations/surveys)
