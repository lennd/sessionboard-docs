When submitting a session proposal, you may not always have all the required information on hand. The Save as Draft feature allows your submitters to begin their submission and return to complete it later, without losing any progress.

👉🏼 Learn how submitters can save their submission as a draft

## View draft submissions
There are two ways to view draft submissions:
1. Navigate to the Sessions > Submissions Module.
   1. Select Drafts above the search bar. A filtered list of submissions that were saved as drafts will display with the submission's title, the session submitter, and source (which form did the submission come from).

   ![View Draft Submissions](/images/kb/37b6cfff-image-png-Feb-25-2026-06-44-23-0324-PM.png)

2. On the Session Submission Forms page (Sessions > Forms), click the ellipses next to a form and select View Draft Submissions.

![On the Session Submission Forms page (Sessions > Forms)](/images/kb/61452f73-image-png-Feb-25-2026-06-45-08-8845-PM.png)

Click on the pencil icon to the left of a submission to view the submission details that were provided so far.

![Opening a draft submission with the pencil icon to review the answers provided so far](/images/kb/4bd4f28c-release-notes-images.gif)

Conveniently see the total number of submissions and drafts for each session submission form from the event Dashboard module.

![Conveniently see the total number of submissions and drafts for each session submission form from the event](/images/kb/3eafd57a-image-png-Feb-25-2026-06-56-48-5156-PM.png)

<Note>
