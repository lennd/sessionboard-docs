Session files are the presentations, handouts and other materials attached to a session. Speakers upload them from the portal once you turn uploads on; admins can upload from the session at any time. Every file keeps its versions, can carry a comment thread, and the whole set downloads as one zip.

This page is about the **Files** tab on a session. File questions on a submission form — including Headshot — are separate: they use **Customize Question → Maximum file size** (up to 5 GB) and do not inherit the settings below. See [Session submission forms](/sessions/submission-forms).

## Enabling files

Uploads are off until you turn them on. Go to **Program → Settings → Files**.

![Program Settings → Files: Enable File Upload, File Due Date, File Limit, Enable Comments, Enable participant assignment, Allowed File Types and File Size Limits](/images/kb/program-settings-files.png)

| Setting | What it does |
| --- | --- |
| **Enable File Upload** | Lets speakers with portal access upload files to their sessions. Off, the session's Files tab tells admins "Speaker file uploads are turned off for this event" and only admins can add files. |
| **File Due Date** | The deadline shown to speakers in the portal. |
| **File Limit** | Maximum number of files per session, or leave empty for no limit. The limit counts files, not versions — a speaker at the limit can still upload a new version of an existing file, only brand-new files are blocked. Admins are never subject to it. |
| **Enable Comments** | Turns on the comment thread under each file. |
| **Enable participant assignment** | Requires whoever uploads — admin or portal user — to pick which session participant the file belongs to. |
| **Allowed File Types** | **All**, or any mix of PDF, PPT, Image, Video, Audio, Word, Excel, ZIP, PNG, JPEG, GIF, SVG and MP4. |
| **File Size Limits** | **Enable Size Limits**, then a **Size Unit** (KB, MB or GB) with a **Minimum Size** and **Maximum Size**. Without a limit, files can be up to 5 GB each. |

Select **Save Changes**. Speakers then see an **Upload Files** area on each of their sessions in the portal; what that looks like from their side is in [Upload files & make comments](/participants/upload-files).

<Tip>
Create a [portal task](/portals/assign-tasks) called "Upload your presentation" with the due date and a link to that participant article, so the upload shows up on every speaker's to-do list.
</Tip>

## Uploading files as an admin

Open the session (select **Edit** on its row) and choose the **Files** tab. Drag files onto the drop zone or select it to browse; the panel shows how many more files the session can take. To replace an existing file rather than add one, choose it under **New version of:** before uploading — the earlier version stays in the file's history.

![The Files tab on a session — the Upload Files drop zone above Session Files, where each file shows its latest version, upload date and size, uploader, comments and type badge](/images/kb/session-files-tab.png)

Each file shows its **Latest Version**, upload date, size, who uploaded it and its type. **Show History** lists earlier versions; the ⋯ menu offers **Download File**, **Copy link**, **Edit File Type** and **Delete File**.

![The file menu: Download File, Copy link, Edit File Type, Delete File](/images/kb/session-file-menu.png)

## Viewing submitted files

Two places show everything that has come in:

- **Program → Submissions → Files** lists every file in the event with the session it belongs to, the uploader and the upload date, in a grid or a list. Search, sort by upload date, and filter by **Upload date** or **File type**. Selecting a file opens it.
- **Program → Submissions → Sessions** — add the **Files** column under **Columns** to see which sessions have files and how many (versions are not counted). Open a session's **Files** tab to see them.

![Submission Files: a grid of every uploaded file with its session, uploader and upload date, plus Select all, search, sort and filters](/images/kb/submission-files-module.png)

## File comments

With **Enable Comments** on, every file has a thread that session speakers and admins share. Select **Show Comments** under a file (or **Expand All** to open every thread) to read it and add a comment; each entry records who wrote it and when.

<Warning>
Nobody is emailed when a comment is added — not the admin, not the speaker. If you leave feedback a speaker needs to act on, [send them an email](/communications/create-send-emails) pointing them at the portal.
</Warning>

## Sharing a single file

**Copy link** (on the file row or in its ⋯ menu) puts a direct link to the current version on your clipboard, so a colleague can open the file without downloading it or signing in to the session.

## Downloading files as a zip

The latest version of each selected file is bundled into a zip and emailed to you. Start from either place:

- **Program → Submissions → Files**: select the files (or **Select all**), then **Download Files**.
- **Program → Submissions → Sessions**: select the sessions, then **Download Files** in the bar above the table.

![The Download Files panel: "Download 9 files for 9 selected sessions", Group files by Content Type, Session Date, Room, Session, and the folder tree those groupings produce](/images/kb/files-download-sidebar.png)

**Group files by** decides the folder structure inside the zip. Select **Edit** to choose and order any of **Content Type**, **Session Date**, **Room** and **Session**; the tree underneath previews the folders, and you can expand it and untick anything you do not want included. Select **Generate Download**. The zip is built in the background — up to ten minutes for a large set — and an email with the subject **Your file is ready** brings the download link.

<Note>
Only the latest version of each file goes into the zip. To keep an earlier version, open the file's history on the session and download it from there.
</Note>

Both download buttons need the **Export** permission on Sessions; without it the button is disabled.
