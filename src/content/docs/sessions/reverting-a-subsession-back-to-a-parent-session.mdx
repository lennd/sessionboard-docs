❗️Note: Integrations currently do not support subsessions.
1.  Within the Sessions module, select the pencil icon to access the parent session of the subsession you wish to revert back. ​

![](/images/kb/081acc04-image-png-Jan-30-2026-08-44-57-9120-PM.png)

2.  Select the "Subsessions" tab on the session page.
3.  Next to the subsession you want to revert, select the ellipsis, and then "Unlink".

![](/images/kb/fe7072db-image-png-Jan-30-2026-08-44-24-0869-PM.png)

4.  A warning message will appear to confirm that you want to convert the select subsession to a session. Select "Unlink".

![](/images/kb/054f56e0-image-png-Jan-30-2026-08-45-20-2661-PM.png)
