The **Session Submission Form** is the first interaction a submitter or speaker has with Sessionboard. It captures information about the session and speaker(s), and once submitted, creates records accessible to admins.

<Note>
Events on the older forms interface cap out at **20 submission forms**. Newer events aren't held to that limit, though 20 distinct intake paths is a sign the routing belongs in [question rules](#use-question-rules) rather than in separate forms.
</Note>

## How to Build a Submission Form
From your **Sessions** module, select the **Forms** button to access the **Session Submission Forms**.

![From your Sessions module, select the Forms button to access the Session Submission Forms](/images/kb/dc06ce4a-image-png-Feb-25-2026-07-59-51-4750-PM.png)

By default, Sessionboard creates an initial submission form that you can customize. Click the ellipsis (⋯) to see additional actions, then select **Edit** to start configuring your form.

![By default, Sessionboard creates an initial submission form that you can customize](/images/kb/5611d521-image-png-Feb-25-2026-08-02-28-4646-PM.png)

Edit the four sections of the submission form: Welcome Screen, Session Information, Speaker Information, and Form Settings.

- **Welcome Screen** - Introduction to the event. This is the first screen a user will see when they access your submission form. Event admins can create a custom welcome message with basic text box functionality.

  ![Welcome Screen - Introduction to the event](/images/kb/532b1b52-image-png-Feb-25-2026-08-13-42-7361-PM.png)

- **Session Information** - Collect information about the submitted session by adding a page title, page description/instructions, and questions to collect data.

  ***Page Heading*** *is* required and can not be deleted from the form.

  ![Page Heading is required and can not be deleted from the form](/images/kb/09205552-image-png-Feb-25-2026-08-14-51-8183-PM.png)

- **Speaker Information** - Collect information for the session's speaker(s) by adding a page title, page description/instructions, as well as questions to collect data.

  ***First Name, Last Name,*** and ***Email*** are required fields that can not be deleted from the form.

    ![First Name, Last Name, and Email are required fields that can not be deleted from the form](/images/kb/a443dbb1-image-png-Feb-25-2026-08-31-18-9649-PM.png)

  - Unique Contact Settings
    - **Allow Users to submit new information for existing contacts:** If enabled, users will be able to submit new information for existing contacts. If disabled, existing contacts will need to log in to the portal to submit any additional information you want to collect.
    - **Notify existing contacts that they have been added to a submission:** If enabled, existing contacts will receive an email notification to log in to the portal to view and update their information. If disabled, existing contacts will not receive any notification upon submission.

- **Form Settings** - The following settings can be applied to your form.

### Deadlines

| Setting | What it does |
| --- | --- |
| **Open Date** | The form won't accept submissions until this date. Leave it empty to open immediately. |
| **Close Date** | Closes the form after this date. New submissions stop, and edits to existing ones are refused. |
| **Send Reminder Email** | Appears once a close date is set. Emails submitters who saved a draft but never completed it, five days and one day before the form closes. |

<Note>
Reminder emails go to **drafts only** — someone who already submitted won't be chased. Edit the wording under **Settings → Email Templates**.

The option is unavailable while conditional deadline rules are set, since there's no single close date to count back from.
</Note>

![The deadline settings, with a close date, reminder email toggle, and the admin notification pickers](/images/kb/7a41d7b4-image-png-Feb-25-2026-08-32-15-1932-PM.png)

### Submission capacity

| Setting | What it does |
| --- | --- |
| **Set Submission Limit** | Limits how many sessions one user may have on this form. This counts saved drafts as well as submitted sessions — at the limit, submitters can resume a draft but can't start a new one. |
| **Allow multiple draft submissions** | Lets one submitter keep more than one draft in progress at a time. |
| **Set Speaker Limit** | The maximum number of speakers on a submission, up to 15. |

<Warning>
The speaker limit is set as high as 15 here, but the public form accepts at most **10** speakers per submission regardless. Setting it higher won't let submitters add an eleventh.
</Warning>

![The submission and speaker limit settings, with the confirmation message editor below them](/images/kb/c25a00d5-image-png-Feb-25-2026-08-32-28-1098-PM.png)

### After submission

| Setting | What it does |
| --- | --- |
| **Confirmation email message** | The message submitters receive by email after a new submission. A link to the speaker portal is added automatically. |
| **Auto-redirect to speaker portal** | Sends the submitter to their portal 10 seconds after the confirmation page. With it off, they click **Continue to portal** themselves. |
| **Customize the success page message** | The message shown on the confirmation page after submitting, and after payment where fees apply. |
| **Notifications** | Which admins are notified when a new submission arrives, and when an existing one is edited. |

<Note>
On newer (v2) forms some of these move: confirmation and notification emails live on their own **Notifications** step, speaker caps are set per role on the **Participant Information** step, and the settings tab adds **Languages** for multi-language submissions.
</Note>

![The success page message editor at the end of the form settings](/images/kb/576317fb-image-png-Feb-25-2026-08-32-38-6915-PM.png)

## Creating, Editing, & Managing Fields

### Creating Fields

<Warning>
**Note**: If your event will use Evaluation Plans, any field names you create will be visible to Evaluators when they review the submitted sessions.
</Warning>

On the **Session Information** and **Speaker Information** pages, event organizers can add system fields or create custom fields to display on the form.

Click the **Add Field** button to view all the fields you can add.

![Click the Add Field button to view all the fields you can add](/images/kb/3eb02470-image-png-Feb-25-2026-08-37-29-2067-PM.png)

The **Select Fields** page displays all standard and previously created custom fields. Click them to add it to your form.

![The Select Fields page displays all standard and previously created custom fields](/images/kb/454e5c5e-image-png-Feb-25-2026-08-38-34-0257-PM.png)

To add a new field, click the **Create New Field** button and follow the prompts to configure it.

![To add a new field, click the Create New Field button and follow the prompts to configure it](/images/kb/cdf240b4-image-png-Feb-25-2026-08-39-09-6851-PM.png)

<Tip>
Two options on the field form decide how far it reaches:

**Field Description** gives your team internal context — what the field is for, or how to fill it in. It is never shown to submitters and exists purely for internal reference.

**Field Level** decides whether the field belongs to one event or to all of them. An **Event Field** is created for and used within a single event. A **Global Field** is created once and reused across every event in the organization, which keeps data consistent and saves setup time.

Field level can't be changed after the field is created, so choose it deliberately.
</Tip>

![The new field form, with the internal field description and the event or global field level choice](/images/kb/8abc562f-image-png-Feb-25-2026-08-40-12-7843-PM.png)

### Editing, & Managing Fields

Once fields have been added to your form, select the ellipses within the Actions column to customize questions, use question rules (i.e., conditional logic), edit a field, or remove a field from your form.

![Once fields have been added to your form](/images/kb/d4ec0d27-image-png-Feb-25-2026-08-43-20-1682-PM.png)

#### Customize Question
Use a **Custom Label** to customize how the field name appears to submitters, or add **Help Text** to provide extra guidance as they complete the field.

![Use a Custom Label to customize how the field name appears to submitters](/images/kb/efe26ab5-image-png-Feb-25-2026-08-46-10-0006-PM.png)

#### Use question rules
Use **question rules** (conditional logic) to create customizable forms that adjust based on the answers that your users provide to various questions. This allows you to use one form to intake multiple different types of sessions.

Question rules can only be used on the following field types:

- Checkbox

- Dropdown

- Number

<Tip>
When using question rules, keep in mind the following:

1. Create and add all fields to your form, then save it before applying question rules.

2. Question rules should be applied to the question that is conditional.

   A **conditional question** is a question that only appears based on the answer to a previous question. For example:

   - **Q1**: "Are you a member?"

   - **Q2** (conditional): “Provide your Member ID” → This only appears if the answer to Q1 is “Yes.”

![Q2 (conditional)](/images/kb/d06f9e02-image-png-Feb-25-2026-08-57-10-7159-PM.png)
</Tip>

## Additional Form Actions 

From the ellipsis menu (⋯) next to a submission form, event organizers can access additional actions:

| Action | What it does |
| --- | --- |
| **Edit** | Customize the form's content, fields, and settings. |
| **View Submissions** | Review all completed submissions for the form. |
| **View Drafts** | See submissions that have been started but not completed. |
| **View Form** | Open the form in a new browser tab. |
| **Copy Link** | Copy the form's public URL to share with submitters. |
| **Duplicate** | Create a copy of the form to reuse or modify for a new purpose. |
| **Delete** | Permanently remove the form from your event. |

<Warning>
Duplicating a form copies the *fields*, not the field definitions. Editing a field on the copy — changing its dropdown values, for example — changes it on every other form that uses the same field.
</Warning>

![The ellipsis menu open beside a submission form, listing the available actions](/images/kb/9b8f9c83-image-png-Feb-25-2026-09-05-18-1801-PM.png)
