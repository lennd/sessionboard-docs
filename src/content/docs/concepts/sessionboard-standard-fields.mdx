Standard fields are the fields every Sessionboard event starts with, before you add any custom ones. Each belongs to one of three types — Contact, Session, or Group — and that type determines which forms, views, and imports it is available in.

Use this page to look up a field's type and where it applies when you are building a submission form, a portal form, or an import template.

## Hiding and renaming standard fields

Standard fields cannot be deleted, but any of them can be **archived** — hidden from forms, pickers, and column pickers for the whole organization from Library > Fields, or for one event from that event's Settings > Fields — and restored later from the **Hidden Fields** tab. Stored values are kept and stay visible read-only on records. The exceptions are session **Title** and **Description** and contact **First name**, **Last name**, and **Email**, which Sessionboard needs and which cannot be archived; their labels can still be edited. The options on the **Annual Revenue** and **Organization Structure** dropdowns can be edited too. See [Archive a field](/faq/how-to-create-and-delete-custom-fields#archive-a-field).
