When creating a form (i.e. Session submission form, intake form, or portal form) you have the ability to add fields to collect information. The data retrieved is then stored in one of three areas:

Below, you will learn the difference between the three fields and where you can retrieve the stored data.

<Note>
Difference between *Text* vs *Text Area* field types

![Difference between Text vs Text Area field types](/images/kb/853b7cb1-image-png-Feb-09-2026-09-58-54-9466-PM.png)

**Text Field:** Text fields have a character limitation of 255. This field type is great when collecting single-word or single-sentence responses.

**Text Area Field**: Text Area fields have a character limitation of 5000. This field type is great when collecting 3 or more sentences within a response.

For both ***Text*** and ***Text*** ***Area*** fields, Admins can provide their limitations within the range listed above.
</Note>

## Session Fields
Session fields are used when creating your session submission form on the page "Session Information". These are fields that relate back to the session such as:

- Title

- Description

- Tags

- Tracks

- Location

![Session fields on the Session Information page of a submission form](/images/kb/03c853c1-image-png-Feb-17-2026-09-33-42-1362-PM.png)

Data from these fields can be retrieved by navigating to the Sessions module. To easily access this information, we recommend creating a [dashboard view](/reporting/dashboard-views) that includes the questions/fields on your session submission form.

## Speaker/Individual Fields
Speaker/Individual fields are used when creating your session submission form (on the page "Speaker Information"), Intake Form (on the page "Contact Information"), or portal form. These are fields that relate back to the speaker contact profile, such as:

- Name

- Email

- Social Media Handles (i.e. Twitter, LinkedIn, Facebook)

- Address

- Bio

- Photo

![Social Media Handles](/images/kb/7c6ec0cf-image-png-Feb-17-2026-09-34-09-3241-PM.png)

Data from these fields can be retrieved by navigating to the Contacts module. We recommend creating a [dashboard view](/reporting/dashboard-views) that includes the questions/fields included on your form(s) to easily access this information.

## Group Fields
Group fields are used when creating your sponsor/exhibitor intake form (on the page "Group Information") or portal form. These are fields that relate back to the group (i.e. sponsor and exhibitor organization) such as:

- Name

- Description

- Address

- Social Media Handles (i.e. Facebook, Instagram, LinkedIn)

- Logo

- Website

![Social Media Handles](/images/kb/d5556c48-image-png-Feb-23-2026-08-37-36-8838-PM.png)

Data from these fields can be retrieved by navigating to either the Sponsor or Exhibitor module. We recommend creating a [dashboard view](/reporting/dashboard-views) that includes the questions/fields included on your form(s) to easily access this information.
