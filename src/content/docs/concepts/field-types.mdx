When you build forms in Sessionboard, data is collected and stored in three distinct areas depending on the field type you select.

## Text vs. text area

| Field type | Character limit | Best for |
| --- | --- | --- |
| **Text** | 255 | Single words or one-sentence responses |
| **Text area** | 5,000 | Longer responses of three or more sentences |

You can customize the character limit within these ranges for both field types.

## Session fields

Capture information about the **session itself** when building session submission forms (under *Session Information*).

- Examples: title, description, tags, tracks, location.
- Data appears in the **Sessions** module.

## Speaker / individual fields

Store **speaker contact profile** data. Used in session submission forms (*Speaker Information*), intake forms (*Contact Information*), and portal forms.

- Examples: name, email, social handles, address, bio, photo.
- Data appears in the **Contacts** module.

## Group fields

Capture **organizational** information. Used on sponsor/exhibitor intake forms (*Group Information*) and portal forms.

- Examples: name, description, address, social handles, logo, website.
- Data appears in the **Sponsors** or **Exhibitors** module.

<Tip>
Create dashboard views that include your form fields in each module so the collected data is easy to find and review.
</Tip>
