The question bank holds questions your organization uses in more than one course. Each question has tags, such as `roi` or `baseline`. A quiz draws from a tag, and each attempt gets its own set.

## Add questions to the bank

There are two ways in:

- **From a quiz you've written.** Under any question, select **Save to question bank**, add tags and select **Save to bank**.
- **In the bank itself.** In the course builder, select **Question bank** above the lesson, then **New question**. Write it as you would in a quiz, add tags and select **Add to bank**.

Tags are lower case. Type one and press Enter; suggestions show the tags already in use and how many questions carry each.

## Find and edit bank questions

![The Question bank panel: search, filter by tags, and bank questions with their tags and Add to this page, Edit and Archive](/images/suites/learning/learning-question-bank.png)

**Question bank** lists every question, newest first. Search by words in the question, or filter to the questions carrying every tag you name. For each question:

- **Add to this page** puts a copy in the lesson or quiz you have open. The copy is yours to change; the bank question stays as it is.
- **Edit** changes the question or its tags.
- **Archive** takes it out of the bank. Courses that already used it keep their copy. **Show archived questions** and **Restore** bring it back.

## Draw questions from the bank

<Steps>
<Step title="Add the block">
On a quiz, type **/** and pick **Questions from the bank**.
</Step>
<Step title="Choose the questions">
Add the tags to draw from, and choose questions tagged **any of these tags** or **all of these tags**.
</Step>
<Step title="Set how many">
Set **Questions per attempt**. Leave **Points each** empty to keep each question's own points, or enter a number to give every drawn question the same points.
</Step>
</Steps>

![Questions from the bank: tag roi, any of these tags, 3 questions per attempt, and the count of matching bank questions](/images/suites/learning/learning-bank-draw.png)

The block says how many bank questions match right now. If fewer match than the quiz draws, it says so, and publishing waits until there are enough.

When you publish, the matching bank questions are copied into the quiz. Each attempt then draws its set for that learner, alongside the quiz's own questions; a retake draws a different set.

<Tip>
A bank question you edit or archive later reaches a course the next time that course is published.
</Tip>

<Note>
Ask can keep the bank for you: "add these five questions to the bank tagged onboarding", "draw three onboarding questions in this quiz". See [Build courses with Ask](/sessionboard-learning/ask#build-and-edit-courses).
</Note>
