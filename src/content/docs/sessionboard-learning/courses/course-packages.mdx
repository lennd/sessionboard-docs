A course you exported from an authoring tool plays inside a lesson. Learners open it on your Learning Site, pick up where they left off, and finishing it completes the lesson like any other step: course completion, credit and certificates follow.

| Standard | Exported from | What Sessionboard reads |
| --- | --- | --- |
| **SCORM 1.2** | Storyline, Rise, Captivate, iSpring, most tools | Completion, pass or fail, score, time, where the learner left off |
| **SCORM 2004** (3rd and 4th edition) | The same tools | Completion and success separately, score, time, the pass mark set in the package |
| **xAPI** (Tin Can) | Storyline, Rise, Adapt | Completed, passed and failed statements about the course, score, time, resume data |
| **cmi5** | Storyline, Rise and xAPI-first tools | The same as xAPI, with the pass mark and "move on" rule from the package |

## Add a package to a lesson

<Steps>
<Step title="Add the block">
In a lesson, type **/** and pick **Course package**.
</Step>
<Step title="Upload the zip">
Drop the course's .zip on the block or select **Choose a zip**. Packages can be up to 500 MB. To reuse a package you've already uploaded, pick it from **Or use one you've uploaded**.
</Step>
<Step title="Wait for it to unpack">
The block says **Unpacking … and checking every file**, then shows the standard, the number of files, the size and the package's pass mark. If anything in the zip isn't served (a readme, a source file), the block lists it under **files aren't served**.
</Step>
<Step title="Choose how it completes">
**Learners must finish this to complete the lesson** is on by default. Under **Finished means**, choose **The package says it's complete** or **The learner passes it**.
</Step>
<Step title="Publish">
Select **Publish**.
</Step>
</Steps>

![A SCORM 1.2 course package block with 3 files and a pass mark of 80%, set so learners must finish it and finishing means the package says it is complete](/images/suites/learning/learning-course-package-block.png)

**Title learners see** is empty unless you type one: learners see the course's own title from the package. **Player height** sets how tall the course is on the page; learners can also open it full screen.

## What learners see

![A lesson on a Learning Site playing a SCORM course inside the page, with the course's status above it](/images/suites/learning/learning-site-course-package.png)

Learners select **Start**, and the course plays inside the lesson. Above it they see where they are: **In progress**, **Completed**, **Passed** with the score, or **Not passed yet**, and the time they've spent. When they come back, **Resume** opens the course where they left it.

A lesson with a package that must be finished says **Completes when you finish the course package** instead of a **Mark as read** button. If finishing means passing, a learner who doesn't pass can open the course again and retake it.

## Security

The course runs in a frame on Sessionboard's content server, never on your Learning Site's own address, so its scripts can't read a learner's sign-in or change the page around it. When a package is uploaded, every file is checked: files that would reach outside the package, links and programs are refused, and the upload is rejected with the reason.

<Tip>
**Preview** in the course builder plays the package without saving any progress, so you can check it before you publish.
</Tip>

<Note>
If the upload fails, the block says why, for example **There is no imsmanifest.xml … at the top of the zip**. Export the course again as SCORM, xAPI or cmi5 (not as a web page) and upload the new zip. A package that failed to unpack can be retried with **Try unpacking again**.
</Note>
