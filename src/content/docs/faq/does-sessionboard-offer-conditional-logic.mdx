Yes. Conditional logic is called **question rules** in Sessionboard. A rule shows or hides a question — or a whole layout block — based on how an earlier question was answered, so one form can take in several kinds of submission.

## Where question rules are available

| Form | Question rules |
| --- | --- |
| Session [submission forms](/sessions/submission-forms#use-question-rules) | Yes |
| [Portal forms](/portals/create-assign-forms) (follow-up forms assigned as tasks) | Yes — on questions and on layout blocks |
| [Awards submission forms](/awards/awards-submission-form) | Yes |
| Sponsor and exhibitor intake forms | No |

## What can trigger a rule

A rule reads the answer to a question that appears **above** the one being shown or hidden. The triggering question must be one of these field types:

- Dropdown (single or multi-select)
- Checkbox
- Number
- Country

If a question has none of these above it, the dialog says *This question has no possible conditions* — drag a dropdown, checkbox, number, or country question higher up the form and reopen the rule.

## Set up a rule

1. Add every question to the form and **Save** before you start writing rules.
2. Hover over a question, open its **⋯** menu, and choose **Use question rules**.
3. You can build the rule from either end of the relationship:
   - **On the later question** — under **Show this field when**, pick the earlier question, choose **is** or **is not**, and tick the answers that should reveal it. For example, *Provide your Member ID* shows when *Are you a member?* is **Yes**.
   - **On the earlier question** — under **This question controls**, click **Add condition**, choose **is** or **is not**, tick the answer, then pick every later question that answer should reveal. For example, *Format is Workshop* shows Duration, Room setup, and Maximum attendees in one step.
4. Click **Save** in the dialog, then save the form.

![The Question Rules dialog for the Format dropdown, with This question controls open to add a condition](/images/kb/question-rules-dialog.png)

A question with no rules is always shown. A question with several rules is shown when any one of them matches.

## Show or hide individual answer options

On a dropdown question, the dialog has a second tab, **Answer option rules**, that hides or shows individual answer options based on earlier answers. Options without rules are always shown. Build a rule once and copy it to other options from the option's menu.

## Rules only show and hide

Question rules never write a value into another field. To set other fields on the same record when an answer is saved — a session room that sets capacity, a contact country that sets the point of contact — use an **Assignment** [Field Rule](/settings/field-rules). Use a **Calculation** Field Rule to write a number from other fields, or a [formula field](/settings/formula-fields) when that number should stay read-only.
