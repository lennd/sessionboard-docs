Yes, conditional logic (referred to as ‘question rules’ in Sessionboard) can be used when creating your session submission form or portal form. Question rules are not available in the sponsor or exhibitor intake forms.

![Does Sessionboard offer conditional logic?](/images/kb/b0dc93f1-image-png-Feb-24-2026-11-11-57-1133-PM.png)

Question rules hide or show questions on a form. They do not set other field values.

To write other fields on the same record when a value is saved — for example a session room that sets capacity, or a contact country that sets point of contact — use an **Assignment** [Field Rule](/settings/field-rules). Use a **Calculation** Field Rule to write a number from other fields, or a [formula field](/settings/formula-fields) when that number should stay read-only.

When using question rules, keep in mind the following:
1. Create and add all fields to your form, then save it before applying question rules.
2. Open **Use question rules** on the later question to set when it appears, or on the earlier question to choose every later field that answer should show.
3. A conditional question only appears based on the answer to a previous question. For example:
   - **Q1:** "Are you a member?"
   - Q2 (conditional): “Provide your Member ID” → This only appears if the answer to Q1 is “Yes.” You can also open Q1 and, under **This question controls**, check Member ID when the answer is Yes.
