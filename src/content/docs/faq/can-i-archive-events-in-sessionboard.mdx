Events are not archived in Sessionboard. Every event you create stays in your organization — past, current or future — so that last year's speakers, sessions and forms remain there to report on, clone and search.

## Keeping the events list tidy

On the organization's **Events** page:

- **Filter** narrows the list to **Upcoming**, **Past** or **Synced** events. Past events leave the Upcoming view automatically once their end date passes; nothing needs to be done to them.
- The search box finds an event by name.

## Why past events stay

- Contact history and the [New/Returning badge](/faq/what-does-the-new-returning-badge-on-a-contacts-profile-indicate) are built from past events.
- [Cloning an event](/faq/clone-an-event) copies its forms, tasks, templates and settings into next year's.
- Reports and audits can look back across years.

## Deleting an event

If an event was created by mistake, a user with the **Delete Events** organization permission can open the event's menu on the Events page and choose **Delete Event**. The event and everything in it — sessions, contacts, files, forms — is hidden from lists and dashboards rather than erased. Restoring is done by Sessionboard support, so contact [support@sessionboard.com](mailto:support@sessionboard.com) if a deleted event needs to come back.
