Most uploads in Sessionboard accept files up to **5 GB**. The size submitters are *told* on a form, and the size a given uploader will *enforce*, depend on where the file is collected.

## Submission-form file questions

On a session submission form, **Customize Question → Maximum file size** is the size advertised under the field (for example “Images only (up to 2 MB)”). Leave it blank to inherit the field default, up to **5 GB**. Session **Files** settings and [speaker headshot limitations](/events/event-details) do not change that hint.

On **Headshot** and **Logo**, **Help Text** you write is the only line under the field. Other file fields still show the type-and-size hint even when they also have help text.

SVG and HTML files are not accepted on submission-form file questions: the file picker does not offer them, and an upload of either type is rejected.

See [Session submission forms](/sessions/submission-forms).

## Headshots and logos

[Speaker headshot limitations](/events/event-details) and the matching logo controls live in **Settings → Record Settings**. When **Limit file size** is on, the photo editor refuses files over the cap you set (10 KB to 5 GB). When that limit is off, the editor uses the 5 GB platform ceiling.

Those event limits do not rewrite the form hint. A blank **Maximum file size** still reads “up to 5 GB” even if Record Settings has a tighter cap.

## Session Files

Presentations and other session content collected under **Sessions → Settings → Files** use a **1.95 GB** per-file cap. That setting does not apply to file questions on a submission form. See [Enable, upload, & download files](/sessions/enable-upload-download-content).

## File requests and other uploads

File requests and most other content uploads accept files up to **5 GB**. Event admins can set a lower maximum for some of those uploads in **Settings → Record Settings**.

Acceptable file types include Word, Excel, PowerPoint, PDF, image, video, and audio — unless the field or event setting narrows the list.
