title: "What is the maximum file size that Sessionboard supports?"
description: "Sessionboard supports files as large as 1.95GB when utilizing file requests or content upload. Acceptable file types include: - Word - Excel - PowerPo"
---

Sessionboard supports files as large as 1.95GB when utilizing file requests or content upload.

Acceptable file types include:
-  Word
-  Excel
-  PowerPoint
-  PDF
-  Image
-  Video
-  Audio
