There are three ways you can download headshots that have been collected within the standard Headshot field provided by Sessionboard.

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/image-png-Feb-09-2026-10-07-33-6867-PM.png)

### OPTION A: Download Headshot(s) as a Zip File

<Warning>
NOTE❗️: Only 100 headshots can be downloaded at a time. Increase your pagination to show 100 records per page.
</Warning>

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/image-png-Feb-09-2026-10-07-50-4907-PM.png)

1. Within the Speaker/Contacts module, select the speaker/contact whose headshot you'd like to download using the checkbox next to their name.
2.  At the top of your page, select the button More > Download Headshots.
3. A zip file will be downloaded to your device with the contact's first and last name appended in the name of each file.

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/image-png-Feb-09-2026-10-08-26-3332-PM.png)

### OPTION B: Download Individual File
1.  Within the Speakers module, ensure that the field Headshot is visible within your dashboard view.
  1.  👉🏽 Learn how to add the headshot field to your view.
2.  Locate the speaker you would like to download a headshot for, and select the file within the Headshot field. This will open a pop-up window that previews the image uploaded. ​

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/image-png-Feb-09-2026-10-08-58-8078-PM.png)

3.  It'll open the image in a new browser tab to view and download.

### OPTION C: Export Spreadsheet with File URL
1.  Within the Speakers module, ensure that the field Headshot is visible within your dashboard view.
  1.  👉🏽 Learn how to add the headshot field to your view.
2.  Once your dashboard view has been updated, export your view as either a CSV or XLSX file.
  1.  👉🏽 Learn how to export data.

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/image-png-Feb-09-2026-10-10-09-3380-PM.png)

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/Knowledge%20Base%20Import/Screenshot%2B2024-04-10%2Bat%2B11_04_46%E2%80%AFAM-1.png)

The exported file will include the hosted URL link for each file within Sessionboard.
