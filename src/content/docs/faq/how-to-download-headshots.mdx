Headshots collected in the standard **Headshot** field can be downloaded three ways. Pick by how many you need and what you plan to do with them.

| You need | Use |
| --- | --- |
| Every speaker's headshot for the website or programme | **Option A** — a zip, converted to PNG, JPG, or SVG |
| One person's photo | **Option B** — open it from the table |
| A list of image links for a designer or another system | **Option C** — export the table |

## Option A: Download headshots as a zip

1. Open **CRM → Contacts** (or a speaker list) and tick the contacts you want. Filter first if it helps — with a filter applied, tick the header checkbox and use **Select all … matching this filter** to include everyone on every page.
2. In the bar above the table, choose **More → Download Headshots**.

   ![The More menu on the contacts bulk bar with Resize Headshots](/images/kb/headshots-resize-menu.png)

3. Choose an **Export format** — PNG, JPG, or SVG — and click **Download Headshots**. Every image in the zip is converted to that format.

   ![The Download Headshots confirmation with the PNG, JPG and SVG export format choices](/images/kb/headshots-download-dialog.png)

The zip is built in the background and opens as a download when it is ready — it is named `Sessionboard_Headshots_<date>.zip`, and each file inside is named `FirstName_LastName`. Contacts without a headshot are skipped and named in the ready notification; if none of the selected contacts has a photo, the download is refused with *No headshot uploaded*.

Downloading headshots needs the Contacts module's **Export** permission on your role — see [Event team members and roles](/event-team/invite-manage-event-team-members).

<Tip>
Need them all one size? Run **More → Resize Headshots** on the same selection first — see [Recommended headshot size](/faq/what-is-the-recommended-size-for-contact-headshots).
</Tip>

## Option B: Open a single headshot

1. Make sure the **Headshot** column is visible — click **Columns** above the table and turn it on. See [Module table views](/reporting/dashboard-views#columns).
2. Click the file in the contact's **Headshot** cell. The image opens in a new browser tab, where you can save it.

## Option C: Export a spreadsheet of image links

1. Add the **Headshot** column to your view as above.
2. Click **Options** in the top-right corner and choose **Export .CSV** or **Export .XLSX**. See [Exporting data](/reporting/exporting-data).

The export contains a publicly hosted link for each headshot rather than the image itself. Use Option A when you need the files.
