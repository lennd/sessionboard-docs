### Resize Headshots (set dimensions)

<Note>
Smaller images won’t be enlarged—only larger files are reduced.
1.  Within the Contacts module, use the checkboxes next to each contact’s name to select the individuals whose headshots you want to resize.
</Note>

![Bulk resize headshot photos: Resize Headshots](/images/kb/7f88db07-image-png-Feb-09-2026-09-49-35-8124-PM.png)

2.  More → Resize Headshots

![Bulk resize headshot photos: Resize Headshots (2)](/images/kb/0ddb6de7-image-png-Feb-09-2026-09-49-54-1228-PM.png)

3.  Enter new dimensions to resize the selected headshots. You can specify both height and width, or just one value to scale proportionally. (Optional) Set a target filesize (KB).

![Bulk resize headshot photos: Resize Headshots (3)](/images/kb/f4689ed2-image-png-Feb-17-2026-06-55-37-1371-PM.png)
