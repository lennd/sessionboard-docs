## Create a field
<Note>
Once a field has been saved, the Field Type cannot be edited. To make changes to the field type, you will need to delete the field and create a new one.
1. Within the Library > Fields module, select the appropriate field type at the top of the page based on the type of field you want to create: Contact, Group, Session, or Evaluation Plan.
</Note>

![Create A Field](/images/kb/286008dd-image-png-Jan-30-2026-07-50-10-7164-PM.png)

2. Click the + Add Field button in the top-right corner.

   ![Click the + Add Field button in the top-right corner](/images/kb/37280833-image-png-Jan-30-2026-07-54-13-1332-PM.png)

3. Within the pop-up modal, define the details of your new field by adding a field name and selecting the field type (i.e. dropdown, file, text, checkbox, or formula) from the dropdown menu. A **Formula** field calculates a number from other fields on the same record. You cannot save it until the expression is valid. See [Create a formula field](/settings/formula-fields) for the builder, the **Write** editor, and the limits. To format text, calculate into an editable field, or set fields when values match, see [Create a field rule](/settings/field-rules).

   ![Within the pop-up modal](/images/kb/9dcbf5ab-image-png-Jan-30-2026-07-55-33-9500-PM.png)

4. Once you’ve completed all the details, click ‘Save Changes’ to add your new field. The custom field will now appear in the list of fields under the selected category and is ready to use. ​

<Tip>
Tip: Create custom fields to track review status, priority, or other admin-only details.
</Tip>

## Delete a field
To delete a field once created, navigate to the Library > Fields module and search for the field you would like to delete.

<Note>
Ensure you are searching for the field within the correct page (i.e. Contacts vs Groups vs Sessions vs Evaluation Plan)
</Note>

![Delete A Field](/images/kb/d96cc2e0-image-png-Jan-30-2026-07-56-34-8689-PM.png)

Open the field first. If it is used in a formula or a Field Rule, the sidebar shows **Used in formulas** and **Field Rules**. Replace that field in those expressions or rules before you delete it. After you delete a source, the last stored result stays on the record and the math does not run again until you fix the expression.

Once the custom field has been located, select Delete within the Actions column.

![Once the custom field has been located, select Delete within the Actions column](/images/kb/0909a755-image-png-Jan-30-2026-07-57-22-7392-PM.png)
