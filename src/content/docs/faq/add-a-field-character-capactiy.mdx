A character limit keeps a session title short enough for the agenda, or a biography inside the program book's word budget. Set it on the field itself and every form, portal and table that uses the field enforces it.

1. Open **Organization Settings → Library → Fields** to change the field for every event, or the event's **Settings → Fields** for this event only.
2. Pick the tab for the record the field belongs to — **Contact**, **Group** or **Session** (**Submission** inside an event) — and find the field. The list shows each field's current cap, for example *Text • 255 char max*.
3. Open the row's **⋯** menu and select **Edit**.
4. Enter the new cap in **Maximum Length** and select **Save Changes**.

![The Edit Session Field sidebar for Title with the Maximum Length input](/images/kb/field-max-length.png)

## Limits by field type

| Field type | Maximum Length |
| --- | --- |
| Text, Email | Up to 255 characters |
| URL | Up to 2,048 characters |
| Text Area | Default 5,000 characters |
| Rich Text | Default 5,000; configurable up to 50,000 |

Number, date, dropdown and other non-text types have no length setting.

## System fields

System fields such as the session **Title** and **Description** or the contact **Biography** accept a **Maximum Length** too. Inside an event, the sidebar asks where the change applies — **This event only** (the default) or **All events (organization)**, which needs organization access. Editing from Library → Fields always changes the shared definition.

Three contact fields — **First name**, **Last name** and **Email** — can be renamed but their settings are locked.

## A limit for one form only

To cap an answer on a single submission form without changing the field — a 100-word abstract on this year's call, say — open the question in the form builder and use **Customize question → Length Limit**, which counts in characters or words and cannot exceed the field's own maximum. See [Submission forms](/sessions/submission-forms#customize-question).
