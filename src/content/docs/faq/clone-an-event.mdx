Yes, events can be cloned in Sessionboard!

If you need to clone an event, simply reach out to our support team at support@sessionboard.com with the following details:
- Name of the new event
- Dates of the new event

Once your request is submitted, our team will handle the cloning process for you.

## What Aspects of the Event Can Be Cloned?

When your event is cloned, the following elements can be duplicated upon request:
- Contacts: Contact records will not appear duplicated within your CRM, as they will be referenced from the organization.
- Sponsors: This will add the sponsors from the original event into your cloned one.
- Exhibitors: This will add the exhibitors from the original event into your cloned one.
- Views: This copies saved views of your contacts and sessions. Note that if you do not copy contacts or sessions, you may be missing custom fields used to create those views.
- Session Submission Forms: This copies the form questions, but not the results/submissions.
- Sessions: Copies sessions with related speakers, tags, tracks, locations, etc. Note that you must reset start and end times to match your new event dates
- Session Settings (i.e. Rooms, tracks, tags, format, level, languages): These must be enabled to copy as expected on sessions.
- Evaluation Plans: Note that evaluation plans are set as closed. You must review the setup and set a new due date to open these in the new event.
- Custom Portals: Note if these are based on custom fields, you may need to reset them in the event.
- Event Team: Copies all event non-portal users (admins, evaluators, etc.)
- Email Templates: Email templates created within the original event will be cloned to the new event.
- Tasks: Copies all tasks into the new event
- Forms: Copies all portal forms into the new event
- File Requests: Copies all file requests into the new event
- Shared Files: Copies all files uploaded into the new event
- Resources (Wiki Pages): Copies all wiki pages into the new event
- Reports: Copies all custom reports
- Applications: Copies all of your application forms
 This ensures you retain all the key components and settings from your original event, saving you significant time and effort.

## Benefits of Cloning an Event

Cloning an event provides several advantages, including:
- Time-saving: Avoid manually recreating the structure and settings of your event.
- Consistency: Ensure branding, templates, and configurations are consistent across multiple events.
- Efficiency: Quickly adapt the cloned event to new dates and details, streamlining the planning process.

If you’re planning a similar event or need to replicate an existing setup, cloning is a quick and effective solution. Contact us today to get started!
