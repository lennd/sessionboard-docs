If you email support@sessionboard.com or use live chat. Share the info below.

### Every ticket

| Tell us | Example |
| --- | --- |
| Event name | Acme Tech Summit 2026 |
| Link to the page | https://appv2.sessionboard.com/events/123/sessions |
| Screenshot or short video | Image attached or Loom link |
| What's happening? Any error? | "Something went wrong. Please try again." |
| Steps you took | 1. Select contact 2. Send Email |
| What you expected | Sending an email |
| What actually happened | No email went out |
| When it happened | Today, 9:15 am ET |
| Browser and device | Chrome on Mac |

### If it is an integration issue

Integrations include ASP, Bizzabo, Cvent, ExpoPlatform, Gleanin, Grip, Snöball, Stova, Swapcard, Swoogo & Zapier. Add these on top of the already mentioned:

| Tell us | Example |
| --- | --- |
| Which integration | Cvent |
| When it last worked | April 1st, 4:00 PM ET |
| Affected records | speaker@email.com, Session ID 789 |
| Error messages | Screenshot of History sync error |

That is it. The more boxes you fill, the faster you get back to your event!
