Tracking who has completed tasks in the Event Portal can be done directly within the Contacts, Sponsor/Exhibitor, or Sessions modules, depending on the type of task created:
-  People tasks → Track via the Contacts /Speakers module
-  Group tasks → Track via the Sponsor/Exhibitor module
-  Session tasks → Track via the Sessions module

#### Adding Task Reporting Fields to Your View
1.  Navigate to the appropriate module (Contacts, Sponsor/Exhibitor, or Sessions).
2.  Select Columns.

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/image-png-Feb-09-2026-10-41-33-7095-PM.png)

3.  On the Columns tab, select the checkbox next to any reporting fields you want to add to your view & Apply Changes.

![](https://657654.fs1.hubspotusercontent-na1.net/hubfs/657654/image-png-Feb-09-2026-10-44-14-1674-PM.png)

| --- | --- |
| Green Check Mark | Task is complete |
| Yellow Clock | File Request pending approval (new submissions AND declined submissions) |
| Orange Checklist | Task assigned manually (not completed) |
| Blue Circle | Task assigned via portal (not completed) |
| Grey Plus Sign | Task not assigned |

#### Filtering by Task Status

You can create filters to quickly find contacts, groups, or sessions based on task completion status. Examples include:
-  Showing only those who have not completed a task.
-  Showing only those who have completed a task.
