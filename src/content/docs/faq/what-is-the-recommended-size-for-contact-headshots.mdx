import { Note } from '@compat';

We recommend speaker headshots be 300 x 300 px (square image).

<Note>
Sessionboard supports files up to 2GB; however, certain third-party applications may have their own parameters around speaker photos, including the following:
-  Swoogo: 1MB
-  Cvent: 2MB
</Note>
