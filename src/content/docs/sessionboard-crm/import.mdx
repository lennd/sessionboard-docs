## Add one at a time

Add a person on **People**, or a company on **Companies**. See [People](/sessionboard-crm/people#add-a-person) and [Companies](/sessionboard-crm/companies#add-a-company).

## Import a spreadsheet

If your people or companies are already in a spreadsheet, import them from **Import**. Every import shows you what will happen before anything is saved.

<Steps>
<Step title="Choose what you're importing">
People or companies. Not sure how to lay out the file? Download the sample and start from that.
</Step>
<Step title="Choose a file">
Choose a CSV or Excel file.
</Step>
<Step title="Match your columns">
Sessionboard CRM matches each column by its header. Check each match and change any that's wrong, or leave a column out.
</Step>
<Step title="Check the preview">
Nothing is saved yet. You see how many rows are new, how many are already here, which rows are invalid and why (with the line number), and rows that appear more than once in the file. Choose whether records already here get the details your file fills in, or stay as they are.
</Step>
<Step title="Import">
Start the import. The summary says how many were added, updated and skipped, and lists each invalid row with its reason.
</Step>
</Steps>

### What a people file can bring

| Column | Notes |
| --- | --- |
| Email | Needed on every row. Rows are matched by email, so importing the same file twice makes no duplicates. |
| First name, last name | Or one full-name column. |
| Job title | |
| Company | A company's name. It's found in **Companies**, or added, and the person is linked to it. |
| Tags | Speaker, member, customer, prospect, influencer or attendee. |

### What a companies file can bring

| Column | Notes |
| --- | --- |
| Name | Needed on every row. Rows are matched by name. |
| Website | |
| Tags | Sponsor, exhibitor or both. |

<Note>
Importing emails no one. A person you import counts as an active contact only once you reach them (see [Active contacts](/sessionboard-crm/plan-and-billing/active-contacts)), so importing your whole list costs nothing by itself.
</Note>

## Bring people in from another system

To read people from a connected CRM, AMS or event platform, use **Connections** instead of exporting a file. See [Find people in your CRM, AMS or event system](/sessionboard-crm/connections/find-people).

Systems Sessionboard CRM doesn't read directly come in as a spreadsheet:

| From | How |
| --- | --- |
| Sessionize | In Sessionize, go to **Speakers**, then **Export**, and choose Excel. Import that file here as people: its columns match automatically. |
| Airtable | Open the view with your people and download it as CSV, then import it here. |
| Fonteva, Nimble AMS, Swapcard | Export your people to a spreadsheet, then import it here. |
