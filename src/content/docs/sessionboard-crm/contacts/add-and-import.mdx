## Add one contact

On **Contacts**, add a contact with their first name and email, and if you like their last name, company, job title, types, tags and a first note. An email already in CRM isn't added twice: Sessionboard CRM tells you which contact has it. Adding a contact emails no one.

## Import a spreadsheet

If your people are already in a spreadsheet, import them from **Import**. Every import shows you what will happen before anything is saved.

<Steps>
<Step title="Choose a file">
Choose a CSV or Excel file. Not sure how to lay it out? Download the sample file and start from that.
</Step>
<Step title="Match your columns">
Sessionboard CRM matches each column to a contact field by its header: email, first name, last name, full name, company, job title, types and tags. Email is the only column you need. Check each match and change any that's wrong, or leave a column out.
</Step>
<Step title="Choose types and tags for everyone">
Optionally pick types and tags to give every contact in the file, for example **Speaker** and a tag for this year's event.
</Step>
<Step title="Check the preview">
Nothing is saved yet. You see how many contacts are new, how many are already in CRM, which rows are invalid and why (with the line number), and emails that appear more than once in the file. Choose whether contacts already in CRM get the details your file fills in, or stay as they are.
</Step>
<Step title="Import">
Start the import. The summary says how many contacts were added, updated and skipped, and lists each invalid row with its reason.
</Step>
</Steps>

### What a file can bring

| Column | Notes |
| --- | --- |
| Email | Needed on every row. Rows are matched to contacts by email, so importing the same file twice makes no duplicates. |
| First name, last name | Or one full-name column. |
| Company, job title | |
| Types | Speaker, SME, influencer, exhibitor or sponsor. |
| Tags | Tag names. |

<Note>
Importing emails no one. A contact you import counts as active only once you reach them (see [Active contacts](/sessionboard-crm/plan-and-billing/active-contacts)), so importing your whole list costs nothing by itself.
</Note>

## Bring people in from another system

To read people from a connected CRM, AMS or event platform, use **Connections** instead of exporting a file. See [Find people in your CRM, AMS or event system](/sessionboard-crm/connections/find-people).

Systems Sessionboard CRM doesn't read directly come in as a spreadsheet:

| From | How |
| --- | --- |
| Sessionize | In Sessionize, go to **Speakers**, then **Export**, and choose Excel. Import that file here: its columns match automatically. |
| Airtable | Open the view with your people and download it as CSV, then import it here. |
| Fonteva, Nimble AMS, Swapcard | Export your people to a spreadsheet, then import it here. |
