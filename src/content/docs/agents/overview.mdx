## Autonomy & trust

Agents operate at supervised autonomy levels — they propose and act within scope, but you stay in control:

- **Activity logging** — every agent action appears in the relevant record's Activity feed, distinct from **User**, **System**, and **Rule** events.
- **Scoped access** — agents inherit token scopes and PII settings; see [API tokens](/integrations/api-tokens).
- **Reversible** — agent changes are auditable in [History](/communications/email-sms-history) and can be rolled back.
- **Run history** — the Coordinator keeps a record of each pass it makes over your participants, including how many it did not reach. See [Check Coordinator run history](/agents/coordinator-run-history).

## Connect your own AI assistant
Any MCP-compatible assistant (Claude, ChatGPT, Copilot, Gemini, Cursor) can act as an agent against your event data via the Sessionboard MCP server. See [Connect AI assistants to Sessionboard](/integrations/connect-ai-assistants).

<Info>
The **Agents** tab is in every event's sidebar. Team Lead is always on for every organization and every event — it is the guide to the product, and its card has no switch. Open it from **Ask** on any page to see [where you are and what is set up there](/agents/team-lead). The other agents are turned on from that tab; if one shows as locked, ask your account manager about AI access. Team Lead also has a shortcut row on the [Event Dashboard](/events/event-dashboard).
</Info>
