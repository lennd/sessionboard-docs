Connect ON24 once and run your webinars from **Program → Webinars**: Sessionboard creates the webcast in ON24, registers people, and after it ends brings back who attended and everything they did, from poll answers and questions to the resources they opened, plus the recording. See [Run webinars from Sessionboard](/webinars/overview) for the webinar side. The same connection can also [import past ON24 events into Speaker CRM](#import-past-on24-events-into-speaker-crm).

<Note>
Any organization can connect ON24. Creating and running webinars in Sessionboard is included with **CRM**: if you cannot create one, ask your Customer Success Manager about adding CRM.
</Note>

## Why use it

ON24 reports more about each attendee than most webinar platforms: engagement score, chat, questions, reactions, call-to-action clicks and the resources they downloaded. Connected to Sessionboard, all of it lands on the same contact record as the rest of your program, feeds Pathways, and shapes each attendee's recap.

## What syncs

| | ON24 |
| --- | --- |
| Create and update the webcast in ON24 | Yes. Title, time zone, start and length; the description is set when the webcast is created |
| Speakers | No. Add them in ON24 Presentation Manager (**Open in ON24**) |
| Registrants to ON24 | Yes. ON24 has no personal join link: everyone gets the webcast's audience link and signs in with their email |
| Registrants from ON24 | Yes |
| Attendance and minutes | Yes, live attendance, plus ON24's engagement score and live and on-demand minutes |
| Poll answers, Q&A (with answers), group chat, reactions | Yes |
| CTA clicks | Yes, including meeting, demo, free-trial and contact-us widgets |
| Survey answers as feedback | Yes |
| Resources viewed | Yes, recorded as content the attendee opened |
| Ratings | No, ON24 reports no per-attendee rating |
| Recordings into Media | Yes, the webcast's archive MP4. **Media → Discover** also lists archived webcasts from about the last three years |

## Before you connect

You need an ON24 API access token from ON24 Elite: go to **Analytics → API Dashboard → Provision a New API Access Token**. It shows the Client ID, Access Token Key and Access Token Secret. One token covers webinars, registrants, attendance, engagement and recordings.

## Connect ON24

<Steps>
<Step title="Open the app">
Open **Apps** in the organization sidebar, go to the **Webinars** category and click **ON24**.
</Step>
<Step title="Enter the token">
Pick your **Data center** (**North America** or **Europe**), turn on **Include sub-accounts** if you need them, and enter the **ON24 Client ID**, **Access Token Key** and **Access Token Secret**. Click **Connect**.
</Step>
<Step title="Pick webinars">
Import ON24 webcasts from **Import from Zoom / Goldcast** on the Webinars page, or create new ones and choose ON24 as the provider.
</Step>
</Steps>

If your organization already used the ON24 import below, you do not need to connect again: the saved credentials are used the first time a webinar needs ON24.

## How it stays in sync

ON24's API sends no notifications, so Sessionboard checks every published webinar every 15 minutes, from 90 days before it starts until two days after it ends. Click **Sync now** on the webinar to check right away.

## Limits

- **Start time**: ON24 refuses to move a webcast within two hours of its start.
- **Length**: ON24 books webcasts in 15- or 30-minute slots, so a 50-minute webinar in a 60-minute ON24 slot is not reported as a change.
- **Import list**: upcoming and past webcasts from the next and last 180 days.
- **Transcripts**: Sessionboard transcribes the recording itself rather than using ON24's transcript.
- **People who joined without registering** are added to the webinar as checked-in registrants when ON24 reports their email address.

## Troubleshooting

- **Sign-in expired**: ON24 rejected the access token, usually because it was revoked. Provision a new token in ON24 and enter it in the ON24 app in **Apps**.
- **ON24's API cannot invite presenters**: publishing marks the speaker step as still to do. Add your speakers in ON24 Presentation Manager (**Open in ON24**).
- **ON24 did not return the new event id**: check ON24 for the webcast before you publish again.
- **Chat or engagement not available from ON24**: ON24 refused that report for this webcast. It comes back on the next sync once ON24 allows it.

## Import past ON24 events into Speaker CRM

This one-time import brings past ON24 webinars and their speakers into Speaker CRM, each webinar as a session in a synced event.

### Set up the import

#### 1. Navigate to your organization page
- Go to your Organization page in Sessionboard.
- In the top navigation bar, click Import Events.

![1. Navigate to your organization page](/images/kb/bf94dbcb-Screenshot-2025-07-15-at-4.09.56-PM.png)

#### 2. Choose ON24 as your integration source
- Select ON24 from the list of available platforms to import Webinars(sessions in Sessionboard) and Speakers

![2. Choose ON24 as your integration source](/images/kb/4cd33f9e-Screenshot-2025-07-15-at-4.10.35-PM.png)

<Note>
If you use a different webinar platform, reach out to Sessionboard Support for custom import options.
</Note>

#### 3. Gather Your ON24 API Credentials

To connect ON24, you will need:
- Client ID
- Access Token Secret
- Access Token Key

<Tip>
These credentials are available within your ON24 account’s API section. If you’re unsure where to find them, contact your ON24 account manager.
</Tip>

#### 4. Connect your ON24 account
Click Add New Connection.

![4. Connect your ON24 account](/images/kb/6d7279eb-Screenshot-2025-07-15-at-4.11.52-PM.png)

- Enter your ON24 Access Token Key, Access Token Secret, and Client ID.

  ![4. Connect your ON24 account](/images/kb/d1b4a180-Screenshot-2025-07-15-at-4.12.56-PM.png)

- Click Connect.

---

#### 5. Select events to import
- After connecting, you will see a list of your ON24 webinars.
- Select the events you wish to sync to Sessionboard.
- If you want to connect an ON24 event to an existing Sessionboard event, click the mapping option below the event name.
  - This will add any speakers in ON24 that are not already in Sessionboard to your event.
- Click Next to proceed.

![5. Select events to import](/images/kb/d8513077-Screenshot-2025-07-15-at-4.15.43-PM.png)

#### 6. Data Sync Progress
- A progress bar will display the sync status.

You’ll see:
- Number of Events Synced
- Number of Speakers Imported
- Time Duration of Sync

![6. Data Sync Progress](/images/kb/9c0f90b5-Screenshot-2025-07-15-at-4.16.46-PM.png)

<Note>
Large imports (hundreds of events) may take longer. Please allow time for the sync to complete.
</Note>

### What Happens After Import

#### Review synced data in Sessionboard
- Imported ON24 webinars will appear under the Synced tab in your Sessionboard account.
- Key details available include:
  - Event Name
  - Event Date & Time
  - ON24 Source Indicator (a special icon signifies ON24 imports)

![Review synced data in Sessionboard](/images/kb/4acce385-Screenshot-2025-07-15-at-4.17.20-PM.png)

#### How ON24 Data Appears in Sessionboard
- Each ON24 webinar becomes a Session within a Synced Event in Sessionboard.
- Each ON24 speaker has a Contact Profile created in your CRM with the history of the sessions that have spoke at.

#### Viewing and managing synced data
- Synced Events:
  - Read-Only Mode: You cannot edit event details, add speakers, or modify sessions within ON24-imported events.
- Speaker Profiles:
  - First Name, Last Name, and Email will sync to Sessionboard from ON24
  - Full Edit Access: You can enrich speaker profiles by:
    - Adding Speakers to existing events/sessions you are managing in Sessionboard
    - Updating speaker attributes
    - Editing core information

#### Managing existing connections
- If needed, you can allows delete an existing connection and remove the integration.

  ![blurred-image](/images/kb/779d0fc5-blurred-image.png)

- The sync to Sessionboard is a one time sync. If you wish to resync an event, please repeat the process and select the event you wish to update/resync.

---

One-Way Sync: ON24 data imports into Sessionboard, but changes in Sessionboard do not sync back to ON24.
