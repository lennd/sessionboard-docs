Brella is an event networking and content platform. Connect Sessionboard to Brella once, map each Sessionboard event to a Brella event, and Sessionboard pushes speakers and content timeslots. Turn on **Enable Continuous Sync** if you want Sessionboard to keep them aligned about every 30 minutes.

The API token and organization ID are saved on the connection. Each Sessionboard event maps to one Brella event. Sessionboard updates the same speaker or timeslot on the next sync instead of creating a duplicate.

<Tip>
Before you start, have your Brella API access token, organization ID, and Brella event ID. Confirm the Brella event timezone matches **Settings > Event Details**. Accept the sessions you want in Brella first. Every person you want pushed needs a first name, last name, and email.
</Tip>

## Connect Brella

Brella is set up at the **organization**. Open it from **Settings > Integrations** or from **Apps** (under **Engagement**). Event **Settings > Integrations** no longer lists Brella.

![Brella card in the Apps marketplace Engagement category](/images/kb/apps/apps-directory-engagement.png)

<Steps>
  <Step title="Open Brella">
    Go to organization **Settings > Integrations** and click **Connect** or **Settings** on Brella, or open **Apps** and click **Brella**.
  </Step>
  <Step title="Save the connection">
    On the **Connections** tab, enter a **Name**, the **Brella API Access Token**, and the **Brella Organization ID**. Click **Save connection**.
  </Step>
  <Step title="Map a Sessionboard event">
    Click **Map events** on the connection. Choose the Sessionboard event and enter the **Brella Event ID** — Brella's event ID, not the Sessionboard event ID. Already mapped events are hidden. Click **Save mapping**.
  </Step>
  <Step title="Check timezones and settings">
    Confirm the Brella event timezone matches the Sessionboard event. On **Event Settings**, turn on **Enable Continuous Sync** if you want Sessionboard to push this event to Brella about every 30 minutes. Leave it off to sync only when you click **Sync**. Continuous sync still requires at least one accepted session that has not ended.

    Leave **Unpublish in Brella when un-accepted** on unless you want un-accepted records to stay published.

    **Session roles to sync** defaults to every role on accepted sessions. Uncheck chairs, co-authors, or any custom role that should not become a Brella speaker. Click **Save event settings**.
  </Step>
  <Step title="Map fields">
    Use **Map Speaker Fields** and **Map Session Fields** to choose which Sessionboard fields write to Brella for that mapping. First name, last name, and email are required for speakers. Title, start, and end are required for timeslots. You cannot save until those are mapped.
  </Step>
</Steps>

<Note>
Credentials are encrypted and are not shown again after you save. Leave a secret blank when you edit a connection to keep the current value.
</Note>

## What syncs

Only **accepted** sessions and the people on those sessions sync. Every session role becomes a Brella speaker — speaker, moderator, chairperson, and any custom role.

If the event has **speaker acceptance** on, a speaker is not pushed until they have accepted. Other roles are not gated by acceptance.

A person needs a first name, last name, and email. Anyone missing those is skipped and is not unpublished in Brella.

| Sessionboard | Brella |
| --- | --- |
| Person on an accepted session | Speaker (name, email, company, role, headshot) |
| Accepted session | Content timeslot (title, description, start, end) |
| Person assigned to a session | Speaker attached to that timeslot |

When a session or participant leaves the accepted set, Sessionboard unpublishes the matching Brella record unless you turned **Unpublish in Brella when un-accepted** off. Meetings and RSVPs on that record stay intact because the record is hidden, not removed.

## Field mappings

**Map Speaker Fields** and **Map Session Fields** apply only to the event mapping you have selected. Defaults cover name, email, company, role, headshot, title, description, and times.

Brella needs a first name, last name, and email to create a speaker, and a title, start, and end to create a timeslot. Those rows stay on the mapping and cannot be removed.

## Run a sync

If **Enable Continuous Sync** is on for that mapping, Sessionboard runs a full sync about every 30 minutes while the event has at least one accepted session that has not ended. When the checkbox is off, click **Sync** when you need an update.

To push immediately, click **Sync** on **Map Events**, or use **Sync to Brella** from Agenda, Sessions, or Speakers. **Check drift** on the connection compares Sessionboard to Brella without writing.

**Sync** on **Map Events**, or **Sync to Brella** from Agenda Options with nothing selected, is a full sync — the same accepted set as a scheduled run, including unpublish when **Unpublish in Brella when un-accepted** is on. If you select rows on Sessions or Speakers and click **Sync to Brella**, only those records update. Sessionboard will not unpublish the rest of the event.

## Add or remove a mapping

<Warning>
Do not change the Brella event ID on a live mapping. Sessionboard will treat the records as new and can create duplicates.
</Warning>

Use **Add event mapping** to point another Sessionboard event at another Brella event on the same connection. You can also add a second connection if you have a different Brella organization or token.

To remove a mapping, use the trash control on that row. Previously synced Brella records stay in Brella; Sessionboard stops updating them.

## Still having issues?

Email [support@sessionboard.com](mailto:support@sessionboard.com) and include the connection name, the Brella organization and event ID, and the session or contact that did not sync. Do not send the API token.
