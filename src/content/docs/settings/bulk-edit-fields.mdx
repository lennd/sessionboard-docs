import { Note, Tip } from '@compat';

When one field needs the same value on many records — moving twenty sessions to a track, tagging every sponsor contact, setting a status — edit them in bulk from the module's table instead of opening each record.

<Tip>
Bulk edit offers the fields that are showing as **columns** in your current view. If the field you want is missing from the **Select a field to edit** list, add it to the table first with **Columns** and try again.
</Tip>

1. Open the module — **Sessions**, **Contacts**, **Speakers**, **Sponsors** or **Exhibitors** — and tick the checkbox on each record you want to change. Use **Select all** in the header row to take every record on the page.

2. The toolbar switches to the selection actions. Click **Edit**.

   ![The sessions toolbar with two records selected — 2 selected, Edit, Send Emails, Download Files, Delete, More, Clear](/images/kb/sessions-bulk-bar.png)

3. In the **Bulk Edit** panel, pick the field under **Select a field to edit**, then set its **New Value**. The value control matches the field type — a dropdown for Track or Format, a date picker for Starts At, a multi-select for Tags, and so on.

   ![The Bulk Edit panel — Edit 2 selected records, Select a field to edit set to Track, New Value list of tracks, Cancel and Save](/images/kb/sessions-bulk-edit.png)

4. Click **Save**, then confirm. The confirmation names the field and the record count; **Update Records** applies it. Large selections run in the background and the toolbar reports progress until they finish.

<Note>
Saving with **no value** clears the field on every selected record. Sessionboard warns you first — the confirmation changes to **Confirm Bulk Clear** with a **Clear Field** button — so read it before you click.
</Note>

## Why use it

When you bulk-edit a large number of sessions, the job can take more than a minute. Previously the overlay would close with what looked like an error, leaving you unsure whether the changes were saved. Now the overlay releases after 60 seconds with a clear "still processing" message, polling continues quietly for up to 15 minutes, and the grid refreshes automatically once the job is done — so you can keep working without worrying about the outcome. Tree-type custom fields also now save and render correctly in the session grid, and the SSO email-conflict screen shows a plain-language explanation in your language instead of a cryptic configuration error.

## Things to know

- **Tags are replaced, not added.** Bulk editing Tags sets the selection to exactly the tags you pick, removing any the records had before. To keep existing tags, include them in the new value.
- **Formula fields can't be bulk edited.** They are calculated; edit a source field instead. See [Create a formula field](/settings/formula-fields). Rich-text fields, signatures and other system-managed fields are also left out of the list.
- **Field Rules still run.** Bulk editing a field that is the condition for an **Assignment** [Field Rule](/settings/field-rules) applies that rule to the records you changed.
- **Status permissions apply.** If your role is limited to certain statuses, only those appear when you bulk edit Status — see [Limit which statuses a role can set](/event-team/invite-manage-event-team-members#limit-which-statuses-a-role-can-set).
