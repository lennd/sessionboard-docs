To edit one field within a module (contacts, speakers, session, sponsor, or exhibitor) for multiple records, consider editing in bulk.

<Tip>
Make sure the field you want to apply a bulk edit to has been added to your dashboard via show/hide fields.
1.  Navigate to your module and select all of the contacts/sessions/groups that you would like to make an edit for.
</Tip>

![Bulk edit fields](/images/kb/4e3f12f0-image-png-Feb-24-2026-11-19-31-1655-PM.png)

2.  Click the button "Edit" at the top of your page and select the field you wish to edit within the dropdown menu.

![Click the button "Edit" at the top of your page and select the field you wish to edit within the dropdown menu](/images/kb/4b29b0f1-image-png-Feb-24-2026-11-21-20-9466-PM.png)

3.  Once complete, click the "Save" button at the bottom of the pop-up window.

<Note>
Tags can not be bulk-edited to add new tags to existing ones. When you bulk edit a tag, the existing tag(s) will be removed from a session.
</Note>
