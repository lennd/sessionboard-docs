Criteria are plain-language rules or guidelines that help you manage your program and avoid conflicts, for example "Keynotes never overlap with breakout sessions". You keep them in one list per event, and Sessionboard uses them when it generates draft agendas and when it looks for scheduling conflicts and insights.

## Where to find it

Inside an event, open **Settings > Library > Criteria**. The page has two tabs, each with a count: **Event Criteria** (your list) and **Suggested**.

## Add a criterion

<Steps>

<Step title="Write it">

In the **Add Criteria** bar at the bottom of the **Event Criteria** tab, type the rule under "Enter your criteria...". Be specific and short; the limit is 500 characters.

</Step>

<Step title="Add it">

Click **Add Criteria** (or press Enter). You see "Criteria added" and the new rule joins the end of the list.

</Step>

</Steps>

To bring in existing criteria instead, open the menu on the **Add Criteria** button and choose **Copy from…**, which opens the library import.

## Start from suggestions

Open the **Suggested** tab. Suggested criteria are generated by AI and may not be perfect, so read each one before you use it. Click **Add** beside a suggestion to put it on your list ("Suggested criteria added"). Review the wording afterward with **Edit**.

## Edit, duplicate, reorder or delete

Each criterion shows its number and a short line telling you whether it references fields ("No references" or a count) and how many draft agendas use it. Open the actions menu on a row for:

- **Edit**: opens **Edit Criteria**. Change the text, then set **Usage** and **Context** below, then click **Save Criteria**.
- **Duplicate**: copies the rule so you can adjust the copy.
- **Delete**: asks you to confirm. Deleting cannot be undone.

In **Edit Criteria**:

| Section | What you set |
| --- | --- |
| **Usage** | **Apply this criteria to draft agendas** (pick which draft agendas use it when generating schedules) and **Use this criteria for insights and conflicts** (use it to detect scheduling conflicts and generate insights). |
| **Context** | **Use contact fields for context** and **Use program fields for context**: pick fields that help Sessionboard apply the rule more accurately. |

To reorder, drag a row by its handle (or use the keyboard with the handle focused). Reordering is turned off while a search is active; clear the search box first.

Use the search box ("Search criteria...") on either tab to find a rule.

## FAQ

**What do criteria do?** They guide draft agendas and conflict checks, depending on the **Usage** options you set on each one.

**Are criteria shared across events?** The list on this page belongs to this event. **Copy from…** opens the library import so you can bring existing criteria in.

**Why does a suggestion look wrong?** Suggestions come from AI and may not fit your event. Edit or skip them.
