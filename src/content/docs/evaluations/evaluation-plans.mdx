## Create Evaluation Plans

Within the **Sessions** \> **Evaluation** module, select **Evaluation Plans** at the top of the page:
![Within the Sessions \> Evaluation module, select Evaluation Plans at the top of the page](/images/kb/8ac6e3a8-image-png-Jan-28-2026-08-28-26-2168-PM.png)

To create a plan, click the "**Add Plan**" button to the right of the page:
![To create a plan, click the "Add Plan" button to the right of the page](/images/kb/185110e2-image-png-Jan-28-2026-08-28-50-6045-PM.png)

The builder walks through six steps.

<Steps>
  <Step title="Type">
    Select your evaluation type — **Assign Evaluators**.

    ![The evaluation type step, with Assign Evaluators selected](/images/kb/3219bbe5-image-png-Feb-18-2026-03-41-19-4839-PM.png)
  </Step>
  <Step title="Configuration">
    Define the basic settings that guide evaluators through the review:

    - **Name** — a clear, descriptive title for the plan.
    - **Instructions** — the guidelines evaluators should follow, including criteria, scoring expectations, and any other relevant notes.
    - **Set the plan as open once it has been created** — with this on, you set a due date now. Left off, the plan is created closed and you open it and set a due date later. Closed plans are view-only to evaluators.
    - **Enable Anonymized Review** — removes speaker first and last names from the submission details.
    - **Enable Weekly Reminders** — emails evaluators every Monday while they have sessions left to review.
    - **Include Uploaded Files** — turn this on to let evaluators open the files attached to sessions.

    ![The configuration step, with the plan name, instructions, and open or closed setting](/images/kb/594a4361-image-png-Feb-18-2026-03-43-12-9077-PM.png)
  </Step>
  <Step title="Evaluators">
    Assign Evaluators, Evaluator Session Managers, and Admin Users to the plan.

    <Warning>
    An evaluator must already be added to the event as an Evaluator before they can be assigned here, and the plan must be **closed** to change its evaluators.
    </Warning>

    <Tip>
    Use tags to pull up a segment of users and assign them in one pass rather than picking names individually.
    </Tip>
  </Step>
  <Step title="Session Filters">
    Filter by standard and custom session fields to assign specific submissions to this plan.
  </Step>
  <Step title="Display Fields">
    Choose the session and speaker fields evaluators see while grading.

    You can also create custom evaluation fields, which are shown to evaluators as questions to answer — for example:

    - Would you recommend this session for the event? (dropdown, Yes/No)
    - External comments (text box)
    - Internal comments (text box)
    - Select the core value this session aligns with (dropdown)

    ![The display fields step, choosing which session and speaker fields evaluators see](/images/kb/fdba9642-image-png-Feb-18-2026-03-44-06-9007-PM.png)

    Evaluator fields appear to evaluators as questions to answer.

    ![Custom evaluation fields rendered as questions in the evaluator's view](/images/kb/a2c6dc0c-image-png-Feb-18-2026-03-46-48-9565-PM.png)
  </Step>
  <Step title="Grading Options">
    - **Rating Icon** — the icon evaluators rate with. Faces and numbers rate 1–5; stars and hearts rate 1–20.
    - **Enable Rubric** — lets evaluators rate against criteria you define, each weighted to produce an average cumulative score.
    ![The grading options step, with the rating icon choice and rubric builder](/images/kb/411f1d60-image-png-Feb-18-2026-03-51-53-9616-PM.png)

    Each rubric criterion is limited to 255 characters, and the weights must add up to 100%.

    - **Set Evaluation Limits** — how many times each submission should be evaluated. The ceiling is the number of evaluators on the plan, so four evaluators means at most four reviews per submission.

    ![The evaluation limit setting at the end of grading options](/images/kb/dffc3df6-image-png-Feb-18-2026-03-52-13-7145-PM.png)
  </Step>
</Steps>

<Warning>
Grading options can't be edited after the plan is created. Settle the rating icon and rubric before you save.
</Warning>

## Manage Evaluation Plan Fields

View, create, and manage all evaluation plan fields from the Content \> Fields module. This will allow admins to reuse Evaluation Plan fields on multiple plans without having to duplicate the same questions.

All fields that are created in an Evaluation Plan are saved to the event level and can be accessed from any evaluation plan. New fields that are created within the Fields module are accessible when creating/editing Evaluation Plans.

![All fields that are created in an Evaluation Plan are saved to the event level and can be accessed from any](/images/kb/75137501-image-png-Jan-28-2026-08-29-52-2058-PM.png)

## Open Evaluation Plans

If you have chosen to keep the evaluation plan closed during setup, you can open it at a later day by clicking the ellipse to the right of the evaluation plan and selecting "***Open***".

Opening the plan gives your evaluators access to start grading the submissions. Closed evaluation plans show the submissions in a 'view only' mode.

![Opening the plan gives your evaluators access to start grading the submissions](/images/kb/0f151e7b-image-png-Feb-18-2026-03-53-10-3157-PM.png)

You will be prompted with two options:

1. **Open and notify evaluators**

   1. Evaluators will receive the below email once this button is selected.
        

      ![Evaluators will receive the below email once this button is selected](/images/kb/6206eeba-Screenshot-2023-03-22-at-12_57_04-PM-1.png)

2. **Open and do not send notifications:** If you select this option, you will be required to notify your evaluators that they can begin completing their evaluations.

## Additional Actions
![Open and do not send notifications](/images/kb/f454161b-image-png-Jan-28-2026-08-31-17-7685-PM.png)

- **Review:** Preview evaluator progress and session ratings/feedback
- **Edit**: Edit your plan configurations
  - ****Please note the following:****
    - Plans must be CLOSED to add or remove evaluators (pg. 2)

- - Filters (Pg. 3) cannot be edited once evaluations are added to the plan
  - Rating, rubric settings, and evaluation limits (Pg. 5) cannot be edited once a plan is created.

- **Export Evaluation Plans**: Event admins can export detailed information from graded evaluation plans.

  Choose which version you want to export:

  - **Individual Grades Report** - This provides a breakdown of session grading by the evaluator, including their comments and criteria rankings with weighted scores

  - **Cumulative Grades Report** - This provides a summarized view of grades per session, including data from the session submission and session owner information.

- **Generate a report from the Evaluators tab:** While viewing one plan, open its **Evaluators** tab, then **Options → Generate report**. Give the report a name and click **Generate report**. Sessionboard creates a Custom Report with the same columns as the tab, plus each evaluator's progress and average score per round, one column per evaluator question, and their average score across rounds. If you had typed a search into the tab, the report is narrowed to the same evaluators. Find it under **Reports → Custom reports**, where you can share, schedule, and export it like any other report — see [Custom reports](/reporting/custom-reports#generate-a-report-from-an-evaluation-plan).

- **Delete Evaluation Plans:** Deleting an evaluation plan removes the plan completely from the admin user as well as the evaluators assigned. Deleted plans can not be recovered.

- **Duplicate Evaluation Plans:** Duplicating an evaluation plan will create a copy of the plan you duplicated. All plan settings (i.e. name, instructions, evaluators assigned, rubric, rating icons, and filters) will be cloned with the ability to edit them before the cloned plan is saved.

- **Notify New Evaluators To Grade Submissions:** Choose to either send an invitation email to all evaluators or newly assigned evaluators informing them that they can log into Sessionboard and grade submissions.

  - 👉🏾 [View what this email will look like.](/evaluations/evaluators-how-to-evaluate-sessions)

    ![View what this email will look like](/images/kb/7f25154f-Screenshot-2024-03-14-at-7_14_51-PM-1.png)

## Frequently asked questions

<AccordionGroup>

<Accordion title="Do ratings and comments automatically get sent to speakers?">

No. Ratings and comments are visible only to event admins with access to plan results. To share feedback, copy the results into an [email](/communications/create-send-emails) to the session's speakers.

</Accordion>

<Accordion title="Can evaluators see other evaluators' comments and ratings?">

Not unless you turn on **Show Scores From Other Evaluators** in the plan's additional settings. With it off (the default), each evaluator sees only their own review and only admins with access to results see everything.

</Accordion>

<Accordion title="Can evaluators communicate with session speakers?">

No. Evaluators have view-only access to the submissions assigned to them. See [what access do evaluators have?](/faq/will-evaluators-have-the-same-access-to-my-event-that-i-do-as-an-admin) for the full comparison with admin access.

</Accordion>

<Accordion title="How should we structure our plan — one plan, several plans, or rounds?">

One plan per decision. Use **rounds** inside a plan when the same pool of submissions goes through stages (a first pass, then a committee shortlist): **Funnel** carries only promoted submissions forward, **Parallel** lets rounds run side by side. Use separate plans when different submission types are judged by different committees on different criteria. Scope a plan with submission filters (form, track, format, status) so each plan sees only its submissions. See [round-based evaluations](/evaluations/setting-up-round-based-evaluations#round-mode-funnel-vs-parallel).

</Accordion>

<Accordion title="How do evaluators see only the submissions and fields that concern them?">

Assignments decide *which* submissions each evaluator reviews; **Reviewer View Configuration** decides *what they see* on each one. Hide fields with **Visible Fields to Reviewers**, choose the dropdowns they can filter by with **Filterable Fields for Reviewers**, and turn on **Enable Anonymized Review** to remove speaker names. Evaluators then work from a filtered list in their review portal. See [reviewer view configuration](/evaluations/setting-up-round-based-evaluations#reviewer-view-configuration).

</Accordion>

<Accordion title="How do we add evaluators and assign submissions to them?">

Evaluators must first be users on the event ([invite team members](/event-team/invite-manage-event-team-members)); then select them in the plan's **Evaluators** step and choose which rounds they join. The **Assignments** wizard picks the submissions (all, by filter, or individually), then distributes them **All to All** or to **Individual Reviewers**, with optional caps on **Reviewers per submission** and **Max submissions per evaluator**. Route by track or topic with a submission filter per rule. See [assignments](/evaluations/setting-up-round-based-evaluations#step-4-assignments).

</Accordion>

<Accordion title="What emails do evaluators receive, and can we remind them?">

An invitation when you add them (controlled by **Send invite email to new evaluators**, resendable from the Evaluators tab), an **Evaluation Plan Open Notification** when the plan opens, and **Evaluation Plan Weekly Reminders** for pending sessions when **Enable Weekly Reminders** is on. Wording for each is in [automated emails](/communications/automated-emails). For anything else, [email your evaluators](/faq/evaluators) from the Contacts module, where every event user is listed.

</Accordion>

<Accordion title="Can reviews be blind, and how are conflicts of interest handled?">

**Enable Anonymized Review** hides submitter and participant identity from evaluators. For conflicts, leave **Allow reviewers to abstain** on so a reviewer can step aside from a submission, and turn on **Require a reason when abstaining** with a fixed list of reasons if you need to report how many abstentions were conflicts. See [abstaining](/evaluations/setting-up-round-based-evaluations#abstaining).

</Accordion>

<Accordion title="How do scores turn into accept and decline decisions?">

Read scores in the plan's **Summary** and **Deep-Dive** views, then [update submission statuses](/sessions/accept-decline) from Submissions or the session profile. **Reviewer recommendations** let evaluators mark Accept, Decline, or Alternate alongside scores, and admins can apply those recommendations to statuses in bulk. In a funnel plan, **Promote** moves a submission to the next round; who may promote is a [permission](/event-team/invite-manage-event-team-members#custom-roles). See [applying recommendations to submission statuses](/evaluations/setting-up-round-based-evaluations#applying-recommendations-to-submission-statuses).

</Accordion>

<Accordion title="Can we report on scores, or reuse a plan next year?">

The [Report Builder](/reporting/report-builder) has Evaluation examples and a pre-built **Sessions with Evaluation Ratings** report, and you can group and filter by track, format, or status from there. [Cloning an event](/faq/clone-an-event) copies evaluation plan structure into the new event.

</Accordion>

<IfFeature id="virtual_evaluators">
<Accordion title="Can AI help review submissions?">

AI evaluations score and summarize each submission alongside your human reviewers, so evaluators start from a first pass rather than a blank scorecard. You are emailed when the virtual evaluations for a plan are ready ([automated emails](/communications/automated-emails)).

</Accordion>
</IfFeature>
