## Preview and Beta

Every feature in the catalogue is one of two stages, and the difference decides whether you can help yourself.

| Stage | How you get it |
| --- | --- |
| **Preview** | Toggle it on and off yourself, immediately. |
| **Beta** | Request access. Our team reaches out to set it up with you. |

Beta features usually need configuration, data, or a conversation about fit — which is why they are not a switch. Preview features are self-serve because the worst case is that you turn them back off.

<Tip>
Turning a Preview off is not destructive. Anything you configured is still there if you turn it back on.
</Tip>

## Where to find it

Early Access is the **Preview** row at the bottom of the sidebar, at both levels, and a feature appears at whichever level it applies to:

| Scope | Where | What lives there |
| --- | --- | --- |
| Organization | **Preview** in the organization sidebar | Features that apply across every event — Marketing, Content Galleries, Media Gallery, Requests, Contracts, Learning |
| Event | **Preview** in the event sidebar | Features you enable per event — Content Galleries, Poster Gallery, Surveys, Floor Maps, Event Pipeline |

You need the **Manage Early Access** permission to see the page. Without it, Sessionboard shows a permission message instead. Ask an admin on your team if you need it added.

## Join the program

<Steps>

<Step title="Open Early Access">

Click **Preview** at the bottom of the sidebar. Before you join, the page describes the program, counts the features available, and shows every card with a **Join Early Access to enable** (or **to request**) badge in place of its control. Use **All**, **Org-wide** and **Per-event** to filter the catalogue.

</Step>

<Step title="Join">

Click **Join Early Access**. Joining does not enable anything on its own — it only unlocks the controls on the cards. One opt-in covers the whole organization, and you can **Leave program** later from the same page.

</Step>

<Step title="Turn on a Preview, or request a Beta">

Each feature is a card. Preview cards have a toggle; flip it and the card reads **Active**, or **Active org-wide** for a feature that covers the whole organization. Turning on an org-wide one asks you to confirm first, because it reaches every event.

Beta cards have a **Request access** button instead. Once you have asked, the card reads **On the list — we'll reach out** and the toggle is greyed out until we set it up with you. A counter at the top of the page tracks how many you are **On the waitlist** for.

</Step>

</Steps>

Each card opens a fuller description of what the feature does and what it gives you, so you can decide before switching anything on.

## What is in the catalogue

The exact list changes as features graduate, but at the time of writing:

**Organization**

- **Marketing** (Beta) — the full content marketing module: voices, stories, clips, quotes, posts, and brand kits. The [Marketing overview](/marketing/what-is-sessionboard-marketing), [Advocacy](/marketing/advocacy), [Live Transcribe](/marketing/live-transcribe), [Media](/marketing/media-library), [Create](/marketing/create), and [Slides](/marketing/slides) are already on for everyone — this beta unlocks the rest.
- **Dispatches** (Beta) — your own team sharing event content to LinkedIn.
- **Content Galleries** (Preview) — hosted, searchable galleries of recordings, clips, documents, lessons and the session catalog, for every event. See [Content galleries](/site/content-galleries).
- **Media Gallery** (Beta) — an organization-wide library for recordings and other media, with the **Webinars** row it adds under **Program**.
- **Goldcast / Zoom Webinars / On24** (Beta) — pull webinar recordings and registrations from those platforms into the Media Gallery.
- **Requests** (Beta) — a speaker directory and request pipeline.
- **Contracts / Docusign** (Beta) — contract sending and tracking. See [Send and track contracts](/speaker-crm/contracts).
- **Scouting Reports / Scout Agent** (Beta) — speaker prospecting.
- **Learning (Lessons & Credits)** (Beta) — turn sessions into lessons with continuing-education credit.
- **Portfolios** (Beta)
- **New Navigation** (Preview) — listed for organizations still on the previous sidebar; everyone else already has it.

**Event**

- **Content Galleries** (Preview) — the same galleries for this event only, without turning them on across the organization.
- **Poster Gallery** (Beta) — publish searchable, shareable galleries of session posters, with inline PDF, video, and image viewing. See [Poster galleries](/marketing/poster-gallery).
- **Surveys** (Beta) — during-event scoring of sessions, speakers, and posters. See [Surveys](/evaluations/surveys).
- **Floor Maps** (Beta)
- **Community Marketing** (Beta)
- **Attend** (Beta)
- **Event Pipeline** (Beta)
- **New Navigation** (Beta) — for a single event, where the organization has not switched yet

<Note>
Features leave Early Access when they are ready for everyone. The September 2026 release graduated a whole wave this way — AI Event Agents, Email Campaigns, Automations, Print Agendas, Notifications & Messaging, Live Transcribe, and Advocacy are now on by default for every organization and no longer appear in the catalogue. New Navigation rolled out to every organization at the same time (organizations with an event starting within 30 days of the rollout keep it opt-in until that event wraps).
</Note>

## Things worth knowing

**Some features need another one first.** Dispatches sits inside the Marketing module, so it needs Marketing too; the card tells you so and stays disabled until it is on. Features that use AI need **AI features** switched on for the organization first, and their cards say so.

**Enabling org-wide means every event.** A Preview switched on at the organization level applies to all of its events, not just the one you are looking at. Event-scoped previews are enabled per event from the event list on the card.

**Early Access features move quickly.** They ship on a faster cadence than the rest of Sessionboard, so labels and layouts can shift between releases. Each feature's own article tracks what it does today.
