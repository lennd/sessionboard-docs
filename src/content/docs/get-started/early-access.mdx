Early Access is where Sessionboard puts features that are built and working but not yet switched on for everyone. Joining lets you turn some of them on yourself and put your name down for the rest.

## Preview and Beta

Every feature in the catalogue is one of two stages, and the difference decides whether you can help yourself.

| Stage | How you get it |
| --- | --- |
| **Preview** | Toggle it on and off yourself, immediately. |
| **Beta** | Request access. Our team reaches out to set it up with you. |

Beta features usually need configuration, data, or a conversation about fit — which is why they are not a switch. Preview features are self-serve because the worst case is that you turn them back off.

<Tip>
Turning a Preview off is not destructive. Anything you configured is still there if you turn it back on.
</Tip>

## Where to find it

Early Access exists at two levels, and a feature appears at whichever level it applies to:

| Scope | Where | What lives there |
| --- | --- | --- |
| Organization | **Org → Early Access** | Features that apply across every event — Notifications & Messaging, Marketing, Requests, Contracts, Media Gallery |
| Event | **Event → Early Access** | Features you enable per event — AI Event Agents, Email Campaigns, Print Agendas, Live Transcribe, Poster Gallery |

You need the **Manage Early Access** permission to see the page. Without it, Sessionboard shows a permission message instead. Ask an admin on your team if you need it added.

## Join the program

<Steps>

<Step title="Open Early Access">

Go to **Early Access** from your organization or event settings. Before you join, the page describes the program and lists how many features are available.

</Step>

<Step title="Join">

Joining takes one click and does not enable anything on its own — it only unlocks the catalogue. You can **Leave program** later from the same page.

</Step>

<Step title="Turn on a Preview, or request a Beta">

Each feature is a card. Preview cards have a switch — **Enable org-wide** turns the feature on for your organization and every event in it. Beta cards have a request button instead; you pick the event it is for when the feature is event-scoped, and our team follows up.

Once requested, the card shows **On the waitlist** so you can see what you are queued for.

</Step>

</Steps>

Each card opens a fuller description of what the feature does and what it gives you, so you can decide before switching anything on.

## What is in the catalogue

The exact list changes as features graduate, but at the time of writing:

**Organization**

- **Notifications & Messaging** (Preview) — the notification centre, delivery preferences, and session messages. See [Notifications](/communications/notifications).
- **New Navigation** (Preview) — the redesigned sidebar grouped into Program, CRM, Marketing, CMS, and Attend.
- **Marketing** (Beta) — the content marketing module. See [Marketing](/marketing/what-is-sessionboard-marketing).
- **Dispatches** (Beta) — your own team sharing event content to LinkedIn.
- **Media Gallery** (Beta) — the shared media, clips, and quotes library.
- **Requests** (Beta) — a speaker directory and request pipeline.
- **Contracts / Docusign** (Beta) — contract sending and tracking.
- **Scouting Reports & Scout Agent** (Beta) — speaker prospecting.
- **Portfolios** (Beta)

**Event**

- **AI Event Agents** (Preview) — Team Lead, Coordinator, Editor, Reviewer, and Scheduler. See [Agents](/agents/overview).
- **Email Campaigns** (Preview)
- **Print Agendas** (Preview) — see [Print agendas](/marketing/print-agendas).
- **Live Transcribe** (Beta) — see [Live Transcribe](/marketing/live-transcribe).
- **Poster Gallery** (Beta)
- **Event Pipeline** (Beta)

<Note>
Features leave Early Access when they are ready for everyone. Reports and dashboards graduated this way — they are now on by default for every organization and no longer appear in the catalogue.
</Note>

## Things worth knowing

**Some features need another one first.** AI Event Agents needs AI features enabled for your organization; the card tells you so and stays disabled until they are. Dispatches sits inside the Marketing module, so it needs both.

**Enabling org-wide means every event.** A Preview switched on at the organization level applies to all of its events, not just the one you are looking at. Event-scoped previews are enabled per event from the event list on the card.

**Early Access features can change.** They are in the catalogue precisely because they are still being shaped, so labels and behaviour may move between releases. Anything with a known rough edge is flagged in its own documentation.
