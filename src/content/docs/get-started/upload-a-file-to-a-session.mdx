Speakers add their slides, handouts and recordings to a session from their portal. The upload lives on the session, so your team sees it under **Program → Submissions → Files** the moment it lands.

## Before speakers can upload

File uploads are off until you enable them for the event: **Program → Settings → Files**, then turn on file upload and set the file types, size and count you will accept, and the deadline. See [Enable, upload, & download files](/sessions/enable-upload-download-content#enabling-files).

## From the portal

<Steps>

<Step title="Open the session">

Sign in to the portal and click the session under **My Submissions** on **Home**, or open it from **Tasks**. The session opens in a panel.

</Step>

<Step title="Go to Files">

Pick the **Files** tab. **Upload Files** shows what is accepted — the file types, the maximum size, how many slots remain, and the deadline if you set one.

</Step>

<Step title="Drop the file and confirm">

Drag the file into the box, or click it to choose one. The file is not saved until you click **Confirm Upload**; the panel tells you so with a note beside the file.

</Step>

</Steps>

Uploaded files are listed under **Submission Files** with the upload date. To replace a deck, drop the new file and pick the original in the **Version:** selector before confirming — it is stored as a new version of that file, marked **Latest Version**, and does not use up a slot. When the session is at its file limit, the selector is the only way to upload, and it reads **Select file to revise**.

<Note>
When the panel says **File uploads are not enabled for this submission**, the event has not turned uploads on; when it says uploads **are no longer being accepted**, the deadline has passed. Both are fixed by an admin under **Program → Settings → Files**, and a speaker sees a note when you extend the window.
</Note>

<Tip>
Create a portal task called *Upload your presentation* with a link to this article, so speakers find the instructions where the request is. See [Assign tasks](/portals/assign-tasks).
</Tip>
