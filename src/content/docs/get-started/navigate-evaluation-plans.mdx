An evaluator's view of Sessionboard is small on purpose: the plans they were assigned, the sessions in each, and a score sheet. This is the page to send them.

## Getting in

The invitation email (*[Event Name] Evaluator Invitation*) has a **View Event** button that signs the evaluator in. If they come back later, they sign in at the same address with their email, and land on the same list.

## The plan list

Evaluators see only the plans assigned to them, with each plan's progress. Open a plan to see the sessions in the round — or, when the admin has split the plan into rounds, the current round.

## Reviewing a session

Inside a plan, each session shows its details and, unless the admin has turned on blind review, the speakers. From top to bottom:

1. **Instructions** from the event team.
2. The scoring criteria — selections save as you go.
3. A **Comments** box, when the admin has enabled written feedback.
4. **Abstain**, when enabled, for a conflict of interest — the session is set aside instead of scored.
5. **Save & Next** to move on.

The progress meter fills as sessions are completed. A plan is finished at 100%, and the admin's close date is the deadline.

<Note>
The names the evaluator sees — criteria, rounds, whether comments and abstaining are available — come from the plan's setup. See [Evaluation plans](/evaluations/evaluation-plans) and the evaluator's own step-by-step in [How to evaluate sessions](/evaluations/evaluators-how-to-evaluate-sessions).
</Note>

## For the admin

Track the evaluators' side from the plan's **Evaluators** tab. **Options → Generate report** turns it into a Custom Report — progress and average scores per round, one column per evaluator question, ready to share or schedule. See [Generate a report from an evaluation plan](/reporting/custom-reports#generate-a-report-from-an-evaluation-plan).
