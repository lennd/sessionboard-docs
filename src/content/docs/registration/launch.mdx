**Registration → Settings → Launch** is where you try registration end to end before it opens, then go live without test orders mixed into your numbers.

## Why use it

Before a form opens, someone has to register, pay with a test card and check the emails, the badge and the reports. Those test registrations should not count as real ones. Test mode marks them, and **Go live** removes them in one step.

## Test mode

Turn on **Test mode**. Registrations work as usual and send their emails, but each order is marked as a test order. An order paid through a test-mode gateway is a test order even with test mode off. While test mode is on, the Overview shows a banner.

## Go live

<Steps>
<Step title="Click Go live">
In **Settings → Launch**, click **Go live**. The dialog says how many test orders and registrations there are.
</Step>
<Step title="Choose whether to remove them">
Leave **Remove … test orders** ticked to cancel and remove them: their seats and promo-code uses come back. Payment records are kept.
</Step>
<Step title="Confirm">
Test mode turns off.
</Step>
<Step title="Switch to the live gateway">
If the event charges through a gateway in test mode, its orders are still test orders. In **Registration → Settings → Payments**, choose the live gateway (see [Payments](/registration/payments)), then check the **Payments readiness** panel reads live mode. From then on new orders are real orders.
</Step>
</Steps>

## Attendance goal

Set **Attendance goal** to the number of registrations you are aiming for. The [Overview](/registration/overview#read-the-overview) shows registrations against it.

## Copy registration from another event

**Copy setup from another event** copies everything into this event: settings, registrant types, tickets and add-ons, promo codes and forms (as drafts, with their questions, rules, pages and languages). Questions on the other event's own attendee fields get matching fields here.

<Note>
It only works while this event has no forms or tickets, so it never duplicates anything. To bring over one form, use **Forms → New form → Import from another event**. Workshop fees and Expo booths are not copied — they belong to the other event's sessions and floor plan.
</Note>

You can copy from any event of your organization that you are a member of.
