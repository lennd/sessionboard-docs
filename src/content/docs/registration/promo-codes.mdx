**Registration → Promo codes** lists the codes registrants can type at checkout, what each one takes off, and how often it has been used.

## Why use it

Promo codes let partners, chapters and early supporters get a discount without a separate ticket for each of them. Use one when a sponsor gives its clients a discount, when you run a time-limited offer, or when you hand out a few complimentary passes — and see exactly how many registrations each code brought in.

## Create a code

Click **New code** and set:

- **Code** — what registrants type, for example `EARLYRES`. Codes are not case-sensitive.
- **Type** — **Percent off**, **Amount off** or **Complimentary**, and the **Percent** or **Amount**.
- **Total uses** — leave blank for unlimited.
- **Valid from** / **Valid until** — leave blank for no limit.
- **Applies to** — tick the tickets it discounts. Leave all unticked to apply to every ticket.

Click **Create code**.

![The New promo code dialog with code, type, value, total uses, valid dates and the tickets it applies to](/images/kb/registration-new-promo-code.png)

The table shows each code's discount, the tickets it applies to, **Uses** against the limit and the dates it is valid. A code past its dates or out of uses is marked **inactive**.

![The Promo codes table with the code EARLYRES at 15% off, its uses and valid dates](/images/kb/registration-promo-codes.png)

## Share a code

Registrants type the code at the **Payment** step under **Promo code (optional)** and click **Apply**. To apply it for them, add `?promo=CODE` to the registration page link.

Deleting a code stops new orders using it. Orders that already used it keep their discount.

<Tip>
For invitations that should work only for one named person, use a pass from [Sales & invitations](/registration/sales-and-invitations) instead of a shared code.
</Tip>
