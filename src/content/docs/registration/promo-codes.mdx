**Registration → Promo codes** lists the codes registrants can type at checkout, what each one takes off, and how often it has been used.

## Why use it

Promo codes let partners, chapters and early supporters get a discount without a separate ticket for each of them. Use one when a sponsor gives its clients a discount, when you run a time-limited offer, or when you hand out a few complimentary passes — and see exactly how many registrations each code brought in.

## Create a code

Click **New code** and set:

- **What the code does** — **Discount** takes money off; **Access code** only unlocks hidden or code-only tickets; **Coupon** is an amount off that each person can use once.
- **Code** — what registrants type, for example `EARLYRES`. Codes are not case-sensitive.
- **Discount** — **Percent off**, **Amount off** or **Complimentary**, and the **Percent** or **Amount**.
- **Total uses** — leave blank for unlimited.
- **Valid from** / **Valid until** — leave blank for no limit.
- **Group size tiers** — bigger groups get more off: for example 10% from 5 seats, 15% from 10. Below the first tier the code does not apply.
- **Apply automatically** — no code to type: the best automatic discount the cart qualifies for applies on its own. It never stacks with a code the registrant typed.
- **Unlocks** — the hidden and code-only tickets the code reveals on the form.
- **Fee groups** — only fees in these groups. Set a fee's group on the ticket. See [Tickets & pricing](/registration/tickets-and-pricing).
- **Applies to** — tick the tickets it discounts. Leave all unticked to apply to every ticket.

Click **Create code**.

The table shows each code's discount, the tickets it applies to, **Uses** against the limit and the dates it is valid. A code past its dates or out of uses is marked **inactive**.

## One code box for every code

Registrants type any code in the same box. When some tickets wait for a code, the form asks **Have a code?** before they choose a ticket; the code opens the tickets it unlocks (a ticket's own access code works too) and any discount it carries applies at payment. A code-only ticket cannot be bought without its code; staff can still sell it.

## Share a code

Registrants type the code at the **Payment** step under **Promo code (optional)** and click **Apply**. To apply it for them, add `?promo=CODE` to the registration page link. If a code cannot be used, the reason shows under the box (for example "That promo code has expired.") and the order keeps its total without the code.

To hide the code box on your forms, turn off **Show the code box on forms**. A link with `?promo=CODE` still applies its code.

## Import or export codes

**Export** downloads every code as a CSV. **Import CSV** reads the columns `code, kind, value, code_type, max_uses, per_order_limit, valid_from, valid_until, applies_to, unlocks, automatic, group_tiers, status`:

- A row updates the code it names (any case), or creates it. Blank cells keep what is stored.
- **value** is a percent (0–100) or an amount like `50.00`.
- **applies_to** and **unlocks** list ticket names (or ids) separated by `|`.
- **group_tiers** is seats and value pairs, such as `5:10|10:15`.

Click **Dry run** to see each row's result, then **Apply**.

Deleting a code stops new orders using it. Orders that already used it keep their discount.

<Tip>
For invitations that should work only for one named person, use a pass from [Sales & invitations](/registration/sales-and-invitations) instead of a shared code.
</Tip>
