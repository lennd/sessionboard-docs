title: "Upload files & make comments"

---

If **Files** is enabled for your event, you can upload supporting documents that will accompany your session. Read more below on how to upload your materials as well as communicate to the event admins through comments.

## How to upload files

1. Select the button **Submissions** at the top of your portal.
   ![Select the button Submissions at the top of your portal](/images/kb/099fcd05-Screenshot-2025-02-17-at-2.05.35-PM.png)
2. Within the **Submissions** page, select the session you would like to upload content for to open the sidebar on the right side of the page.
   ![open session](/images/kb/7e36f4f7-open-session.gif)
3. Within the sidebar, select the **Files** button below the session name.
   ![Within the sidebar, select the Files button below the session name](/images/kb/d18f7258-Screenshot-2025-02-17-at-2.06.31-PM.png)
4. Add your file by either dragging and dropping or selecting the file from your computer.
   ![upload content](/images/kb/149bb5f0-upload-content.gif)
5. Once you have added the file, you can adjust the file type and version type. Do not forget to click the blue **Upload** button once complete.
   1. **File Type:** Once files have been uploaded, they can be assigned a content type. By default, this is set to Presentation; however, this can be changed to Poster or Handout to differentiate types of session content.

      ![File Type: Once files have been uploaded, they can be assigned a content type](/images/kb/1044b685-Screenshot-2025-02-17-at-2.16.20-PM.png)

   2. **File Versioning**: Files can also be marked as versions of previously uploaded files. This allows a new file to be connected to a previous version. All file versions will remain accessible in the content upload history and can be downloaded to cross-reference.
      ![File Versioning](/images/kb/39f72747-Screenshot-2025-02-17-at-2.16.42-PM.png)

View File Version History

Selecting “**History**” or "**Expand All**" will allow you to see versions of a specific file.

![Selecting “History” or "Expand All" will allow you to see versions of a specific file](/images/kb/5731ced9-Screenshot-2025-02-17-at-2.18.18-PM.png)

## Comments

Speakers can add and view comments on session content within their portals. Commenting is a quick and simple way to communicate with event admins directly.

To view and send new comments, either click "**Expand All"** or the word **"Comment".**

![To view and send new comments, either click "Expand All" or the word "Comment"](/images/kb/c568ff6f-Screenshot-2025-02-17-at-2.19.26-PM.png)
