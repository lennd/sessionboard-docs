### Fields

We recommend utilizing system fields first and modifying them (if applicable) before considering creating a custom field.
</Note>

#### Field Types

Fields are assigned one of the following categories:
-  Custom: Any fields the org team member creates
-  Profile: Includes Name, Pronouns, Honorific, Job Title, Company Name, Headshot, Bio, etc.
-  Attribute: Includes Audience Type, Ethnicity, Languages, Speaker Fee, etc.
-  Communication: Includes Phone Number, Email, Address, etc.

Org team members can locate these fields within 'Contacts' when adding fields to their view as fields will be listed within each category they are assigned.

---

#### Renaming System Fields

Team members have the ability to edit the names of system default fields. System default fields are fields that are created by Sessionboard but can be modified including (but not limited to) Biography, Job Title, Audience Type, and Industry.

To edit a system field ensure the field has been added to your dashboard view within 'CRM' > 'Directory' and right-click on the field name. From the pop-up window, select 'Edit Column'.

![](/images/kb/484a5012-image-png-Mar-16-2026-06-35-12-3737-PM.png)

Within the pop-up window, edit the 'Field Name' box. Ensure to click 'Save Changes' once you are done.

![](/images/kb/632d35f3-image-png-Jan-30-2026-08-20-24-7495-PM.png)

<Note>
If you make updates to system/global fields, these updates will also be reflected within each event in the organization.
</Note>

#### Create A Custom Field
1.  Within the Library > Fields module select the + Add Field button to the right of the page.

![](/images/kb/0f63f277-image-png-Mar-16-2026-06-35-42-7078-PM.png)

2.  Within the pop-up window, provide a field name and field type (i.e. text, dropdown, checkbox).

![](/images/kb/dc8ddde4-image-png-Jan-30-2026-08-25-29-8063-PM.png)

3.  Once completed, click the 'Save Changes' button at the bottom of the window.

---

#### Managing Attribute Fields

For Attribute Fields that have a dropdown field type, you can adjust the dropdown options by adding new answer choices or editing the existing ones. To do this, ensure the field is added to your 'Directory' view via the Columns button, and right-click on the field to edit the field options.

Up to 25 fields can be added as Columns in your Contacts view at once. Note that within the CRM we don't support multiple saved column views the way Dashboards do,instead, the CRM uses Segments and Dynamic Lists to help you organize and revisit groups of contacts.

A Segment saves a filtered list of contacts you can return to anytime (Dynamic = auto-updating, Curated = manually managed), which covers most workflows where you'd otherwise want a separate view. For setup steps, see Speaker CRM: Segments.

<Note>
The field type for an attribute can not be changed (i.e. if the field is a dropdown, you can not change it to be a text field).
</Note>
