Sessionboard fills the variables below from the contact, account, session, event, and organization data it already holds when it sends a contract. They work in both places you write an agreement:

- In a [Sessionboard e-sign template](/speaker-crm/contract-templates), as `{{contact.full_name}}` in the document, the email subject and message, and in conditional sections.
- In a [Docusign template](/speaker-crm/contracts#send-a-contract-via-docusign), as the **Data label** of a **Text** field. Fields with any other label are left for the signer to complete.

## Use a variable in a Sessionboard template

1. Open **CRM > Contracts > Templates** and edit the template.
2. In the **Variables** rail, search for the variable and click it to insert `{{…}}` at the cursor, or type the id by hand. Only the namespaces that apply to the template's base module are listed — `contact.*` for Contacts templates, `account.*` for Groups templates.
3. To show a clause only when a value is present, use the **Conditional section** rail; it wraps the selection in `{{#if contact.custom.country}} … {{/if}}`.

A variable with no value on the record is left blank in the sent document. Use **Preview as…** on the template to see which variables resolve for a real contact or group before you send.

## Name a Docusign template field

1. In Docusign, edit the template and drag a **Text** field onto the document.
2. In the field's properties, set **Data label** to the variable id exactly as written, for example `contact.full_name`.
3. Save the template. Sessionboard fills the field at send time and shows the value in the **Review & edit fields** step so you can change it before sending.

<Tip>
The Docusign panel in **Organization Settings > Integrations** lists every variable available to your organization, including your custom properties, with a copy button next to each id.
</Tip>

## Always available

| Variable | Value |
| --- | --- |
| `today` | The date the contract is sent |

## Organization

| Variable | Value |
| --- | --- |
| `org.name` | Organization name |
| `org.legal_name` | Organization legal name, or the organization name if none is set |
| `org.website` | Organization website |

## Sender

The Sessionboard user who sends the contract.

| Variable | Value |
| --- | --- |
| `sender.first_name` | Sender first name |
| `sender.last_name` | Sender last name |
| `sender.full_name` | Sender full name |
| `sender.email` | Sender email |

## Contact

Available when the contract is with a contact.

| Variable | Value |
| --- | --- |
| `contact.first_name` | First name |
| `contact.last_name` | Last name |
| `contact.full_name` | Full name |
| `contact.email` | Email |
| `contact.title` | Job title |
| `contact.company` | Company |
| `contact.custom.<property>` | Any custom contact property, by its id. For example `contact.custom.hotel` |

## Account

Available when the contract is with an account.

| Variable | Value |
| --- | --- |
| `account.name` | Account name |
| `account.website` | Account website |
| `account.type` | Account type |
| `account.custom.<property>` | Any custom account property, by its id |

## Session

Available when the contact has a session in the event you choose for the contract.

| Variable | Value |
| --- | --- |
| `session.title` | Session title |
| `session.start_at` | Session start date and time |
| `session.end_at` | Session end date and time |
| `session.room` | Room |
| `session.format` | Session format |

## Event

The event you choose in the **Add Contract** dialog.

| Variable | Value |
| --- | --- |
| `event.name` | Event name |
| `event.start_date` | Event start date |
| `event.end_date` | Event end date |
| `event.location` | Event location |

<Note>
A variable that has no value on the record shows as **No source** in the review step. Type the value there; it is used for that contract only and does not change the record.
</Note>
