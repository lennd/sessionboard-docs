### NEW FEATURES

#### Additional User Roles & Permissions

Now introducing FOUR new roles including:
-  Admin Lite
-  Content Manager
-  Communication Manager
-  Reporting Only Admin

PLUS create custom user roles/profiles for each event.

The new Permissions page allows Admins to view what feature each role has access to as well as create new profiles/roles.
