Release Date: March 15, 2024

## FEATURE IMPROVEMENTS

### Add session and speaker fields to evaluation plans
Choose which session and speaker fields you'd like to be shown to your evaluators.

![Add Session and Speaker fields to Evaluation Plans](/images/kb/9519d610-Screenshot-2024-03-15-at-12_22_21-PM-1.png)

### Filtering by tag to select evaluators
When selecting evaluators to add to a plan, filter using tags on your users to help expedite your selection process.

![Filtering by Tag to select Evaluators](/images/kb/5094f1fc-Screenshot-2024-03-15-at-10_39_48-AM-1.png)

### Notifying Your Evaluators

We've added the ability to notify new evaluators recently added to an open evaluation plan.

![Notifying Your Evaluators](/images/kb/683abcc0-2-20240312-121229-1.gif)

### Tags Update

Looking at the tag module, click on the number of users or number of sessions, and use

each tag to see a filtered view of associated users or sessions to help verify your tagging.

![Tags Update](/images/kb/5ece27ee-Untitled-design-1--2.gif)

### Agenda Embed

We've updated the layout to help focus on each session track, title, and subsession count when applicable.

![Agenda Embed](/images/kb/0e744910-Screenshot-2024-03-15-at-12_53_39-PM-1.png)
