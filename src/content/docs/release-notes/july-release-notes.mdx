Release Date: July 3, 2024

## New Features

### Creating custom session status
Customize your Sessionboard event by creating custom session statuses tailored to your event-specific workflows, ensuring efficient session tracking and management.

Session Statuses may be found in Session Settings.

![Creating Custom Session Status](/images/kb/d74c3979-Screenshot-2024-07-02-at-5_21_52-PM-1.png)
 Update Session Statuses

### Extend Task Deadlines

Event admins may set the number of days portal tasks and forms will be accepted past the due date. This extension may be set per portal.
