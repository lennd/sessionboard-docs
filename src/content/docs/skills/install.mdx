A skill needs two things: the **Sessionboard connector**, which gives the assistant Sessionboard's tools as you, and the **skill**, which tells it how to do a whole job with them. Connect first, then add skills.

## 1. Connect Sessionboard

Every assistant connects the same way: it opens a Sessionboard sign-in, you pick your organization and choose **Authorize**. There is no API token to paste. Follow the guide for your assistant:

- [Connect Claude](/integrations/connect-claude)
- [Connect ChatGPT](/integrations/connect-chatgpt)
- [Microsoft Copilot, Google Gemini and other assistants](/integrations/connect-ai-assistants)

Use the server for the region you sign in to:

| Your admin login URL | MCP server URL |
|----|----|
| `appv2.sessionboard.com` | `https://mcp.sessionboard.com/mcp` |
| `appv2-eu.sessionboard.com` | `https://mcp-eu.sessionboard.com/mcp` |
| `appv2-me.sessionboard.com` | `https://mcp-me.sessionboard.com/mcp` |

## 2. Add skills

### Claude (web and desktop)

<Steps>
  <Step title="Turn on skills">
    Skills need **Code execution and file creation** on, under **Settings → Capabilities**. On Team and Enterprise plans an Owner controls this under **Organization settings → Plugins & skills**.
  </Step>
  <Step title="Download a skill">
    Open the skill's page in this section and choose **Download skill (.zip)**. Keep the zip as it is: its folder is the skill.
  </Step>
  <Step title="Upload it">
    In Claude, open **Customize → Skills**, choose **+**, then **Create skill → Upload a skill**, and pick the zip.
  </Step>
  <Step title="Use it">
    Start a chat with the Sessionboard connector on and ask in your own words, for example *"Open our call for speakers for the Spring Summit"*. Claude picks the skill that fits.
  </Step>
</Steps>

<Tip>
On Team and Enterprise plans an Owner can add a skill for everyone: **Organization settings → Plugins & skills → Add → Upload a skill**. Each person can still turn it off.
</Tip>

### Claude Code

The Sessionboard plugin carries the connector for your region and every organizer skill. Download the one for your region:

- [United States](/skills/downloads/sessionboard-claude-plugin-us.zip)
- [Europe](/skills/downloads/sessionboard-claude-plugin-eu.zip)
- [Middle East](/skills/downloads/sessionboard-claude-plugin-me.zip)

Unzip it, then in Claude Code:

```bash
/plugin marketplace add ./sessionboard-claude-plugin
/plugin install sessionboard@sessionboard
```

Claude Code signs you in to Sessionboard the first time a tool runs. Skills you uploaded to your Claude account also appear in Claude Code when you sign in with the same account.

To add skills without the plugin, unzip [every skill](/skills/downloads/sessionboard-skills.zip) into `~/.claude/skills` and connect Sessionboard with `claude mcp add --transport http sessionboard https://mcp.sessionboard.com/mcp` (your region's URL).

### ChatGPT

Connect the Sessionboard app first ([Connect ChatGPT](/integrations/connect-chatgpt)). Then use a skill one of two ways:

- **For one job:** on the skill's page choose **Open in ChatGPT**. It starts a chat with the skill's starter prompt. Turn on Sessionboard for that chat if ChatGPT asks.
- **For a job you repeat:** create a ChatGPT project, open the skill's page, copy **The full instructions** into the project's instructions, and use the Sessionboard app in that project's chats.

<Note>
ChatGPT does not read the skill's zip the way Claude does, so the project instructions are the whole skill. The tools, permissions and approvals are the same in both, because they come from Sessionboard, not from the assistant.
</Note>

### Other assistants

Copilot, Gemini, Cursor and any other assistant connected to the Sessionboard MCP server can follow a skill too. If it reads skill folders (a `SKILL.md` with `name` and `description` at the top), unzip the skill into its skills folder. If it does not, paste the skill's full instructions into the chat or the assistant's custom instructions.

## Keep skills up to date

Skills change when Sessionboard adds tools. Download a skill again to update it, or reinstall the Claude Code plugin. Each skill's page always has the current version.
