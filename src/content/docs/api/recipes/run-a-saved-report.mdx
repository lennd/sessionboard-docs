---
title: "Run a saved report"
description: "Run a report built in Sessionboard from a script and get its rows back as JSON."
---

Build the report once in Sessionboard, then run it on a schedule from your own system. You need a token with `read:insights`.

## 1. Find the report

[`GET /v1/event/{eventId}/insights/queries`](/api/reference/insights/list-saved-queries-event-scoped-insights) lists an event's saved reports, and [`GET /v1/insights/queries`](/api/reference/insights/list-saved-queries) the organization's. Note the report's `id`.

## 2. Run it

```bash
curl --request POST \
  --url 'https://public-api.sessionboard.com/v1/event/{eventId}/insights/queries/{queryId}/run' \
  --header 'x-access-token: <api-token>'
```

[`POST /v1/event/{eventId}/insights/queries/{queryId}/run`](/api/reference/insights/run-a-saved-query-event-scoped-insights) runs it on that event; [`POST /v1/insights/queries/{queryId}/run`](/api/reference/insights/run-a-saved-query) runs an organization report. The report's columns and filters are the ones saved in Sessionboard, so changing the report there changes what your script gets.

To write a query yourself instead, see the [SbQL Reference](/api/insights/sbql).
