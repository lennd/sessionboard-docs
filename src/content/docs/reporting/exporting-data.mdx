Within each module in Sessionboard, you have the ability to export details as a CSV or Excel file. Below are instructions on how to export data (For the purpose of this example, we will be working from the Session model; however, this is applicable for the People, Sponsor, and Exhibitor Module as well).

<Tip>
TIP: To customize the fields included in your export, update your table view by adding or removing the desired columns
1. Navigate to the module and select the grey "Options" button in the top right-hand corner of your screen.
2. From the dropdown menu, select if you would like the data exported in either a CSV file or an Excel file.
</Tip>

📣 NOTE: File fields included in the export will appear as publicly hosted URL links within the file.

## Dates and times in an export

Every date and time in a downloaded file is written in the **event timezone** from [Event Details](/events/event-details). Exports that aren't scoped to one event — organization-wide Awards exports, for example — use your organization's timezone instead. That is often not the timezone of the person opening the file, and it is not the timezone the on-screen grid uses either, which renders in the reader's own browser.

So every exported value names the zone it belongs to:

| In the file | Means |
| --- | --- |
| `2026-04-01 18:30 PDT` | The zone has an abbreviation, so the abbreviation is used |
| `2026-04-01 18:30 UTC-04:00` | The zone has no standard abbreviation, so the offset is spelled out |
| `2026-04-01 18:30 UTC` | No timezone is set, so the value is UTC |

<Note>
If your export format already includes a timezone token, nothing is added — you won't get two markers on one value. When dates and times are split into separate Date and Time columns, the marker sits on the Time column, since a calendar date on its own has no time of day to be ambiguous about.
</Note>

On-screen report grids are deliberately left unlabelled. The marker is for files that leave Sessionboard and get read somewhere else.
