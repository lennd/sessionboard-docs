import { Note } from '@compat';

Creating a view is a great way to personalize the way you see fields based on your current needs. Views can be created and seen by all admins.
- Columns
- Filter a View
- Sort a View
- Delete a View
- Rename a View

---

Within your event, navigate to the module you are working from (for this example, we will be looking at the Contacts module).

### Columns

Select "Columns" to add, order, and hide fields that you want to be shown on your dashboard view.

![Module table views: Columns](/images/kb/588de5fc-image-png-Jul-08-2026-05-37-28-8789-PM.png)

Task Completion Status

To manage task completion for sessions, groups (sponsors/exhibitors), and contacts, add the task to your view.

![Module table views: Columns (2)](/images/kb/9a63812d-image-png-Feb-24-2026-12-46-24-0942-AM.png)

Once completed, click the "Apply Changes" button.

![Module table views: Columns (3)](/images/kb/47253349-image-png-Feb-03-2026-07-42-01-5039-PM.png)

💡TIP: Do not forget to SAVE your updated view so that the changes applied remain the next time you access this module.

![Module table views: Columns (4)](/images/kb/09d8ce85-image-png-Feb-03-2026-07-45-22-4702-PM.png)

<Note>
Columns currently support a maximum of 25 fields. If you need to display more information than that, consider creating multiple views with different column configurations to stay within the limit.
</Note>

### Filters

❗️You can not filter or sort by the following fields within the Contacts or Speakers Modules at this time:
- [Session] Track
- [Session] Language
- Sessions

Select "Filter" from the right side of your screen.

![Module table views: Filters](/images/kb/bb8cc340-image-png-Feb-03-2026-07-48-23-7622-PM.png)

Then click "+ Add Filter" to create a new one:

![Module table views: Filters (2)](/images/kb/cb384287-image-png-Feb-03-2026-07-48-59-1003-PM.png)

Within the pop-up modal, select the field that you would like to filter by. Next, you will be able to apply settings to this field to further filter by, such as:
- contains
- does not contain
- is
- is not
- is empty
- is not empty
- starts with
- ends with

![Module table views: Filters (3)](/images/kb/e10b1ffe-image-png-Feb-17-2026-06-15-17-9537-PM.png)

Once complete, do not forget to select "Apply Changes" at the bottom of the pop-up modal.

💡TIP: Do not forget to SAVE your updated view so that the changes applied remain the next time you access this module.

![Module table views: Filters (4)](/images/kb/09d8ce85-image-png-Feb-03-2026-07-45-22-4702-PM.png)

### Sort By

❗️You can not filter or sort by the following fields within the Contacts or Speakers Modules at this time:
- [Session] Track
- [Session] Language
- Sessions

Select "Sort" from the right side of your screen.

​

![Module table views: Sort By](/images/kb/9f7b730a-image-png-Feb-03-2026-07-53-59-3238-PM.png)

Within the pop-up modal, select the field you would like to sort, as well as if you would like to sort by ascending (↑) or descending (↓).

![Module table views: Sort By (2)](/images/kb/afdba608-image-png-Feb-03-2026-07-57-03-5049-PM.png)
Once complete, do not forget to select "Apply Changes" at the bottom of the pop-up modal.

💡TIP: Do not forget to SAVE your updated view so that the changes applied remain the next time you access this module.

![Module table views: Sort By (3)](/images/kb/09d8ce85-image-png-Feb-03-2026-07-45-22-4702-PM.png)

### Navigate To A View

To select a view to see, select the down arrow next to the grey "View" icon. This will open a pop-up modal that will allow you to select a previously created view to see.

![Module table views: Navigate To A View](/images/kb/790544de-image-png-Feb-03-2026-08-06-38-9765-PM.png)

### Rename A View

Within your module, select the "View" button from the right side of your screen and click "Rename View".

![Module table views: Rename A View](/images/kb/bcb43bb6-image-png-Feb-03-2026-08-12-02-6877-PM.png)

### Delete A View

Within your module, select the "View" button on the right side of your screen and click "Delete View".

![Module table views: Delete A View](/images/kb/baed84cc-image-png-Feb-03-2026-08-12-45-7842-PM.png)
