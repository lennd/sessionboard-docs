The Report Builder is a full-screen workspace for building custom reports on live event or organization data — no code required. Pick the fields you want, watch the preview update as you work, and shape the result with filters, grouping, pivots, and sorting.

Reports and dashboards can be built and managed at either the **organization level** or the **event level**. Most teams work within a specific event, so the Reports module is most commonly accessed from there.

![Reports and dashboards can be built and managed at either the organization level or the event level](/images/kb/fefd3f04-image-png-Jul-07-2026-06-41-38-8983-PM.png)

![The Report Builder with fields on the left, a live preview in the center, and the report shape rail on the right](/images/kb/report-builder-overview.png)

The screen has three parts:

- **Fields** (left) — every field you can report on, grouped by module and relationship. Use the search box to find a field fast.
- **Preview** (center) — a live result table that re-runs as you change the report. Row count and query time are shown at the bottom.
- **Report shape** (right) — the rail that defines the report: **Filters**, **Group by**, **Nested rows**, **Pivot**, **Sort**, and **Columns**. Each section collapses so you can focus on the part you're shaping.

## Start a report

From **Reports**, you have two starting points, and both open the builder:

![The Browse the gallery and Describe it with AI entry cards on the Reports page](/images/kb/report-builder-entry-points.png)

- **Browse the gallery** — pick a ready-made report and run it in one click.
- **Describe it with AI** — ask a question in plain English and the builder writes the report for you.

You can also click **+ Add Report**, or open any saved custom report from its card — saved reports open directly in the builder.

### Start from an example

New reports open the example gallery automatically. Every example opens with its columns, filters, and sorts ready to reshape — it's the fastest way to learn what the builder can do. Filter by category (Sessions, Speakers, Evaluation, Contacts, Sponsors, and more) or search by name. You can reopen the gallery at any time with the **Examples** button in the toolbar.

![The Start from an example dialog with category chips and a grid of ready-made report cards](/images/kb/report-builder-examples-gallery.png)

### Describe it with AI

Click **Describe it with AI** in the toolbar to open a prompt dialog. Describe the report you want — for example, *"Report all accepted speakers"* — or, if you already have a report open, describe what to change. The instructions apply to the report as currently built, so you can iterate: *"Group it by track and only show sessions with more than 2 speakers."*

![The Describe it with AI dialog with a prompt box and a Generate button](/images/kb/report-builder-ai-dialog.png)

Beyond answering direct questions, the AI can also **surface anomalies and patterns** you may not have considered, such as sessions with no assigned speakers or evaluation score distributions that stand out. Try prompts like *"Are there any patterns in session submissions I should know about?"* to proactively explore your data.

## Columns

Click a field in the left panel to add it as a column; click it again to remove it. Added fields show a check mark. In the **Columns** section of the rail you can:

![The Columns section listing four columns, each with a drag handle, a rename field, and a Show as menu](/images/kb/report-builder-columns-section.png)

- **Reorder** — drag the handle on the left of each column, or drag the column headers directly in the preview.
- **Rename** — click the column name and type a new one. When a column is renamed, the original field name stays visible in small text underneath, so you always know what the data is.
- **Change how it shows** — the **Show as** menu offers treatments that fit the field type: show a person as their full name, bucket a date by day, month, or year, or count values instead of listing them.
- **Add an empty column** — for a placeholder you'll fill in a spreadsheet later.

You can also resize columns by dragging the edge of a column header in the preview. Widths are remembered when you save the report.

## Filters

Click **+ Add a filter** and pick a field. The operators fit the field type — option fields like status offer **is** / **is not** with a picker of real values from your event, text fields offer contains/empty checks, and so on.

## Group by

Grouping turns the report into a summary: pick a field under **Group by** and the builder counts rows per group. Date fields can be bucketed **By day**, month, or year. Use **Only show groups where** to filter on the calculation itself — for example, only tracks with more than 5 sessions.

![The Group by section grouping on a date field bucketed By day, with an Only show groups where control](/images/kb/report-builder-group-by.png)

## Nested rows and Pivot

Two more ways to shape related data:

- **Nested rows** — stack related rows under the row they belong to, instead of repeating the parent on every line. For example, sessions as top-level rows with each speaker nested underneath.
- **Pivot** — show related records side by side as extra columns: one row per session, with speaker 1 and speaker 2 spread across the row.

Group by, Nested rows, and Pivot are alternatives — when one is active the others explain why they're off, and turning one on switches the others off.

## Sort and row limit

Add sorts in the **Sort** section — the direction labels match the field type (**A to Z** for text, newest first for dates). Use **Keep only the first … rows** to cap the result, for example a top-50 list.

## Work from the column headers

Click the arrow on any column header in the preview to act on that column directly:

![The Speaker column header menu with sort directions, Filter by this column, Group by this, and Remove column](/images/kb/report-builder-column-header-menu.png)

## Undo and redo

Every change in a builder session can be undone and redone with the arrows in the toolbar, or with the usual keyboard shortcuts (Cmd/Ctrl+Z to undo, Shift+Cmd/Ctrl+Z to redo).

## Save and name the report

Click **Save** in the toolbar. The first save asks for a report name in the **Report details** dialog — a name is required so the report is findable later. Reopen the dialog any time by clicking the report name in the toolbar, or via **Report details** in the **…** menu. It also shows who created the report and who last updated it.

![The Report details dialog with the report name field and created by / last updated by](/images/kb/report-builder-details-modal.png)

Saved reports appear under **Custom Reports** on the Reports page.

## The … menu

The **…** menu next to the report name holds report-level actions:

![The report actions menu with Report details, Duplicate, Hide personal details, and Delete](/images/kb/report-builder-overflow-menu.png)

- **Report details** — rename the report and see who created and last updated it.
- **Duplicate** — copy the report as a starting point for a variation.
- **Hide personal details** — mask personal data such as names and email addresses in the preview. Useful when sharing your screen or working where data privacy is a concern.
- **Delete** — permanently remove the report, along with its schedules and share links.

## Download the results

Click **Download** above the preview and choose **Excel (.xlsx)** or **CSV**. The export runs in the background — you can keep working, and the file downloads automatically when it's ready. Progress appears in the export tray at the bottom of the screen.

![The Download menu above the preview offering Excel (.xlsx) and CSV](/images/kb/report-builder-download-menu.png)

<Tip>
Every report is powered by **SbQL** (Sessionboard Query Language) under the hood. Advanced users can click **View report code** above the preview to see the query behind the report.
</Tip>

## Manage a saved report

Once a report is saved, the tabs at the top of the rail manage everything around it, without leaving the builder:

![The Scheduled tab open, with the tab strip in the rail and the scheduled sends panel in the center](/images/kb/report-builder-manage-tabs.png)

- **Scheduled** — email the report on a daily, weekly, or monthly cadence to a list of recipients.
- **Links** — create share links that anyone can open without logging in; manage, revoke, or open existing links.
- **Widgets** — pin the report to a dashboard as a chart or table. Linked widgets update when you save changes to the report.
- **Activity** — see every run of the report and every external view.

The same actions are available from the report's card on the Reports page — click the **...** menu for **Edit Query**, **Share**, **Schedule**, **Duplicate**, and **Delete**.

![Custom Reports are any reports you've saved yourself](/images/kb/7cfe5451-image-png-Jun-11-2026-04-52-02-5609-PM.png)

## Share a report

Share a report with anyone — even people without a Sessionboard account — using a secure link. Shared links always show **live data**, not a static snapshot.

### Creating a Share Link

1. Open the **Links** tab in the builder (or select **Share** from the report card's **...** menu).
2. Click **+ Create New Link**.
3. Give the link a name so you can identify it later.
4. Optionally configure access restrictions:
   - **Require password** — recipients must enter a password to view
   - **Set expiration** — the link stops working after a chosen date
   - **Limit views** — restrict the number of times the link can be opened
5. Click **Create Link**.

![Limit views — restrict the number of times the link can be opened](/images/kb/7dc3e76e-image-png-Jun-11-2026-04-53-16-3146-PM.png)

### Using the Share Link

Each link exposes multiple formats you can copy and use directly:

- **Shareable Public Link** — view the report in a browser
- **CSV Link** — direct URL that downloads the report as CSV
- **Google Sheets Formula** — paste the `=IMPORTDATA()` formula into Google Sheets to pull live data automatically
- **JSON Link** — for developers integrating report data into other tools
- **XLSX Link** — direct URL that downloads the report as Excel

![XLSX Link — direct URL that downloads the report as Excel](/images/kb/3309a811-image-png-Jun-11-2026-04-54-01-2395-PM.png)

You can create **multiple links per report** — for example, one public link and one password-protected link for internal use. The view count for each link is shown next to its name.

## Schedule automated report deliveries

Set up a schedule to have any report emailed automatically to your team on a regular basis — no manual work required.

### Creating a Schedule

1. Open the **Scheduled** tab in the builder (or select **Schedule** from the report card's **...** menu).
2. Enter a **Schedule Name** (e.g., "Weekly Speaker Status Update").
3. Set the **Frequency**: Daily, Weekly, or Monthly.
4. For weekly schedules, select the day(s) of the week to send.
5. Set the **Time** and **Timezone** for delivery.
6. Add up to **5 recipients** by entering their email addresses.
7. Optionally write a **Custom message** to include in the email body.
8. Click **Create Schedule**.

![Click Create Schedule](/images/kb/39855b6a-image-png-Jun-11-2026-04-56-38-2265-PM.png)

<Note>
📌 **Note:** Recipients receive an email with a secure link to view the report. The link expires after **7 days** and shows live data, not a static export.
</Note>

<Tip>
💡 **Tip:** Scheduled reports also appear in the **Scheduled Reports** section of the Reports page, where you can view, edit, or delete them at any time.
</Tip>

## Pre-built Session Reports

**Session Reports** are ready-made reports included with every event. They cover the most common data needs so you don't have to build them from scratch.

Examples include:

- Sessions with Speaker Details
- Sessions with Evaluation Ratings
- New Sessions Report

To run one, click **Run Report** on any card. Results load instantly and can be exported or shared just like a custom report.

## Permissions & Access

Access to Insights is controlled at both the organization and event level through the Permissions system.

![Access to Insights is controlled at both the organization and event level through the Permissions system](/images/kb/6f73987b-image-png-Jun-11-2026-05-30-43-8704-PM.png)

To manage permissions, go to **Event Team > Permissions** and select the relevant role. Under the **Data & Insights** section, configure:

- **Can view reports** — view and run existing reports
- **Can create reports** — build and save new custom reports
- **Can share reports** — generate shareable links
- **Can schedule reports** — set up automated email delivery
- **Can manage dashboards** — create and configure custom dashboards
- **Connect AI Assistants** — required for accessing event data via Claude, ChatGPT, or other AI clients

## FAQ & Troubleshooting

### Who can access the Report Builder?
Any team member with the appropriate permissions under **Data & Insights** in their role configuration. Insights reporting must also be activated for your account — contact [support@sessionboard.com](mailto:support@sessionboard.com) if it's not available.

### Can I share a report with someone who doesn't have a Sessionboard account?
Yes. Use the Share link feature to generate a public URL. You can optionally add a password, set an expiration date, or limit the number of views. The recipient accesses the live report in their browser with no login required.

### My AI-generated report isn't returning the results I expected. What should I do?
Try rephrasing your question with more specific details. For example, instead of "show me speakers," try "show all accepted speakers assigned to sessions in Track A." Because the AI iterates on the open report, you can also follow up with a correction — *"only accepted sessions"* — or adjust the columns and filters yourself in the builder.

### Can I use report data in Google Sheets?
Yes. When creating a share link, copy the **Google Sheets Formula** (`=IMPORTDATA()`) and paste it into any Google Sheets cell. The sheet will automatically pull live data from your report and refresh when you reload.

### Can I build a dashboard that pulls data from multiple modules?
Yes. Each widget on a dashboard is powered by its own query and can pull from any module (Sessions, Contacts, Evaluations, etc.). You can mix and match modules across widgets in the same dashboard.

### What's the difference between a Session Report and a Custom Report?
Session Reports are pre-built templates included with every event — they cover the most common reporting needs and can't be modified. Custom Reports are reports you build and save yourself in the Report Builder; they can be edited, shared, scheduled, and duplicated.

### Can scheduled report emails be sent to people outside my organization?
Yes. You can add any email address as a recipient when setting up a schedule — Sessionboard accounts are not required. Recipients receive a secure link that expires after 7 days.
