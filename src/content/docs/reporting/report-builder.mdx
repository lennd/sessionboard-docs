The Report Builder is a full-screen workspace for building custom reports on live event or organization data — no code required. Pick the fields you want, watch the preview update as you work, and shape the result with filters, grouping, pivots, and sorting. The same builder is available at the event level and the organization level.

![The Report Builder with fields on the left, a live preview in the center, and the report shape rail on the right](/images/kb/report-builder-overview.png)

The screen has three parts:

- **Fields** (left) — every field you can report on, grouped by module and relationship. Use the search box to find a field fast.
- **Preview** (center) — a live result table that re-runs as you change the report. Row count and query time are shown at the bottom.
- **Report shape** (right) — the rail that defines the report: **Filters**, **Group by**, **Nested rows**, **Pivot**, **Sort**, and **Columns**. Each section collapses so you can focus on the part you're shaping.

## Start a report

From **Reports**, you have two starting points, and both open the builder:

![The Browse the gallery and Describe it with AI entry cards on the Reports page](/images/kb/report-builder-entry-points.png)

- **Browse the gallery** — pick a ready-made report and run it in one click.
- **Describe it with AI** — ask a question in plain English and the builder writes the report for you.

You can also click **+ Add Report**, or open any saved custom report from its card — saved reports open directly in the builder.

### Start from an example

New reports open the example gallery automatically. Every example opens with its columns, filters, and sorts ready to reshape — it's the fastest way to learn what the builder can do. Filter by category (Sessions, Speakers, Evaluation, Contacts, Sponsors, and more) or search by name. You can reopen the gallery at any time with the **Examples** button in the toolbar.

![The Start from an example dialog with category chips and a grid of ready-made report cards](/images/kb/report-builder-examples-gallery.png)

### Describe it with AI

Click **Describe it with AI** in the toolbar to open a prompt dialog. Describe the report you want — or, if you already have a report open, describe what to change. The instructions apply to the report as currently built, so you can iterate: *"Group it by track and only show sessions with more than 2 speakers."*

![The Describe it with AI dialog with a prompt box and a Generate button](/images/kb/report-builder-ai-dialog.png)

## Columns

Click a field in the left panel to add it as a column; click it again to remove it. Added fields show a check mark. In the **Columns** section of the rail you can:

![The Columns section listing four columns, each with a drag handle, a rename field, and a Show as menu](/images/kb/report-builder-columns-section.png)

- **Reorder** — drag the handle on the left of each column, or drag the column headers directly in the preview.
- **Rename** — click the column name and type a new one. When a column is renamed, the original field name stays visible in small text underneath, so you always know what the data is.
- **Change how it shows** — the **Show as** menu offers treatments that fit the field type: show a person as their full name, bucket a date by day, month, or year, or count values instead of listing them.
- **Add an empty column** — for a placeholder you'll fill in a spreadsheet later.

You can also resize columns by dragging the edge of a column header in the preview. Widths are remembered when you save the report.

## Filters

Click **+ Add a filter** and pick a field. The operators fit the field type — option fields like status offer **is** / **is not** with a picker of real values from your event, text fields offer contains/empty checks, and so on.

## Group by

Grouping turns the report into a summary: pick a field under **Group by** and the builder counts rows per group. Date fields can be bucketed **By day**, month, or year. Use **Only show groups where** to filter on the calculation itself — for example, only tracks with more than 5 sessions.

![The Group by section grouping on a date field bucketed By day, with an Only show groups where control](/images/kb/report-builder-group-by.png)

## Nested rows and Pivot

Two more ways to shape related data:

- **Nested rows** — stack related rows under the row they belong to, instead of repeating the parent on every line. For example, sessions as top-level rows with each speaker nested underneath.
- **Pivot** — show related records side by side as extra columns: one row per session, with speaker 1 and speaker 2 spread across the row.

Group by, Nested rows, and Pivot are alternatives — when one is active the others explain why they're off, and turning one on switches the others off.

## Sort and row limit

Add sorts in the **Sort** section — the direction labels match the field type (**A to Z** for text, newest first for dates). Use **Keep only the first … rows** to cap the result, for example a top-50 list.

## Work from the column headers

Click the arrow on any column header in the preview to act on that column directly:

![The Speaker column header menu with sort directions, Filter by this column, Group by this, and Remove column](/images/kb/report-builder-column-header-menu.png)

## Undo and redo

Every change in a builder session can be undone and redone with the arrows in the toolbar, or with the usual keyboard shortcuts (Cmd/Ctrl+Z to undo, Shift+Cmd/Ctrl+Z to redo).

## Save and name the report

Click **Save** in the toolbar. The first save asks for a report name in the **Report details** dialog — a name is required so the report is findable later. Reopen the dialog any time by clicking the report name in the toolbar, or via **Report details** in the **…** menu. It also shows who created the report and who last updated it.

![The Report details dialog with the report name field and created by / last updated by](/images/kb/report-builder-details-modal.png)

Saved reports appear under **Custom Reports** on the Reports page.

## The … menu

The **…** menu next to the report name holds report-level actions:

![The report actions menu with Report details, Duplicate, Hide personal details, and Delete](/images/kb/report-builder-overflow-menu.png)

- **Report details** — rename the report and see who created and last updated it.
- **Duplicate** — copy the report as a starting point for a variation.
- **Hide personal details** — mask personal data such as names and email addresses in the preview. Useful when sharing your screen.
- **Delete** — permanently remove the report, along with its schedules and share links.

## Download the results

Click **Download** above the preview and choose **Excel (.xlsx)** or **CSV**. The export runs in the background — you can keep working, and the file downloads automatically when it's ready. Progress appears in the export tray at the bottom of the screen.

![The Download menu above the preview offering Excel (.xlsx) and CSV](/images/kb/report-builder-download-menu.png)

## Schedule, share, and pin a saved report

Once a report is saved, the tabs at the top of the rail manage everything around it, without leaving the builder:

![The Scheduled tab open, with the tab strip in the rail and the scheduled sends panel in the center](/images/kb/report-builder-manage-tabs.png)

- **Scheduled** — email the report on a daily, weekly, or monthly cadence to a list of recipients.
- **Links** — create share links that anyone can open without logging in; manage, revoke, or open existing links.
- **Widgets** — pin the report to a dashboard as a chart or table. Linked widgets update when you save changes to the report.
- **Activity** — see every run of the report and every external view.

For the full walkthrough of share links, formats (CSV, Google Sheets, JSON), and schedules, see [Insights: AI reports & dashboards](/reporting/insights-ai).
