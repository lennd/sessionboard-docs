Through Sessionboard's integration with Cvent, event admins can easily send information for their sessions and speakers that were collected in Sessionboard to Cvent:

## Why use it

Organizers running Cvent syncs on accounts with low daily API quotas (e.g. free/dev accounts at 1,000 calls/day) will no longer see a sync silently "complete with errors" after burning through hundreds of doomed calls. The sync stops at the first quota hit, History tells them exactly when the quota resets, and a 403 tells them which scopes to ask their Cvent admin to add — cutting troubleshooting from a support ticket to a one-line fix.

## Integration Set Up

First, complete the following steps to get set up in Cvent and Sessionboard:

### Cvent
- Create a Machine to Machine Application that supports Client ID and Client Secret. You can do this in the Cvent developer portal: [https://developers.cvent.com/docs](https://developers.cvent.com/docs)

  ![Create a Machine to Machine Application that supports Client ID and Client Secret](/images/kb/bf982b71-image-Sep-28-2024-02-31-34-5330-AM.png)

  You will need to give the application you create permission to the following scopes:

  - event/sessions:read

  - event/sessions:write

  - event/sessions:delete

  - event/custom-fields:read

  - event/program-items:delete

  - event/program-items:read

  - event/program-items:write

- event/speakers:write

- event/speakers:read
  - event/speaker-categories:write
  - event/speaker-categories:read

- event/events:read
  - event/contacts:write
  - event/session-categories:read
  - event/session-categories:write
  - bulk/bulk-jobs:write
  - bulk/bulk-jobs:read
  - file/file:write

- In your Cvent event, you need to enable the features: "***Agenda***" and "***Speakers***"

  ![In your Cvent event, you need to enable the features](/images/kb/9320856e-image-Sep-28-2024-02-31-32-7171-AM.png)

  - If you would like to sync associated Session Content to Cvent, you will also need to enable the **"Attendee Hub"**.

    ![If you would like to sync associated Session Content to Cvent, you will also need to enable the "Attendee Hub"](/images/kb/ce517148-image-Sep-28-2024-02-31-31-7067-AM.png)

## Connect Integration

Integrations are connected on the **organization level** in Sessionboard.

After logging in, click “Organization Dashboard" to access your event's organization:

![After logging in, click “Organization Dashboard" to access your event's organization](/images/kb/f5a64c87-image-png-Feb-26-2026-05-23-13-0299-PM.png)

Or, from your event, you can click **Back to organization**:

![From your event, you can click Back to organization](/images/kb/3ce332e9-image-png-Feb-26-2026-05-22-06-6541-PM.png)

Select the '***Settings***' module to locate '***Integrations***'.

![Select the 'Settings' module to locate 'Integrations'](/images/kb/cc340125-image-png-Feb-26-2026-05-26-46-7552-PM.png)

There, you can connect new or manage existing integrations. To connect a new integration, click the “**Connect**” button below the integration.

![There, you can connect new or manage existing integrations](/images/kb/5fc3d5d0-image-png-Feb-26-2026-06-34-23-5679-PM.png)

For Cvent, enter the **Client ID**, **Client Secret** and **Cvent endpoint** that your Cvent instance is using:

- North America — `https://api-platform.cvent.com`
- Europe — `https://api-platform-eur.cvent.com`

![Entering the Cvent client ID, client secret, and endpoint](/images/kb/2213eaab-image-png-Feb-26-2026-06-35-07-2127-PM.png)

<Warning>
Enter the Client ID and Client Secret yourself in this form. Never send them by email or chat, including to Sessionboard staff. If a secret has already been shared that way, create a new secret in the Cvent developer portal and update the connection here.
</Warning>

The connection belongs to your organization, not to one event. A new event can reuse the existing connection as long as its Cvent event belongs to the same Cvent account — just add a mapping for it. You only need a new Client ID and Client Secret when the Cvent event lives in a different Cvent account, which you add with **Add New Connection**.

<Note>
Enable continuous sync to create/update records on a regular interval (approx. 30 minutes) so that admins don't have to force sync them. The admin can still manually push a sync if they want to update between the sync intervals.
</Note>

## Map Events

Once the integration is connected, a window will appear prompting you to map your Cvent events with Sessionboard ones. Select the Sessionboard Event from the dropdown list, then choose the Cvent Event in the right-hand dropdown.

Click “**Add Mapping**” to complete the mapping process.

![Click “Add Mapping” to complete the mapping process](/images/kb/05e12c9b-image-png-Feb-26-2026-06-36-15-5622-PM.png)

The Cvent event picker lists every event the connection's credentials can see, by name and Cvent ID. Check the ID before you click **Add Mapping** — similar event names from different years are easy to mix up.

Once your event is connected, you'll have access to these event-specific settings:

- **Sync Subsessions to Session Programs** — Syncs subsessions of accepted sessions to the Cvent Programs feature.

- **Skip Content Sync** — Allows you to collect session content files without syncing them to Cvent.

- **Sync Moderators** — Syncs your Moderators to your Cvent speakers list.

- **Sync Chairpersons** — Syncs your Chairpersons to your Cvent speakers list.

- **Sync Speakers with Sessions** — On by default. Turn it off to manage speakers only in Cvent; Sessionboard then leaves them untouched.

- **Remove Deleted Sessions** — Deletes sessions from Cvent when they are deleted in Sessionboard or their status changes from accepted.

- **Remove Deleted Speakers** — Deletes speakers from Cvent when they are deleted or no longer belong to any accepted session in the event.

![Sync Chairpersons — Syncs your Chairpersons to your Cvent speakers list](/images/kb/9b0b9c87-Screenshot-2026-04-02-at-4.33.36-PM.png)

## Mapping Session Fields

Once your events have been connected, your next window will allow you to map your designated session fields.
Within the dropdown, be sure you have selected the correct event that you wish to map the session fields for.

![Within the dropdown, be sure you have selected the correct event that you wish to map the session fields for](/images/kb/722aba8d-image-png-Feb-26-2026-06-42-00-9294-PM.png)

The default fields will populate within the session field mapper. You will be able to map additional fields by selecting "**Add Field Mapping**". You will then be able to select the Sessionboard field and the destination field in Cvent that you wish to be mapped to.

Any Cvent session field that isn't in the default list only receives a value once you add a row for it. Besides your Cvent custom session fields, these standard Cvent session fields can be mapped:

| Cvent field | What it holds |
| --- | --- |
| `capacity`, `capacityUnlimited` | In-person capacity, or unlimited in-person capacity |
| `capacityVirtual`, `virtualCapacityUnlimited` | Virtual capacity, or unlimited virtual capacity |
| `enableWaitlist`, `waitlistCapacity`, `enableWaitlistVirtual`, `waitlistCapacityVirtual` | Waitlist settings |
| `openForRegistration`, `openForAttendeeHub` | Whether the session is open for registration and shown in Attendee Hub |
| `displayOnAgenda`, `featured`, `includedSession` | Agenda display flags |
| `automaticallyOpensOn`, `automaticallyClosesOn` | Registration open and close dates |
| `code`, `group`, `presentationType`, `dataTagCode`, `relevance` | Other session details |

The pickers show each field's type, so pair matching types: map a number field to `capacity` and the other integer fields, a checkbox field to yes/no flags such as `openForRegistration` and `openForAttendeeHub`, and a date field to the date fields. Every field you map must already exist in Sessionboard — create it first under **Settings > Library** — and Cvent custom fields must exist in the Cvent event. Cvent custom fields are matched by name, so if you rename one in Cvent, map it again.

The default fields will populate within the speaker field mapper. You will be able to map additional fields by selecting "**Add Field Mapping**". You will then be able to select the Sessionboard field and the destination field in Cvent that you wish to be mapped to.

### Description formatting in Cvent

Sessionboard sends the session description to Cvent as the HTML stored by the description editor, exactly as it is — nothing is added, removed or cleaned up on the way. What you see in Cvent depends on how Cvent displays that HTML:

- Cvent's description editor supports Bold, Italics, Underline, Strikethrough, Subscript, Superscript, Text color, Fill color, left, center and right alignment, Bulleted lists, Numbered lists, Indent, Outdent, and Links. Other formatting may not display as expected.
- Every paragraph is sent as its own block, including empty ones. Blank lines you add for spacing can show up as extra space in Cvent, so remove them rather than pressing Enter twice.
- Text pasted from Word, a web page or another editor can carry hidden formatting into the HTML. Paste as plain text, then apply formatting with the editor's own toolbar.
- The markup counts toward any length limit Cvent applies to the description, so a description with heavy formatting can be rejected even when its visible text looks short enough. If a session fails for its description length, shorten it or simplify its formatting, then sync it again.
- An export or a report that shows the raw field shows the HTML tags. That is the stored formatting, not an error.

## How to Sync Data

After working with your Sales Engineer representative to connect your Cvent integration with your Sessionboard event(s), you'll be able to begin syncing your session and speaker details.

To sync manually, go to **Program > Collect & Review > Agenda**, click **Options**, and then click **Sync to Cvent (event: …)**. The ID in the menu item is the Cvent event the sync writes to, so check it before you start.

![You can sync to Cvent manually from the Agenda by clicking Options](/images/kb/b66146f9-image-png-Feb-26-2026-06-45-20-7189-PM.png)

With **Enable Continuous Sync** turned on for the connection, Sessionboard also checks every 30 minutes for sessions that changed since the last successful sync and pushes the event again. Continuous sync starts after the event's first successful sync, so run one manual sync after mapping. With continuous sync off, changes reach Cvent only when someone syncs.

The sync runs in the background. Its progress and result are in **History > Integrations > Sync History**: each run shows the external event it wrote to, a **Sync ID**, its status, error count, start and end time, and duration. Click the results link on a row to see counts and the error summary. How long a sync takes depends on the number of sessions, speakers and files, and on your Cvent API plan — Sessionboard paces its requests to your Cvent account's rate limit, so lower-tier accounts sync more slowly. If your account's daily API quota runs out, the sync stops and the history shows when the quota resets.

What happens when data is synced?

During a sync, the following workflow takes place:

- **Sessions**

  - New sessions that Sessionboard is syncing to Cvent are created

    - **Note:** Sessionboard only knows about the sessions that it has already synced. So, be mindful if you're also adding sessions directly to Cvent and know that Sessionboard will not automatically detect them.

  - Sessions that Sessionboard has already synced are updated

  - Only sessions in the future will sync. We will not be able to sync any sessions that have passed

- **Speakers**

  - Sessionboard attempts to find a Speaker in your Cvent Event by the same email address.

    - If it finds one, it will use the found Speaker (and respective Cvent contact record)

  - If no matching Speaker is found by email address, it will create a new Speaker record in your Cvent event

    - Cvent automatically creates a Contact record for the speaker in your Cvent Address Book

  - The updates are then performed against the Speaker record

- **Sessions \<\> Speakers**

  - Speakers are attached to Sessions. Sessionboard does not send a speaker order, so set the display order of a session's speakers in Cvent.

  - If a speaker has been removed in Sessionboard for a session, that speaker will be removed from the synced session in Cvent

- **Content**

  - To sync content that is attached to your sessions to Cvent, you will need to ensure the "Attendee Hub" module is enabled in Event.

  - Cvent allows the following file types to be synced over:

    - ai, bmp, doc, docx, eml, eps, gif, ics, jpeg, msg, otf, ost, pdf, png, ppt, pptx, tif, tiff, ttf, txt, woff, woff2, xls, xlsx

  - Cvent allows for files less than or equal to 10MB to be synced over

  - To ensure efficient syncing of your content, please refrain from any spaces within your file naming conventions

- **Locations**

  - Sessionboard Locations are created in Cvent as Locations

    - Sessions are associated with the proper Location based on the session's relationship with a Location in Sessionboard

- **Subsessions \> Programs**
  - **Title, Description, Speakers** and **Files** will all sync for your Subsessions to Programs
    - The Order and duration of programs are controlled within the Cvent platform

<Warning>
By default, sessions and speakers are not removed from Cvent when you delete them in Sessionboard or change their status. Delete them in Cvent, or turn on **Remove Deleted Sessions** and **Remove Deleted Speakers** in the event settings so the next sync deletes them for you.
</Warning>

### Syncing only speakers

Alternatively, if you wish to just sync speakers to Cvent, go to **CRM > People > Speakers** and click **Options > Sync to Cvent (event: …)**, or select speakers and click **More**. This will sync only your speakers and no session details. Please note that if you later sync from the Agenda, this will associate the speakers with their respective sessions in Cvent.
![Alternatively, if you wish to just sync speakers to Cvent, that can be completed under your Speakers view](/images/kb/b70ffce8-image-png-Feb-26-2026-06-47-05-5983-PM.png)

### Resync Behavior

On resync, new sessions and speakers that have been added to the agenda in Sessionboard will be sent to Cvent. Any updates that are made to previously synced fields (such as correcting a speaker’s title or changing a session time) will also be applied.

In addition to syncing all sessions and their speakers, you have the ability to choose **individual sessions to sync**. Go to **Program > Collect & Review > Agenda**, select the sessions you wish to sync, then click **More > Sync to Cvent (event: …)**.

![In addition to syncing all sessions and their speakers](/images/kb/6ac9c42e-image-png-Mar-03-2026-08-32-22-3650-PM.png)

## Frequently asked questions

<AccordionGroup>
  <Accordion title="What data is synced over?">
    You decide what is mapped where on the **Map Session Fields** and **Map Speaker Fields** steps. Standard and custom Sessionboard fields can be mapped to Cvent standard and custom fields on Cvent Contact, Speaker, and Session records. A field with no mapping row is not sent.
  </Accordion>
  <Accordion title="Does deleting a session or speaker in Sessionboard delete it from Cvent?">
    Only if **Remove Deleted Sessions** or **Remove Deleted Speakers** is turned on in the event settings. With both off, delete the record in Cvent yourself.
  </Accordion>
  <Accordion title="I changed a session, but Cvent still shows the old value">
    Cvent only changes when a sync runs. Edits in Sessionboard are not sent the moment you save.

    1. To push one session now, go to **Program > Collect & Review > Agenda**, select the session, and click **More > Sync to Cvent (event: …)**.
    2. To have changes go out on their own, turn on **Enable Continuous Sync** on the Cvent connection. Changed sessions are then pushed within about 30 minutes, once the event has had one successful sync.
    3. Check the run in **History > Integrations > Sync History**. If it shows errors, open the results to see which records failed and why.
  </Accordion>
  <Accordion title="The sync completed, but nothing appears in Cvent">
    The sync most likely wrote to a different Cvent event than the one you are looking at — for example last year's event, or an event mapped before the new one was created in Cvent.

    1. On the Agenda, open **Options** and read the ID in **Sync to Cvent (event: …)**, or check the **External Event** column in **History > Integrations > Sync History**.
    2. Compare it with the event ID in Cvent.
    3. If it is wrong, open the Cvent integration's **Map Events** step, add a mapping to the correct Cvent event, and sync again. Sessions already created in the wrong Cvent event stay there until you delete them in Cvent.
  </Accordion>
  <Accordion title="How do I send session capacity to Cvent?">
    Map it — capacity isn't in the default mapping.

    1. Make sure the capacity is stored in a number field on your sessions.
    2. On **Map Session Fields**, click **Add Field Mapping**, choose that field on the left, and choose `capacity` on the right for in-person capacity (or `capacityVirtual` for virtual).
    3. Save, then sync. If the session's matching unlimited flag (`capacityUnlimited`) is mapped and checked, Cvent receives unlimited capacity instead of the number.
  </Accordion>
  <Accordion title="Why don't Open for Registration or Open for Attendee Hub match what I set in Cvent?">
    Once `openForRegistration` or `openForAttendeeHub` is mapped, the Sessionboard checkbox decides the value on every sync. A checked box sends yes; an unchecked or empty box sends no, and replaces whatever was set in Cvent.

    1. Map each flag to a Sessionboard checkbox field on **Map Session Fields**.
    2. Check the box on every session that should be open, then sync.
    3. For Attendee Hub, make sure the Attendee Hub feature is enabled on the Cvent event.

    Cvent session fields you don't map keep the value they already have in Cvent.
  </Accordion>
  <Accordion title="Do I need new Cvent credentials for a new event?">
    Not if the new Cvent event is in the same Cvent account. The connection is set up once for your organization; add a mapping for the new event on **Map Events** and map its fields. You only need a new Client ID and Client Secret when the Cvent event belongs to a different Cvent account. Enter them yourself in the connection form — never send them by email.
  </Accordion>
  <Accordion title="Why does a session's speaker order differ in Cvent?">
    Sessionboard attaches each speaker to the session but does not send an order. Set the speaker display order in Cvent.
  </Accordion>
</AccordionGroup>
