<Note>
The Zapier integration is a **self-service** tool — you provide your own Zapier license and build your own Zaps.
</Note>

## Connect Sessionboard to Zapier
<Steps>
  <Step title="Start a new Zap">In Zapier, click **Create → New Zap** and select **Sessionboard** as the trigger app.</Step>
  <Step title="Authenticate">
    Provide:
    - **Connection name** — e.g., your event name
    - **Region** — Europe (`appv2-eu.sessionboard.com`) or United States (`appv2.sessionboard.com`)
    - **Application ID & Integration Key** — from **Settings → Integrations → Zapier → Get Access**
    - **Organization API Key** — from **Organization Dashboard → Settings → [API Tokens](/integrations/api-tokens) → Create Token**
  </Step>
  <Step title="Choose a trigger">
    Contact, session, sponsor, and exhibitor triggers are available — e.g., *New Contact Created*, *Session Recently Updated*, *New Sponsor Created*, *Contact Recently Associated With Event*.
  </Step>
  <Step title="Add a find-record action">Add a Sessionboard action matching your trigger (e.g., **Find Contact**).</Step>
  <Step title="Connect an external app">Pick the destination app (e.g., Slack → Send Channel Message), map fields, and **Test**.</Step>
  <Step title="Publish">Name your Zap and click **Publish**.</Step>
</Steps>

<Tip>
Authentication failing? Verify all API fields, confirm you accepted permission prompts, check account permissions, and regenerate credentials if needed.
</Tip>
