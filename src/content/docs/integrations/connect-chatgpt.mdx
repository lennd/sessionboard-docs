ChatGPT connects to Sessionboard through the [Sessionboard MCP server](/integrations/connect-ai-assistants), so it can query and manage your event data in plain English. You sign in with OAuth. There is no API token to paste and no switch to turn on in Sessionboard. Before you start, check the [prerequisites](/integrations/connect-ai-assistants#prerequisites) — AI features enabled for your org, and the **Connect AI assistants** permission on your role.

There are two ways to connect, depending on where your organization is hosted:

| | Best for | How |
|----|----|----|
| **Option 1: Install the Sessionboard app** | US-hosted organizations | Install from ChatGPT's plugin directory — no URL needed |
| **Option 2: Create a developer-mode connector** | EU / Middle East organizations | Paste your region's MCP server URL (paid ChatGPT plan, on the web) |

Not sure where you're hosted? Look at your admin login URL: `appv2.sessionboard.com` is the US, `appv2-eu.sessionboard.com` is Europe, and `appv2-me.sessionboard.com` is the Middle East.

## Option 1 — Install the Sessionboard app (US-hosted)

Sessionboard is published in ChatGPT's plugin directory.

<Steps>
  <Step title="Find Sessionboard">
    In ChatGPT (web, desktop, or mobile), click **Plugins** in the sidebar and search for "Sessionboard".
  </Step>
  <Step title="Install and sign in">
    Open the Sessionboard listing and install it. ChatGPT starts the Sessionboard OAuth flow: sign in with your Sessionboard admin credentials, pick your organization on the consent screen, review the requested access, and click **Authorize**.
  </Step>
  <Step title="Use it in a chat">
    Open a new chat, open the **+** menu (or type **@Sessionboard**), and select Sessionboard. Ask something like *"What events do we have in Sessionboard?"* to confirm it's working.
  </Step>
</Steps>

<Note>
The Sessionboard app points at the **US server**. If your organization is hosted in the EU or Middle East, the app won't see your data — use Option 2 instead.
</Note>

<Tip>
On ChatGPT Business, Enterprise, and Edu workspaces, an admin controls which plugins members can install under **Workspace settings → Plugins**. If you can't find or install Sessionboard, ask your ChatGPT workspace admin to allow it.
</Tip>

## Option 2 — Create a developer-mode connector (EU / Middle East)

EU- and Middle East-hosted organizations connect by creating their own connector that points at their region's server. ChatGPT's developer mode requires a paid plan (Plus, Pro, Business, Enterprise, or Education) on the web. Leave **Authentication** on **OAuth** when you create the connector.

Use the MCP server URL for your region:

| Your admin login URL | Region | MCP server URL |
|----|----|----|
| `appv2-eu.sessionboard.com` | Europe | `https://mcp-eu.sessionboard.com/mcp` |
| `appv2-me.sessionboard.com` | Middle East | `https://mcp-me.sessionboard.com/mcp` |
| `appv2.sessionboard.com` | United States | `https://mcp.sessionboard.com/mcp` (only if you can't use the app in Option 1) |

<Steps>
  <Step title="Turn on developer mode">
    In ChatGPT, go to **Settings → Security and login** and enable **Developer mode**. The "elevated risk" warning is ChatGPT's standard notice for any connector it hasn't reviewed yet.

    ![The Developer mode toggle under Security and login in ChatGPT settings](/images/kb/connect-ai-chatgpt-developer-mode.png)
  </Step>
  <Step title="Create the connector">
    Go to **Plugins** in the ChatGPT sidebar and click the **+** button next to the search box.

    ![The Plugins page header in ChatGPT with the create button on the right](/images/kb/connect-ai-chatgpt-plugins-create.png)

    In the **New Plugin** dialog, give it a name like "Sessionboard", paste the MCP server URL for your region — for example `https://mcp-eu.sessionboard.com/mcp` — leave **Authentication** on **OAuth**, check **I understand and want to continue**, and click **Create**.

    ![ChatGPT's New Plugin dialog filled in with the Sessionboard name and US MCP server URL, OAuth selected](/images/kb/connect-ai-chatgpt-new-connector.png)
  </Step>
  <Step title="Sign in and authorize">
    ChatGPT starts the Sessionboard OAuth flow. Sign in, select your organization, and click **Authorize**. Back on the connector's page, click **Refresh** if the tool list looks empty.

    ![The Sessionboard connector detail page in ChatGPT with the Try in chat button](/images/kb/connect-ai-chatgpt-connector-detail.png)
  </Step>
  <Step title="Use it in a chat">
    Click **Try in chat** (or open a new chat, open the **+** menu, and select Sessionboard). Then prompt away — ChatGPT shows "Called tool" while it queries your data:

    ![A ChatGPT conversation where the prompt "Search Sessionboard for keynote sessions" triggers a tool call and returns two keynote sessions](/images/kb/connect-ai-chatgpt-in-chat.png)
  </Step>
</Steps>

## What to try first

- *"What events do we have in Sessionboard?"*
- *"Search Sessionboard for keynote sessions"*
- *"Create a new session called 'AI in Events' in [event name]"*

More examples, plus how [PII masking](/integrations/connect-ai-assistants#privacy-and-pii) works, are on the [AI assistants overview](/integrations/connect-ai-assistants). The full tool list lives in the [MCP Server reference](https://apidocs.sessionboard.com/insights/mcp-server).

## Troubleshooting

| Symptom | Likely cause |
|----|----|
| Sessionboard connects but shows no organizations | App installed on an EU/ME-hosted org — the app uses the US server; use [Option 2](#option-2--create-a-developer-mode-connector-eu--middle-east) |
| Can't find or install the Sessionboard app | On a Business, Enterprise, or Edu workspace, an admin has to allow it under **Workspace settings → Plugins** |
| Developer mode missing in settings | Free plan, or a workspace where an admin has disabled it — developer mode needs a paid plan on the web |
| Developer-mode connector added but no tools appear | Click **Refresh** on the connector's detail page after authorizing |
| Consent screen shows no organizations | Wrong regional URL, AI features not enabled, or the role is missing **Connect AI assistants** — see [Prerequisites](/integrations/connect-ai-assistants#prerequisites) |
| ChatGPT can read but not create/update | Write scopes weren't granted during authorization — disconnect and reconnect Sessionboard, approving write access |
