ChatGPT connects to Sessionboard through the [Sessionboard MCP server](/integrations/connect-ai-assistants), so it can query and manage your event data in plain English. Before you start, check the [prerequisites](/integrations/connect-ai-assistants#prerequisites) — AI features enabled for your org and the AI Access permission on your user — and note that ChatGPT's developer mode requires a paid plan (Plus, Pro, Business, Enterprise, or Education) on the web.

Use the MCP server URL for your region:

| Your admin login URL | Region | MCP server URL |
|----|----|----|
| `appv2.sessionboard.com` | United States | `https://mcp.sessionboard.com/mcp` |
| `appv2-eu.sessionboard.com` | Europe | `https://mcp-eu.sessionboard.com/mcp` |
| `appv2-me.sessionboard.com` | Middle East | `https://mcp-me.sessionboard.com/mcp` |

## Set up the connector

<Steps>
  <Step title="Turn on developer mode">
    In ChatGPT, go to **Settings → Security and login** and enable **Developer mode**. The "elevated risk" warning is ChatGPT's standard notice for any connector it hasn't reviewed yet.

    ![The Developer mode toggle under Security and login in ChatGPT settings](/images/kb/connect-ai-chatgpt-developer-mode.png)
  </Step>
  <Step title="Create the connector">
    Go to **Plugins** in the ChatGPT sidebar and click the **+** button next to the search box.

    ![The Plugins page header in ChatGPT with the create button on the right](/images/kb/connect-ai-chatgpt-plugins-create.png)

    In the **New Plugin** dialog, give it a name like "Sessionboard", paste the MCP server URL for your region, leave **Authentication** on **OAuth**, check **I understand and want to continue**, and click **Create**.

    ![ChatGPT's New Plugin dialog filled in with the Sessionboard name and US MCP server URL, OAuth selected](/images/kb/connect-ai-chatgpt-new-connector.png)
  </Step>
  <Step title="Sign in and authorize">
    ChatGPT starts the Sessionboard OAuth flow. Sign in, select your organization, and click **Authorize**. Back on the connector's page, click **Refresh** if the tool list looks empty.

    ![The Sessionboard connector detail page in ChatGPT with the Try in chat button](/images/kb/connect-ai-chatgpt-connector-detail.png)
  </Step>
  <Step title="Use it in a chat">
    Click **Try in chat** (or open a new chat, open the **+** menu, and select Sessionboard). Then prompt away — ChatGPT shows "Called tool" while it queries your data:

    ![A ChatGPT conversation where the prompt "Search Sessionboard for keynote sessions" triggers a tool call and returns two keynote sessions](/images/kb/connect-ai-chatgpt-in-chat.png)
  </Step>
</Steps>

## What to try first

- *"What events do we have in Sessionboard?"*
- *"Search Sessionboard for keynote sessions"*
- *"Create a new session called 'AI in Events' in [event name]"*

More examples, plus how [PII masking](/integrations/connect-ai-assistants#privacy-and-pii) works, are on the [AI assistants overview](/integrations/connect-ai-assistants). The full tool list lives in the [MCP Server reference](https://apidocs.sessionboard.com/insights/mcp-server).

## Troubleshooting

| Symptom | Likely cause |
|----|----|
| Developer mode missing in settings | Free plan, or a workspace where an admin has disabled it — developer mode needs a paid plan on the web |
| Connector added but no tools appear | Click **Refresh** on the connector's detail page after authorizing |
| Consent screen shows no organizations | Wrong regional URL, AI features not enabled, or missing AI Access permission — see [Prerequisites](/integrations/connect-ai-assistants#prerequisites) |
| ChatGPT can read but not create/update | Write scopes weren't granted during authorization — remove and re-add the connector, approving write access |
