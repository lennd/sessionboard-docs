## Import a program from a CSV

If you already have your program in a spreadsheet, import it instead of adding sessions one by one.

### Prepare the file

Save your spreadsheet as a CSV with a header row. Sessions recognises these columns, in any order:

| Column | Also recognised as | Needed |
| --- | --- | --- |
| Title | Session title, Name, Session | Yes |
| Description | Abstract, Summary | No |
| Track | Topic, Theme | No |
| First name | Speaker first name | No |
| Last name | Surname, Speaker last name | No |
| Email | Speaker email, E-mail | No |
| Job title | Position, Role | No |

Put one speaker on each line. Lines with the same title become one session with several speakers.

### Import it

<Steps>
<Step title="Choose the file">
On **Agenda**, under **Import your program**, select **Choose a CSV**.
</Step>
<Step title="Check what was found">
Sessions says how many sessions and speakers it found. If it can't find a title column, it says so: name one column "Title".
</Step>
<Step title="Import">
Select **Import**. Imported sessions are accepted and appear under **Not scheduled yet**.
</Step>
</Steps>

A session whose title is already on the event is skipped, so importing the same file twice doesn't make duplicates. A track name you don't have yet is added to **Tracks**.

Imported speakers count toward the speakers your plan includes for the event.

## Export to a spreadsheet

- **Sessions**: on **Agenda**, select **Export CSV**. You get every session, whatever its decision, with its title, status, start and end times in your event's timezone, room, track, format, speakers and their emails, sponsors, whether it came through the call, and description.
- **Speakers**: on **Speakers**, select **Export CSV**. You get each speaker's name, email, job title and sessions.

<Note>
The files open in Excel, Numbers and Google Sheets. Cells that start with `=`, `+`, `-` or `@` get a leading apostrophe so a spreadsheet doesn't run them as formulas.
</Note>
