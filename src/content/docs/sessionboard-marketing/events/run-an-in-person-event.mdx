An in-person event has tabs for each part of the job: **Guests**, **Accounts**, **Emails**, **Event page**, **Check-in**, **Follow-up**, **Listings** and **Settings**.

## Build the guest list

On **Guests**, add people or select **Upload a CSV**. When people ask to come, select **Approve**, **Waitlist** or **Decline**.

## Send the invitations

<Steps>
<Step title="Check the email">
On **Emails**, read the invitation. Select **Rewrite this email** to have it redrafted, or **Keep these words**.
</Step>
<Step title="Send">
Select **Send invitations** on **Guests**, or **Send this email** on **Emails**.
</Step>
</Steps>

<Warning>
Invitations go out as soon as you send them and can't be recalled.
</Warning>

## Check people in

On **Check-in**, use **Find a guest** to mark people as they arrive. Select **Open on another phone** to check in from a second device at the door.

## List the event

On **Listings**, post the event to LinkedIn Events or Luma, and confirm with **Yes, post it**.

## Tours

If the event is one stop of a tour, you can add another stop like it and send invitations for every stop at once from Ask.
