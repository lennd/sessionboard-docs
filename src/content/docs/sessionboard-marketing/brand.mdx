Event pages, campaign previews and clips are all made from the brand kit an event uses, so they always match.

<Steps>
<Step title="Make the kit">
Go to **Brand** and select **Make my brand kit**.
</Step>
<Step title="Fill it in">
Import it from your website, or fill it in with Claude or ChatGPT, then check the logos, colors, fonts, voice, posting rules and video clip style. Changes save as you go.
</Step>
<Step title="Pick each event's kit">
Under **Which kit each event uses**, choose a kit per event. **Make default** sets the kit new events use.
</Step>
</Steps>
