**Home** is Ask. You can also open it from **Ask** on the right-hand rail, from the menu on a phone, or with **Set it up with Ask** on any section. Chats are saved; start one with **New chat** or find an old one with **Search chats**.

## What you can ask

Each section has its own set of things Ask can do. A few examples:

| Section | Try |
| --- | --- |
| Events | "Create a webinar series", "Who's coming?", "Send the invitations" |
| Campaigns | "Get my speakers sharing", "How are my campaigns doing?" |
| Goals | "Fill my event", "How is my goal doing?" |
| Content | "Make everything from my last recording", "Turn this event into a podcast", "Draft this month's newsletter" |
| Pages | "Write the event page", "Add a sign-up form to my event page" |
| People | "Who's most engaged?", "Import people from a CSV" |
| Results | "What drove registrations?", "Share the results as a link" |
| Apps | "Connect an app", "What did my AI assistants do?" |

Anything that sends, posts, publishes, turns on a follow-up or spends money asks you first.

<Note>
If Ask can't do something from the workspace, it says so and lists what it can set up right now.
</Note>
