A portal file is something you hand out, not something you collect: the programme PDF, the exhibitor manual, a venue map, or a link to a page elsewhere. It downloads from the portal home. To collect a file *from* someone, use a [file request](/portals/collect-documents); to share content you will keep editing, use a [resource page](/portals/assign-pages).

## Add a file

<Steps>
<Step title="Open Files">
Go to **Program → Portals → Files** and click **Add → Add File**.

![The Files library under Portals](/images/kb/portal-files-library.png)
</Step>
<Step title="Upload it, or link it">
![The Add File panel](/images/kb/portal-file-add.png)

| Field | What it does |
| --- | --- |
| **Type** | **Upload File** for a document (up to 5 GB), or **External URL** for a link. |
| **Title** | The name shown on the portal. |
| **Description** | One line of context under the title. |

Click **Add → Add File**.
</Step>
</Steps>

## Assign the file to a portal

Open the **⋯** menu on the portal card and choose **Edit Tasks**. In the **Files** section of the **Assign Items** step click **Add**, tick the file, and click **Add Selected**. The pencil under **Actions** opens **Edit Settings**, where you can give the file an **Alias** for this portal and switch on **Open in New Tab**.

![The Assign Items step, with its content sections](/images/kb/portal-editor-assign-items.png)

A file can sit on as many portals as you like. Replace the file in the library and every portal serves the new version.
