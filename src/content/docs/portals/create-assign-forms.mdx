## Create a form

Go to **Program → Portals → Forms** and click **Add → Add Form**. The tabs — **All Forms**, **Contact Forms**, **Group Forms**, **Submission Forms** — filter by who the form is for.

![The Forms library under Portals](/images/kb/portal-forms-library.png)

### Form Setup

The editor has three steps down the left: **Form Setup**, **Form Questions**, **Settings**.

| Field | What it does |
| --- | --- |
| **Name** | Internal — what your team sees in the library. |
| **Title** | What portal users see. |
| **Show welcome description** | Adds a **Welcome description** above the questions — instructions, context, a deadline. |
| **Type** | **Contacts** (one person), **Groups** (a sponsor or exhibitor company), or **Submissions** (each session). This decides which fields you can put on the form and where the answers land. |

### Form Questions

Give the section a **Section Title** and **Description & Instructions**, then click **Add Field**. Pick an existing field — First Name, Job Title, Headshot, Session Title — or create a new one; existing fields arrive pre-filled from the record and write back on submit.

#### Layout blocks & multi-page forms

Hover between fields to insert layout blocks:

- **Section Header** — a heading that groups related questions.
- **Rich Text** — formatted text, images and links.
- **Divider** — a horizontal rule.
- **Page Break** — splits the form into pages. Give each break a title and portal users see a step indicator, moving with **Next** and **Back**; required questions are validated per page. Remove every break and the form is one page again.

**Conditional logic** works on questions and on layout blocks. Open a question's or block's **⋯** menu, choose **Use question rules**, and build the rule under **Show this field when** — for example, show travel instructions only when "Attending in person?" is Yes. A rule can only use a question that appears above it.

**Merge tags.** Type &#123;&#123;event_name&#125;&#125; in the welcome description, a section title or a Rich Text block and it renders as the event's name.

Click **Preview** at any point to see the form as a portal user will — pages, rules and merge tags included.

### Settings

**Send Confirmation Email** emails the person when they submit, with a PDF summary of their answers attached and a link back to the submission in their portal. **Confirmation message** is your text in that email; it accepts merge tags.

## Assign the form to a portal

Open the **⋯** menu on the portal card and choose **Edit Tasks**. In the **Forms** section of the **Assign Items** step click **Add**, tick the form, and click **Add Selected**. Then use the pencil under **Actions** to open **Edit Settings**:

![Edit Settings for an item on a portal](/images/kb/portal-item-settings.png)

| Setting | What it does |
| --- | --- |
| **Form Title Alias** | A different title for this portal only. |
| **Due Date** / **Extended Due Date** | A real deadline, and an optional grace period after it. Once both pass the form can no longer be submitted. |
| **Allow edits** | Lets the person reopen and change their answers after submitting. |
| **Required** | Marks the form as required on the portal. |
| **Make Completed Tasks View-Only** | Locks the form once submitted. |
| **Assign By Filter** *(Submissions forms only)* | Show the form only on submissions that match **Submission Filters**, optionally limited to certain **Participant Roles**. |

Click **Update**. A form can sit on several portals, and can also be assigned to a few people directly — select them in **Contacts**, then **Assign → Forms** ([Assign tasks (including bulk)](/portals/task-assignment)).

## See who has submitted

The form is a column in **Contacts**, **Speakers**, **Sponsors** or **Exhibitors** — add it with **Columns** and save the view ([Dashboard views](/reporting/dashboard-views)).

| Icon | Status | Meaning |
| --- | --- | --- |
| Green check | **Submitted** | Done. |
| Blue circle | **Assigned Via Portal** | Reached them through a portal; not yet submitted. |
| Amber clipboard | **Manually Assigned** | Assigned to this record directly; not yet submitted. |
| Grey plus | **Not Assigned** | Click to assign to this one record. |

## Review and export the answers

On **Program → Portals → Forms**, open the form's **⋯** menu and choose **View Submissions**. The **Submissions** table shows one row per person; use **Columns**, filters and sorting to shape it, then **Export .CSV** or **Export .XLSX** from the **⋯** menu.

Tick submissions and click **Download Forms** for a zip of PDF summaries — one per submission, generated on demand. **Download files...** opens the bundle wizard below for anything uploaded through file questions.

## Download every file a form collected

If your form includes a file field (e.g., to collect logos, signed agreements, or other uploaded documents), you can download all submitted files in bulk as a single zip file. Sessionboard will bundle the files and email you a download link when the bundle is ready.
1. Within the Contacts (or Speakers, Sessions, Sponsors, or Exhibitors) module, select the contacts/records whose files you want to download using the checkbox next to their name.
2. At the top of the page, select More > Download Files.

   ![2-2](/images/kb/1e3b6e86-2-2.jpg)

3. In the Download Files modal, check Form file uploads — Files uploaded through portal form file fields. You can also select any other file types you want to include in the same bundle:
   - Headshots — Speaker headshots/contact photos
   - File requests — Files submitted to document/file requests
   - Session files — Files attached to sessions (presentations, handouts, etc.)
   - Custom field files — Files stored in custom file fields on records
   - Awards files — Files uploaded to awards programs (submissions, supporting docs)
   - Speaker contracts — Signed speaker contracts (PDFs)

   ![Bulk Download Files from File Fields](/images/kb/2adf155a-image-png-Jul-07-2026-05-10-55-5008-PM.png)

4. Click Next. Choose how to organize the files within the zip. The options available will vary depending on the file types you selected in the previous step:
   - By submitter — files grouped into folders by each contact's name
   - By field — files grouped into folders by form field name
   - By record — files grouped by individual record

   ![By record — files grouped by individual record](/images/kb/f5a0dffd-image-png-Jun-22-2026-03-01-40-0093-PM.png)

5. Click Next. Review the summary showing the total file count and estimated size.

<Tip>
TIP: The modal shows an estimated file count and size before you generate the download; use this to confirm you've selected the right records and file types.
</Tip>

![The summary showing total file count and estimated download size](/images/kb/dad19be7-image-png-Jun-22-2026-03-03-44-7526-PM.png)

6. Click Generate Download. Once the bundle is ready, an Export details screen will appear showing the file name, size, and number of files included. Click Download zip to save it to your device.

   ![Click Generate Download](/images/kb/a0c13642-image-png-Jun-22-2026-03-04-16-1552-PM.png)

7. You will also receive an email from Sessionboard with the subject "Your file is ready" containing a Download File link, handy if you close the modal before downloading.

![You will also receive an email from Sessionboard with the subject "Your file is ready" containing a Download](/images/kb/711e3730-image-png-Jun-22-2026-03-16-35-7370-PM.png)

<Note>
Only files submitted through file-type fields within the form are included in this download. Text, dropdown, and other field types are not included — use Export as CSV/XLSX for those.
</Note>


## Common questions

**Does an admin get notified when a form is submitted?**
Not by email. The **Submissions** page is the record; the task column in your contacts table shows who has finished at a glance.

**Is there a limit on the number of forms?**
No.
