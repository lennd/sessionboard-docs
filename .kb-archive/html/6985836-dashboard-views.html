Creating a view is a great way to personalize the way you see fields based on your current needs. Views can be created and seen by all admins.

  • Columns
  • Filter a View
  • Sort a View
  • Delete a View
  • Rename a View

Within your event, navigate to the module you are working from (for this example, we will be looking at the Contacts module).

Columns

Select "Columns" to add, order, and hide fields that you want to be shown on your dashboard view. 

Task Completion Status

To manage task completion for sessions, groups (sponsors/exhibitors), and contacts, add the task to your view.

Once completed, click the "Apply Changes" button.

💡TIP: Do not forget to SAVE your updated view so that the changes applied remain the next time you access this module.

Note: Columns currently support a maximum of 25 fields. If you need to display more information than that, consider creating multiple views with different column configurations to stay within the limit.

Filters

❗️You can not filter or sort by the following fields within the Contacts or Speakers Modules at this time:

  • [Session] Track
  • [Session] Language
  • Sessions

Select "Filter" from the right side of your screen.

Then click "+ Add Filter" to create a new one:

Within the pop-up modal, select the field that you would like to filter by. Next, you will be able to apply settings to this field to further filter by, such as:

  • contains
  • does not contain
  • is
  • is not
  • is empty
  • is not empty
  • starts with
  • ends with

Once complete, do not forget to select "Apply Changes" at the bottom of the pop-up modal.

💡TIP: Do not forget to SAVE your updated view so that the changes applied remain the next time you access this module. 

Sort By

❗️You can not filter or sort by the following fields within the Contacts or Speakers Modules at this time:

  • [Session] Track
  • [Session] Language
  • Sessions

Select "Sort" from the right side of your screen.

​

Within the pop-up modal, select the field you would like to sort, as well as if you would like to sort by ascending (↑) or descending (↓).

Once complete, do not forget to select "Apply Changes" at the bottom of the pop-up modal.

💡TIP: Do not forget to SAVE your updated view so that the changes applied remain the next time you access this module. 

Navigate To A View

To select a view to see, select the down arrow next to the grey "View" icon. This will open a pop-up modal that will allow you to select a previously created view to see.

   

Rename A View

Within your module, select the "View" button from the right side of your screen and click "Rename View".

                                       

Delete A View

Within your module, select the "View" button on the right side of your screen and click "Delete View".
