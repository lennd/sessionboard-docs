To have Submission Form Settings enabled within your event, contact support@sessionboard.com.

Adjust your Session Submission Form settings (i.e. background color, button colors, typography) to reflect the branding of your organization and event.

To locate your submission form settings, navigate to Settings > Submission Forms


IMPORTANT NOTE❗️: The settings applied will update ALL submission forms created within your event.

  • Appearance
  • Typography

Appearance

Within Appearance, the following areas can be set:

  • Logo Image + Alt-Text

  • Background Image + Alt-Text

  • Background Color

  • Primary Button Color + Text Color

  • Secondary Button Color + Text Color

Typography

Within Typography, the following areas can be set:

  • System Font

  • Form Title Font Size + Color

  • Section Header Font Size + Color

  • Section Description Font Size + Color

  • Question Labels Font Size + Color
