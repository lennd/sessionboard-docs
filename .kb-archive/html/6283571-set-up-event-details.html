    Record Settings

    • Set Submission Limit: Set the maximum number of sessions a user can submit to your event. This limit applies to the total number of submissions across all completed forms.
    • Automatically provision contact portal access: When enabled, contacts will automatically be given portal access when you add or import them.
    • Collect Additional Contacts: Enables the collection of Additional Contacts for your speakers through the session submission form (see example image of the submission form below).

    • Enable Primary Speakers: Turn on the ability to denote specific speakers (or authors) as 'Primary' across your sessions. This will help you understand who the primary point of contact is and who to feature for a given session or abstract.

    • Enable Session Speaker Acceptance: Allow speakers to accept or decline their participation in each accepted session through their portal.

    • Enable Speaker Headshot Limitations: Control what type of files and maximum file size for headshots being uploaded to your event. This will not auto-downsize the images; it will only prevent headshots from being uploaded, providing portal users with instructions on why the image wasn't allowed.
      • When enabled, this will apply restrictions to Submission Forms, Portal Forms, Application Forms, and Edit Profile functionality for admin and portal users.
      • You can now also specify allowed headshot dimensions — Height × Width, Height only, or Width only (for example, 300 × 300). These values set default crop max/min restrictions for headshots uploaded across the event, helping keep speaker headshots visually consistent.
      • Headshot Limitations are configured event-wide under Record Settings and apply to all places a headshot can be uploaded (submission forms, portal forms, application forms, and Edit Profile). There is no perform override.




     

    •  Enable Sponsor & Exhibitor Logo Limitations: Control what file formats, file sizes, and dimensions are accepted for sponsor and exhibitor logos uploaded to your event.

    Accepted File Formats: Restrict uploads to All Image Types, PNG, JPEG, or GIF.

    Limit File Size: Optionally cap the maximum file size for uploaded logos.

    Limit Dimensions: Set a max width and/or height (in pixels). Unlike Speaker Headshot Limitations, larger logo uploads are automatically downsized to fit rather than rejected. When both width and height are set, the crop tool also enforces the matching aspect ratio. Leave blank for no limit.

    Sponsor & Exhibitor Logo Limitations are configured event-wide under Record Settings and apply everywhere a sponsor/exhibitor logo can be uploaded.





    •  Record IDs: Configure the prefixes used to generate unique record IDs across your event.

    Submission Prefix / Contact Prefix / Group Prefix: Set a 3–6 uppercase character prefix used when generating IDs for submissions, contacts, and groups (e.g., sponsors/exhibitors) respectively.

    Keep original ID with subsessions: When enabled, subsessions retain the same record ID as their parent session instead of generating a new one.
