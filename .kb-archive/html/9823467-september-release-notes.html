🆕 New Features Drag and Drop Unscheduled Sessions in Agenda Calendar Views

Admins may schedule any unscheduled accepted sessions (e.g. sessions without a date or time) by dragging and dropping them in calendar views. Our new sidebar helps you find sessions by title keyword and shows tracks to keep your scheduling informed.

🛠️ FEATURE IMPROVEMENTS

Filter Portals by Session Submitters

Submitters are now given portal access and can be filtered down in Portal filters using the new “Is Submitter” filter.

Session Profile

Like the Contacts profile page, admins now have a full-page view to manage sessions- including access to a source code.

Embeds

Admins can create custom-filtered embeds to show a select list of sessions and/or speakers (i.e. filtering by track or session status).

How to Create Embeds

Portal Forms

Like our submission form, admins may now add dividers, headers, images, and rich text blocks to portal forms.

Evaluation Plans:

Evaluators who have performed any reviews now cannot be removed from an evaluation plan. This ensures their feedback remains with the plan and is not accidentally lost.
