How to access sponsors

Navigate to the Sponsors module > All Sponsors tab:

Sponsor Tier Levels

Sponsor Tier Levels - Tier is now a standard field for sponsor groups that can be customized in sponsor tiers. Tiers can be utilized to sync with our integration patterns (i.e. Swoogo).

This page will show 3 tiers by default.

  • Gold

  • Silver

  • Bronze

Admins can edit the names of these tiers or add new ones.

This field will be added to the default view of the sponsor's module to the right of “Name”.

 

In this view, admins can select tiers individually as shown above, or bulk apply them.
 

Filters, views & outreach

  • Filter by Tier to segment (e.g., Tier = Gold), then Save View for quick reuse.

  • From a filtered view, you can send targeted emails/SMS to that tier.

Use tiers to target Portals

Create tier-specific portals (e.g., different benefits or tasks):
Portals > Create Portal > Filter: Tier = {Your Tier} > add tier-specific tasks/files.

  • (For building portals, see Creating Custom Portals)

Why this helps (use cases)

  • Fulfillment by tier: Gold gets extra deliverables—filter Gold, bulk-assign tasks, and track completion in one place.

  • Tier-based comms: Send a “Logo specs” email only to Silver & Bronze; a “Sponsored session details” email only to Gold.

  • Cleaner admin views: Save “All Gold Sponsors” and “Needs Assets – Bronze” as reusable views for your team.

  • Portal experiences: Show different task sets/resources per tier (e.g., Gold gets “Upload Sponsored Session Slides”; Bronze doesn’t).

  • Import at scale: When tiers change post-sale, update 100+ sponsors at once via import.
