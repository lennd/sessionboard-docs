Release Date: May 15, 2025

Welcome to this month’s product updates! Below is a summary of new features and enhancements released during this cycle. These updates are designed to improve your overall experience and streamline your workflows within Sessionboard.

✅ New Features

  1. AI Evaluations (enabled upon request): Sessionboard’s AI Evaluations feature automates and enhances the submission review process using AI-generated scores, summaries, and feedback via customizable Virtual Evaluator Personas.

  2. Bulk Download File Request Submissions: Conveniently bulk download file request submissions as a single ZIP file to share with your AV team.
  3. Bulk Export History Page: View all generated bulk exports for session files, contact headshots, and file request submissions from one centralized location.


✨ Enhancements

  1. [History] View Sent System/Automated Emails: System-generated emails sent to event team members and contacts are now logged and viewable in the History module.

  2. [Event Settings] New 'Event Details' Fields: With the launch of new AI tools within Sessionboard, the more context you provide about your event, the more effective the AI will be in supporting your setup, especially when generating evaluator personas for session reviews. Be sure to complete the following fields within the Settings module on the Event Details page: Event Type, Event Website URL, Event Location, and Theme.
  3. [Event Settings] New 'Record Settings' Page: Enable 'Collect Additional Contacts' from the new 'Record Settings' page. 
  4. [Portal] Edit Appearance Shortcut: New “Edit Appearance” shortcut allows admins to quickly access and update portal appearance settings.
  5. [Embeds] Fields With No Values Are Hidden: Embeds now automatically hide any fields without values, keeping your display clean and focused.

🔗Integration Updates

Our integrations continue to improve! Read more about our recent updates below. 

  1. Cvent auto-sync: The Cvent auto-sync functionality ensures that new or updated sessions and speakers are continuously synced to Cvent every 30 minutes.
  2. API Returns 'Created By' for Session Files: When calling the 'Get Session' or 'Search Sessions' endpoint, you will now be able to retrieve the name and email of the user who uploaded a session file (formerly known as 'Content').
