In some cases, a session participant (such as a moderator) may need to view information about other participants in their session — for example, speaker names, emails, or phone numbers.

Portal Configuration

  1. Navigate to the Portals module and click the ellipses (⋮) to the right of the portal where you want users to view session participant information:
  2. Select Edit Settings:
  3. Within Step 3 (Configuration), enable the setting Manage Sessions:

    1. This setting allows portal users to view specific fields you choose to expose for session participants.
    2. It also enables them to view and, if permitted, edit certain session and participant fields.
    3. In the following steps, you’ll learn how to control which fields are visible and whether they are editable or view-only (locked).

  4. Click the Next button in the top-right corner to navigate to Page 4 (Appearance):


  5. In step 4, you can add all the appearance settings for the portal, including title, welcome, logo & background images: 
  6. In step 5, select Manage Fields:


    For both the Session and Contact sections, use the Show/Hide Fields button to control which fields are visible or hidden.
  7. In the Locked column, click the Lock icon to prevent portal users from editing certain fields.
    1. We recommend locking all session and contact participant fields so users can view, but not change, session details or participant information.

Steps to View Participant Information in the Portal

  1. In the My Sessions widget, select the session for which you want to view participant information.



  2.  A side panel will open, displaying detailed session information. Navigate to the Participants tab. You’ll see a list of all participants associated with the session (e.g., speakers, moderators, chairpersons).
  3. Click on the contact whose information you want to view.

❗️IMPORTANT INFORMATION:

  • If the field Email is exposed for the session participants, the mail icon will display. Selecting the icon will allow the user to view the email address.
  • Users will be able to view session participant tasks. Users will not be able to complete tasks for session participants unless they are assigned as their additional contact.
