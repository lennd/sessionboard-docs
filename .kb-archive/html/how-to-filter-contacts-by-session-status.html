Method 1: Using Pre-Set Filters

Go to the Speakers/Chairpersons/Moderators view, and click one of the pre-set filters at the top:

The list instantly narrows to speakers on sessions with that status—no setup needed:

  • Session – Accepted
  • Session – Pending
  • Session – Declined

Method 2: Manually

1) Go to the Contacts view

  1. From your event, open any tab under Contacts, can be 'All Contacts', 'Speakers', 'Chairpersons', 'Moderators, or 'Session Submitters'.

  2. Click Columns.
    This opens the field picker for the current view.

2) Expose the Session Fields

  1. In the field picker, check the boxes for the fields you want to use (e.g., [Session] Status - Accepted).

  2. Click Apply Changes to apply.


3) Add a filter by session status

  1. In the right sidebar, click Filter:

  2. Click Add Filter:

  3. Choose the session field you enabled (e.g., [Session] Status - Accepted).

  4. Set the condition (e.g., Is checked to include Accepted, or Is not checked to exclude).

  5. Click 'Apply Changes' to see matching contacts.

To save or rename this view, please check our Module Table Views guide.

Troubleshooting

  • I don’t see the [Session] Status Fields. Make sure you scroll down till you find Status field; you can try doing CTRL + F on your keyboard to search.

  • Filters aren’t changing results. Confirm the correct Session Status field is selected, and the condition is set to Is checked.
