You can now automatically grant portal access to contacts as you add/import them by enabling Settings → Record Settings → Automatically provision contact portal access. If this setting is off, continue using the manual steps below.

  1. Within the 'Contacts' module, select the contact(s) you would like to grant portal access to.

  2. At the top of your page select the button 'More' > 'Manage Portal Access'.

    ​

  3. From the pop-up window, select the blue Give Portal Access for the contacts you have selected.
