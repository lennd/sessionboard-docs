Important Note: The Zapier integration within Sessionboard is a self-service tool. While Sessionboard provides access to our Zapier application, it is the client’s responsibility to procure their own Zapier license and to build, implement, and maintain their Zaps. Sessionboard does not build or manage individual Zaps on behalf of clients. We recommend working closely with your internal team or a certified Zapier expert to ensure your workflows are set up and functioning as intended

 

If you want to automate workflows between Sessionboard and other apps like HubSpot, Google Sheets, or Slack, Zapier is the way to go.

This article walks you through setting up the Zapier integration with Sessionboard, including how to authenticate your account and build a working Zap.

Step-by-Step: Connecting Sessionboard to Zapier

1. Start a New Zap

  1. Go to your Zapier dashboard.

  2. Click Create - New Zap.

  3. In the Trigger step, search for Sessionboard and select it.

2. Authenticate Your Sessionboard Account

  • Zapier will prompt you to connect your Sessionboard account. To simplify your workflows, each event in your organization can be mapped as a separate connection.

  • You’ll see a screen asking for:

    • Connection Name - enter a name for your connection (e.g. the name of your event)

    • Region - select the region of your Sessionboard account. This corresponds with the Data Host Region of your organization.

      • If you log in with appv2-eu.sessionboard.com, choose Europe.
      • If you log in with appv2.sessionboard.com, choose United States.

    • Sessionboard Application ID

    • Sessionboard Integration Key

      • These keys are generated in each event from Settings > Integrations > Zapier.

      • Click "Get Access" to generate the Application ID and Integration Key.
      • Click each copy icon and paste each value into the corresponding field on the  Zapier authentication menu.

  • Sessionboard Organization API Key
    • This is accessible in your Organization Dashboard under Settings > API Tokens > Create Token.
    • You must have organization-level privileges to create and access tokens.
    • If you do not, please speak with an account admin or contact support for assistance.
    • We recommend creating a unique API key for Zapier.

  • Click the copy icon and paste the value into the Sessionboard Organization API Key field on the Zapier authentication menu.

🧪 Troubleshooting Authentication

If you see an error like:

  • Authentication failed: The app returned "An internal server error occurred."

Try the following:

  • Make sure all API fields are filled correctly.

  • Confirm you clicked Allow or Accept on the permission prompt.

  • Check if your account has the required permissions.

  • If needed, revisit the credentials keys in Sessionboard and regenerate them.

🔄 Testing the Connection

Once authenticated:

  • Zapier will confirm the connection is working:

⚡ Set Up the Zap Action

  1. Trigger - Sessionboard Event
  2. Choose a trigger event such as New Contact Created.
    1. Contact triggers include:
      1. New Contact Created
      2. Contact Recently Deleted
      3. Contact Recently Updated
      4. Contact Recently Associated With Event
        1. Use this to track existing contacts that were added to events from your CRM.
      5. Contact Recently Disassociated With Event
        1. Use this to track contacts that were removed from an event but still exist in your CRM.
    1. Session Triggers include
      1. New Session Created
      2. Session Recently Deleted
      3. Session Recently Updated
    2. Sponsor/Exhibitor Triggers include
      1. New Sponsor Created
      2. Sponsor Recently Deleted
      3. Sponsor Recently Updated
      4. Sponsor Recently Associated With Event
      5. Sponsor Recently Disassociated With Event
      6. New Exhibitor Created
      7. Exhibitor Recently Deleted
      8. Exhibitor Recently Updated
      9. Exhibitor Recently Associated With Event
      10. Exhibitor Recently Disassociated With Event

2.  Sessionboard Action - Find Record

Add your Action Step and select Sessionboard again:

  • Select the corresponding action from your trigger step
    • e.g., if you selected a Contact trigger, your action is Find Contact.
3. Connect Action - External App

  1. Choose any app that you would like to connect to your trigger (e.g. Slack).

  2. Choose an action event (e.g., Send Channel Message).

  3. (If necessary, authenticate that app to connect your account with Zapier)

  4. Configure what information and data fields from your Sessionboard (e.g., session description ID) are included in the action. (e.g., in my Slack message, I want to see new sessions that are added with their title, description, and speakers)

  5. Click Test to verify the connection works.

✅ Finalize and Publish Your Zap

  • If the test passes, name your Zap and click Publish.
  • Your integration is now live and running automatically!

     

FAQs

  • Where do I find my Zapier keys in Sessionboard?

    • Inside your event: Go to Settings > Integrations.

  • Can I reconnect or remove my Sessionboard account?

    • Yes. Zapier allows you to manage connections under your profile settings.
