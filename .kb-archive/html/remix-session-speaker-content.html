Enhance AI-Powered Features with Complete Event Details

With Sessionboard’s new AI features, the more context you provide about your event, the more effective the AI will be in supporting your setup.

Be sure to complete the following fields within the Settings module on the Event Details page:

  • Event Type

  • Event Website URL

  • Event Location

  • Theme


 

These fields help the AI better understand the nature, audience, and goals of your event, leading to smarter persona suggestions and more tailored evaluation workflows. Taking a few extra minutes here allows the AI to deliver more meaningful support as you build out your review process.

Remix Session & Speaker Content

To get started,  navigate to Studio in the left sidebar and click Remix Content


Or go directly to Library → Remix 

For this demonstration, we will review remixing session content; however, this workflow can be followed for remixing speaker content.

Configure

Choose the content you want to optimize:

  • Session Titles – Optimizes titles for clarity and engagement.
  • Session Descriptions – Improves clarity and audience appeal.
  • Tags – Suggests relevant tags based on session content.
  • Tracks – Suggests session categorization by track.
Set Remix Parameters
  • Tone – Select a tone from the dropdown (e.g., Professional, Friendly, Academic)
  • Additional Guidance – Optionally add custom instructions to guide the AI (e.g., “Make titles more engaging for a marketing audience”).

Select Content

Apply a filter based on session attributes or browse for specific sessions to target.

Review Results

On the left panel, you’ll see a list of the sessions you filtered. Select each one to review its optimized content:

  • The Original title and description.

  • The optimized version generated by the AI.

  • A summary of what was changed (e.g., “Shortened for clarity”, “Rephrased for a more professional tone”).

If needed, click Regenerate to try a different version. If satisfied, click Save to keep the optimized version.

Once all desired sessions have been reviewed and saved, click Finish Review in the bottom-right corner.

Summary

This page provides an overview of all the sessions you reviewed and saved updates for.

🎉 That’s it! Your remixed session content is now updated and ready for use in your event materials or portal.
