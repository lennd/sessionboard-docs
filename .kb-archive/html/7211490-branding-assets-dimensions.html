When creating a new event, using the correct image sizes ensures your event displays properly across all platforms. This article outlines the required images and recommended dimensions for new events in Sessionboard.

Event Images and Dimensions:

Note: Images not meeting the recommended dimensions may be cropped or scaled incorrectly.

Event Logo

 300 x 300 px

The event logo is displayed within the session submission form, portal, group intake forms, and all emails sent through Sessionboard. 

Event Banner

 1500 x 500 px

The event banner is displayed within the session submission form, group intake forms, and the portal. 

Note: Background images should not include text. 

Steps to Add Images:

  1. Navigate to the Event Details page within the Settings module.

  2. Click Upload next to the relevant image type.

  3. Save your edits once complete.
